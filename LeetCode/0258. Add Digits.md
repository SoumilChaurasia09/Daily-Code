# 0258. Add Digits

**Problem Name:** Add Digits  
**Difficulty:** Easy

---

## Question

Given an integer `num`, repeatedly add all of its digits until the result has only one digit.

Return the final single-digit number.

---

## My Solution

```cpp
class Solution {
public:
    int addDigits(int num) {

        while (num >= 10) {

            int sum = 0;

            while (num > 0) {
                sum += num % 10;
                num = num / 10;
            }

            num = sum;
        }

        return num;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(log n)` |
| **Space Complexity** | `O(1)` |

## What I Learned

This problem helped me practice working with the digits of a number.

I repeatedly extracted each digit using the modulo (`%`) operator, added the digits together, and replaced the original number with their sum. I continued this process until the number became a single digit.

This problem also reinforced my understanding of using loops and arithmetic operations to manipulate numbers.

Initially, I thought about converting the number into a string and adding the characters. However, using arithmetic operations made the solution simpler and avoided extra space.

I also learned that there is an `O(1)` mathematical solution using the **Digital Root** concept, but implementing the iterative approach helped me better understand digit manipulation.
