# 1934. Confirmation Rate

**Problem Name:** Confirmation Rate
**Difficulty:** Medium

---

## Question

Find the confirmation rate for every user.

The formula is:

```text
Confirmation Rate = Confirmed Messages / Total Confirmation Requests
```

If a user has no confirmation requests, the rate should be `0`.

The result should be rounded to `2` decimal places.

---

## My Solution

```sql
SELECT 
    s.user_id,
    ROUND(
        COALESCE(
            SUM(CASE WHEN c.action = 'confirmed' THEN 1 ELSE 0 END) 
            / COUNT(c.user_id),
            0
        ),
        2
    ) AS confirmation_rate
FROM Signups s
LEFT JOIN Confirmations c
    ON s.user_id = c.user_id
GROUP BY s.user_id;
```

---

## Approach

### 1. Start with all users

We use:

```sql
FROM Signups s
```

Every user must appear in the result, even if they have no confirmation requests.

---

### 2. Use `LEFT JOIN`

```sql
LEFT JOIN Confirmations c
    ON s.user_id = c.user_id
```

`LEFT JOIN` keeps users who have no matching confirmation records.

For example, user `6` has no confirmation requests, but they still need to appear with:

```text
0.00
```

---

### 3. Count confirmed messages

We use:

```sql
SUM(CASE WHEN c.action = 'confirmed' THEN 1 ELSE 0 END)
```

For example, if a user has:

```text
confirmed
confirmed
timeout
```

the `CASE` produces:

```text
1
1
0
```

So:

```text
SUM = 2
```

There are `2` confirmed messages.

---

### 4. Count total requests

We use:

```sql
COUNT(c.user_id)
```

This counts all confirmation records.

For:

```text
confirmed
confirmed
timeout
```

the count is:

```text
3
```

Therefore:

```text
2 / 3 = 0.67
```

---

### 5. Avoid NULL using COALESCE

For a user with no confirmation requests:

```sql
COUNT(c.user_id)
```

is `0`.

The division would result in `NULL`.

So we use:

```sql
COALESCE(..., 0)
```

This converts the result to:

```text
0
```

---

### 6. Round to Two Decimal Places

Finally:

```sql
ROUND(..., 2)
```

makes results such as:

```text
0.5 → 0.50
0.6666 → 0.67
1 → 1.00
```

---

## Example

For user `2`:

```text
confirmed
timeout
```

Confirmed messages:

```text
1
```

Total requests:

```text
2
```

Therefore:

```text
1 / 2 = 0.50
```

For user `7`:

```text
confirmed
confirmed
confirmed
```

Therefore:

```text
3 / 3 = 1.00
```

For user `6`:

```text
No confirmation requests
```

Therefore:

```text
0.00
```

---

## Key Takeaway

The important pattern is:

```text
Signups
   ↓
LEFT JOIN Confirmations
   ↓
SUM(CASE...) → confirmed count
   ↓
COUNT(...) → total requests
   ↓
confirmed / total
   ↓
COALESCE(..., 0)
   ↓
ROUND(..., 2)
```

Use `LEFT JOIN` because users with no confirmation requests must still appear in the result.
