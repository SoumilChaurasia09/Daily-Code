# 3942. Minimum Operations to Sort a Permutation

**Problem Name:** Minimum Operations to Sort a Permutation
**Difficulty:** Medium

---

## Question

You are given a permutation of integers from `0` to `n - 1`.

You can perform two operations:

1. Reverse the entire array.
2. Rotate the array left by one position.

Return the minimum number of operations needed to sort the array in increasing order. If sorting is impossible, return `-1`.

---

## My Solution

```cpp
class Solution {
public:
    int minOperations(vector<int>& nums) {
        int n = nums.size();
        int zero = 0;

        for (int i = 0; i < n; i++) {
            if (nums[i] == 0) {
                zero = i;
                break;
            }
        }

        bool normal = true;
        bool reversed = true;

        for (int i = 0; i < n; i++) {
            if (nums[(zero + i) % n] != i) {
                normal = false;
            }

            if (nums[(zero - i + n) % n] != i) {
                reversed = false;
            }
        }

        int ans = INT_MAX;

        if (normal) {
            ans = min(zero, n - zero + 2);
        }

        if (reversed) {
            int pos = n - 1 - zero;
            ans = min(ans, 1 + min(pos, n - pos));
        }

        return ans == INT_MAX ? -1 : ans;
    }
};
```

---

## Approach

### 1. Find the position of zero

The sorted permutation always starts with `0`.

Store the index of `0` in `zero`.

### 2. Check the normal order

Check whether the elements follow the increasing cyclic order:

`0, 1, 2, ..., n - 1`

Starting from `zero`, check whether each next element equals `i`.

If the order is correct, the array can be sorted using rotations and possibly reversals.

The cost is:

`min(zero, n - zero + 2)`

* `zero` operations rotate the array left until `0` reaches the beginning.
* Alternatively, reversing, rotating, and reversing again can achieve the equivalent right rotation, costing `n - zero + 2` operations.

### 3. Check the reversed order

The array might also be sortable by reversing it and then rotating.

Check whether the elements follow the required order when traversing backward from `zero`.

If this order is valid, calculate:

`pos = n - 1 - zero`

The minimum cost for this possibility is:

`1 + min(pos, n - pos)`

The `1` represents a reversal, and the remaining operations account for rotations.

### 4. Return the minimum answer

Take the minimum cost among all valid possibilities.

If neither order is possible, return `-1`.

---

## Example

**Input:**

```text
nums = [0, 2, 1]
```

The position of `0` is `0`.

The normal increasing order is invalid, but the backward order is valid.

One way to sort the array:

1. Rotate left: `[2, 1, 0]`
2. Reverse: `[0, 1, 2]`

**Output:**

```text
2
```

---

## Complexity

**Time Complexity:** `O(n)` — Finding zero and checking both possible orders each take linear time.

**Space Complexity:** `O(1)` — Only a few variables are used.

---

## Key Takeaway

The allowed operations can only produce rotations of the original order or rotations of its reversed order. Check both possibilities and calculate the minimum number of operations required.
