# 3875. Construct Uniform Parity Array I

**Problem Name:** Construct Uniform Parity Array I
**Difficulty:** Easy

---

## Question

Given an array of distinct integers, construct another array of the same length where all elements are either odd or all even.

For each element, we can either:

* Keep the original value.
* Subtract another element from it.

Return `true` if such an array can be constructed.

## Approach

The answer is always `true`.

There are two cases.

### Case 1: All elements already have the same parity

We simply keep every element unchanged.

For example:

```text
[4, 6, 8]
```

All are even, so the answer is `true`.

### Case 2: The array contains both odd and even numbers

We can make every element odd.

For an even number, subtract any odd number:

```text
even - odd = odd
```

For an odd number, subtract any even number:

```text
odd - even = odd
```

Since both parities exist, every element can be made odd.

For example:

```text
[2, 3]
```

For `2`:

```text
2 - 3 = -1
```

For `3`, keep it as `3`.

Result:

```text
[-1, 3]
```

Both are odd.

If there is only one element, we can simply keep it unchanged.

Therefore, every valid input can produce a uniform-parity array.

**Time Complexity:** `O(1)`

**Space Complexity:** `O(1)`

---

## Key Takeaway

The important parity rules are:

```text
even - even = even
odd - odd = even

even - odd = odd
odd - even = odd
```

If both odd and even numbers exist, we can make every element odd.

If all elements already have the same parity, we can keep them unchanged.

Therefore, the answer is always `true`.
