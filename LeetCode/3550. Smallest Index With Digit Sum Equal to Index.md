# 3550. Smallest Index With Digit Sum Equal to Index

**Problem Name:** Smallest Index With Digit Sum Equal to Index
**Difficulty:** Easy

---

## Question

Given an integer array `nums`, find the smallest index `i` where the sum of the digits of `nums[i]` is equal to `i`.

If no such index exists, return `-1`.

---

## My Solution

```cpp
class Solution {
public:
    int smallestIndex(vector<int>& nums) {
        for (int i = 0; i < nums.size(); i++) {
            int n = nums[i];
            int sum = 0;

            while (n > 0) {
                sum += n % 10;
                n /= 10;
            }

            if (sum == i) {
                return i;
            }
        }

        return -1;
    }
};
```

---

## Approach

1. Traverse the array from left to right using index `i`.
2. For each `nums[i]`, calculate the sum of its digits.
3. To get the last digit:

   ```cpp
   n % 10
   ```
4. Remove the last digit:

   ```cpp
   n /= 10
   ```
5. If the digit sum is equal to the current index:

   ```cpp
   if (sum == i)
   ```

   return `i` immediately.
6. Since we traverse from left to right, the first matching index is automatically the smallest.
7. If no index matches, return `-1`.

---

## Example

For:

```text
nums = [1, 10, 11]
```

At index `0`:

```text
nums[0] = 1
digit sum = 1
index = 0
```

They are not equal.

At index `1`:

```text
nums[1] = 10
digit sum = 1 + 0 = 1
index = 1
```

They are equal, so we immediately return:

```text
1
```

---

## Complexity

**Time Complexity:** `O(n × d)`

Where `n` is the number of elements and `d` is the maximum number of digits in an element.

**Space Complexity:** `O(1)`

Only a few integer variables are used.

---

## Key Takeaway

Traverse the array from left to right and calculate the digit sum of each number.

The first index satisfying:

```text
digit sum of nums[i] == i
```

is the answer.
