# 0287. Find the Duplicate Number

**Problem Name:** Find the Duplicate Number  
**Difficulty:** Medium

---

## Question

Given an integer array `nums` containing `n + 1` integers where each integer is in the range `[1, n]`, return the duplicate number.

The solution should not modify the array and should use as little extra space as possible.

---

## My Solution

```cpp
class Solution {
public:
    int findDuplicate(vector<int>& nums) {
        int left = 1;
        int right = nums.size() - 1;

        while (left < right) {
            int mid = left + (right - left) / 2;

            int count = 0;
            for (int num : nums) {
                if (num <= mid)
                    count++;
            }

            if (count > mid)
                right = mid;
            else
                left = mid + 1;
        }

        return left;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(n log n)` |
| **Space Complexity** | `O(1)` |

---

## What I Learned

This problem introduced me to a different use of **Binary Search**.

Instead of searching on the array indices, I performed Binary Search on the **value range** from `1` to `n`.

For each middle value, I counted how many numbers in the array were less than or equal to `mid`.

- If the count was greater than `mid`, the duplicate must be in the left half.
- Otherwise, the duplicate was in the right half.

This approach works because of the **Pigeonhole Principle** and does not modify the original array.

---

## Personal Notes

Initially, I thought about using a hash set to find the duplicate, but that would require extra space. I also considered sorting the array, but the problem does not allow modifying it.

Learning that Binary Search can be applied to the **answer space** instead of the array itself was something new for me. This problem showed me that sometimes the search range is not the array indices but the possible values.
