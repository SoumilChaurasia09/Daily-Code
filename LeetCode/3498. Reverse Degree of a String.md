# 3498. Reverse Degree of a String

**Problem Name:** Reverse Degree of a String
**Difficulty:** Easy

---

## Question

Given a string `s`, calculate its reverse degree.

For each character:

* `'a'` has reverse alphabet value `26`
* `'b'` has reverse alphabet value `25`
* ...
* `'z'` has reverse alphabet value `1`

Multiply this value by the character's **1-indexed position** in the string and add all the products.

---

## My Solution

```cpp
class Solution {
public:
    int reverseDegree(string s) {
        int sum = 0;

        for (int i = 0; i < s.size(); i++) {
            int value = 'z' - s[i] + 1;
            sum += value * (i + 1);
        }

        return sum;
    }
};
```

---

## Approach

We loop through every character in the string.

The reverse alphabet value can be calculated using:

```cpp
'z' - s[i] + 1
```

For example:

```text
'a' → 26
'b' → 25
'c' → 24
'z' → 1
```

The loop index `i` starts from `0`, but the problem uses a **1-indexed position**, so we use:

```cpp
i + 1
```

For every character:

```text
reverse alphabet value × string position
```

is added to `sum`.

---

## Example

For:

```text
s = "abc"
```

Values are:

```text
a → 26 × 1 = 26
b → 25 × 2 = 50
c → 24 × 3 = 72
```

Therefore:

```text
26 + 50 + 72 = 148
```

---

## Complexity

**Time Complexity:** `O(n)`

**Space Complexity:** `O(1)`

---

## Key Takeaway

The reverse alphabet position can be directly calculated using:

```cpp
'z' - character + 1
```

Then multiply it by the **1-based position** of the character.
