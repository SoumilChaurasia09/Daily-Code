# 2540. Minimum Common Value

**Problem Name:** Minimum Common Value  
**Difficulty:** Easy

---

## Question

Given two sorted integer arrays `nums1` and `nums2`, return the smallest integer that appears in both arrays.

If there is no common value, return `-1`.

---

## My Solution

```cpp
class Solution {
public:
    int getCommon(vector<int>& nums1, vector<int>& nums2) {

        int i = 0;
        int j = 0;

        while (i < nums1.size() && j < nums2.size()) {

            if (nums1[i] == nums2[j]) {
                return nums1[i];
            }
            else if (nums1[i] < nums2[j]) {
                i++;
            }
            else {
                j++;
            }
        }

        return -1;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(n + m)` |
| **Space Complexity** | `O(1)` |

Where:
- `n` = size of `nums1`
- `m` = size of `nums2`

---

## What I Learned

This problem helped me practice the **Two Pointer** technique.

Since both arrays are already sorted, I compared their current elements.

- If both elements were equal, I found the smallest common value and returned it.
- If one element was smaller, I moved that pointer forward because larger values might match later.
- I continued until one of the arrays was completely traversed.

This approach avoids checking every pair of elements and is much more efficient than a nested loop.

---

## Personal Notes

At first, I thought about using two nested loops to compare every element of one array with every element of the other. However, that would take `O(n × m)` time.

Because the arrays are sorted, using two pointers makes the solution much faster. This problem reinforced that sorted arrays often allow us to solve problems efficiently without extra space.
