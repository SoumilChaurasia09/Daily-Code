# 1748. Sum of Unique Elements

**Problem Name:** Sum of Unique Elements
**Difficulty:** Easy

---

## Question

Given an integer array `nums`, find the sum of all elements that appear **exactly once**.

An element is unique if its frequency in the array is `1`.

For example:

```text
nums = [1,2,3,2]
```

`1` and `3` appear only once, so:

```text
1 + 3 = 4
```

---

## My Solution

```cpp id="q5m2rx"
class Solution {
public:
    int sumOfUnique(vector<int>& nums) {
        int count[101] = {};

        for (int num : nums) {
            count[num]++;
        }

        int sum = 0;

        for (int num : nums) {
            if (count[num] == 1) {
                sum += num;
            }
        }

        return sum;
    }
};
```

---

## Approach

We use a **frequency array** to count how many times each number appears.

Since the constraints say:

```text
1 <= nums[i] <= 100
```

we can create:

```cpp id="j8v1dn"
int count[101] = {};
```

The index represents the number, and the value represents its frequency.

### 1. Count every element

```cpp id="4l9q2m"
for (int num : nums) {
    count[num]++;
}
```

For:

```text
nums = [1,2,3,2]
```

the frequencies become:

```text
1 → 1
2 → 2
3 → 1
```

---

### 2. Add elements whose frequency is 1

We traverse the array again:

```cpp id="9b7z4p"
for (int num : nums) {
    if (count[num] == 1) {
        sum += num;
    }
}
```

Only elements appearing exactly once are added.

For:

```text
[1,2,3,2]
```

we get:

```text
1 → unique → add
2 → appears twice → skip
3 → unique → add
2 → appears twice → skip
```

Therefore:

```text
1 + 3 = 4
```

---

## Example

For:

```text
nums = [1,2,3,2]
```

Frequency table:

```text
1 → 1
2 → 2
3 → 1
```

Unique elements:

```text
1, 3
```

Sum:

```text
1 + 3 = 4
```

Therefore, the answer is:

```text
4
```

---

## Complexity

**Time Complexity:** `O(n)`

We traverse the array twice, which is still `O(n)`.

**Space Complexity:** `O(1)`

The frequency array always contains `101` positions, which is constant space because the value range is fixed from `1` to `100`.

---

## Key Takeaway

When the possible values have a small fixed range, a **frequency array** is a simple way to count occurrences.

The main pattern is:

```text
1. Count the frequency of every element.
2. Add elements whose frequency is exactly 1.
```
