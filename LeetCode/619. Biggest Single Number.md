# 619. Biggest Single Number

**Problem Name:** Biggest Single Number
**Difficulty:** Easy

---

## Question

A **single number** is a number that appears exactly once in the `MyNumbers` table.

We need to find the **largest** number among all single numbers.

If there are no single numbers, `MAX()` should return `NULL`.

---

## My Solution

```sql
SELECT MAX(num) AS num
FROM (
    SELECT num
    FROM MyNumbers
    GROUP BY num
    HAVING COUNT(*) = 1
) AS single_numbers;
```

---

## Approach

Your solution is **correct**.

It uses two steps:

1. Find numbers that appear exactly once.
2. Find the maximum among those numbers.

---

### 1. GROUP BY

```sql
SELECT num
FROM MyNumbers
GROUP BY num
```

`GROUP BY num` creates one group for each different number.

For example:

```text
8
8
3
3
1
4
5
6
```

becomes groups:

```text
8 → 2 occurrences
3 → 2 occurrences
1 → 1 occurrence
4 → 1 occurrence
5 → 1 occurrence
6 → 1 occurrence
```

---

### 2. HAVING COUNT(*) = 1

```sql
HAVING COUNT(*) = 1
```

`COUNT(*)` counts how many times each number appears.

We only keep numbers that appear exactly once.

So:

```text
1
4
5
6
```

remain.

`HAVING` is used instead of `WHERE` because we are filtering **groups after aggregation**.

---

### 3. Use MAX()

The subquery produces:

```text
1
4
5
6
```

Then the outer query:

```sql
SELECT MAX(num) AS num
```

finds the largest one:

```text
6
```

---

### 4. Why does it return NULL when there are no single numbers?

Suppose every number appears multiple times.

The subquery returns no rows.

Then:

```sql
MAX(num)
```

over an empty result returns:

```text
NULL
```

So no additional `COALESCE()` or special condition is required.

---

## Example

For:

```text
8
8
3
3
1
4
5
6
```

After:

```sql
GROUP BY num
HAVING COUNT(*) = 1
```

we get:

```text
1
4
5
6
```

Then:

```sql
MAX(num)
```

returns:

```text
6
```

For:

```text
8
8
7
7
3
3
3
```

there are no numbers appearing exactly once.

Therefore:

```text
MAX(empty result) = NULL
```

---

## Complexity

**Time Complexity:** `O(n)`

The database needs to group the rows and count their occurrences. Actual performance depends on indexes and the database engine.

**Space Complexity:** `O(k)`

The grouping operation may require storage for the distinct numbers, where `k` is the number of distinct values.

---

## Key Takeaway

The important SQL pattern is:

```sql
GROUP BY num
HAVING COUNT(*) = 1
```

to find values that appear exactly once.

Then use:

```sql
MAX(num)
```

to find the largest one.

The complete pattern is:

```text
GROUP BY
   ↓
HAVING COUNT(*) = 1
   ↓
MAX()
```

This also automatically returns `NULL` when no single number exists.
