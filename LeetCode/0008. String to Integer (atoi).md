# 0008. String to Integer (atoi)

**Problem Name:** String to Integer (atoi)  
**Difficulty:** Medium

---

## Question

Implement the `myAtoi(string s)` function that converts a string into a 32-bit signed integer.

The function should:

- Ignore leading spaces.
- Read an optional `+` or `-` sign.
- Read consecutive digits.
- Stop when a non-digit character is found.
- Return `INT_MAX` or `INT_MIN` if the number exceeds the 32-bit signed integer range.

---

## My Solution

```cpp
class Solution {
public:
    int myAtoi(string s) {

        int i = 0;
        int n = s.size();

        while (i < n && s[i] == ' ') {
            i++;
        }

        int sign = 1;

        if (i < n && (s[i] == '+' || s[i] == '-')) {

            if (s[i] == '-') {
                sign = -1;
            }

            i++;
        }

        long long num = 0;

        while (i < n && isdigit(s[i])) {

            num = num * 10 + (s[i] - '0');

            if (sign * num <= INT_MIN) {
                return INT_MIN;
            }

            if (sign * num >= INT_MAX) {
                return INT_MAX;
            }

            i++;
        }

        return sign * num;
    }
};
```
