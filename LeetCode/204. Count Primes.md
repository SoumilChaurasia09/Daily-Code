# 204. Count Primes

**Problem Name:** Count Primes
**Difficulty:** Medium

---

## Question

Given an integer `n`, return the number of prime numbers that are strictly less than `n`.

For example:

```text
n = 10
```

The prime numbers less than `10` are:

```text
2, 3, 5, 7
```

So the answer is `4`.

---

## My Solution

```cpp
class Solution {
public:
    int countPrimes(int n) {
        if (n <= 2)
            return 0;

        vector<bool> isPrime(n, true);

        isPrime[0] = false;
        isPrime[1] = false;

        // 2 is the only even prime
        int count = 1;

        // Only consider odd numbers
        for (int i = 3; i * i < n; i += 2) {

            if (isPrime[i]) {

                // Only mark odd multiples
                for (int j = i * i; j < n; j += 2 * i) {
                    isPrime[j] = false;
                }
            }
        }

        // Count remaining odd primes
        for (int i = 3; i < n; i += 2) {
            if (isPrime[i])
                count++;
        }

        return count;
    }
};
```

---

## Approach

This solution uses the **Sieve of Eratosthenes**, with an optimization that skips even numbers.

### 1. Handle small values

If `n <= 2`, there are no prime numbers strictly less than `n`.

```cpp
if (n <= 2)
    return 0;
```

### 2. Create the prime array

Initially, assume every number is prime:

```cpp
vector<bool> isPrime(n, true);
```

But `0` and `1` are not prime:

```cpp
isPrime[0] = false;
isPrime[1] = false;
```

### 3. Count `2` separately

`2` is the only even prime number.

So we start with:

```cpp
int count = 1;
```

### 4. Check only odd numbers

We start from `3` and increase by `2`:

```cpp
for (int i = 3; i * i < n; i += 2)
```

This skips all even numbers because they cannot be prime.

### 5. Mark only odd multiples

If `i` is prime, mark its odd multiples as non-prime:

```cpp
for (int j = i * i; j < n; j += 2 * i)
```

For example, when `i = 3`:

```text
9, 15, 21, 27, 33, ...
```

are marked as non-prime.

We use `2 * i` instead of `i` so that we skip even multiples.

### 6. Count the remaining odd primes

Finally, check only odd numbers:

```cpp
for (int i = 3; i < n; i += 2)
```

If `isPrime[i]` is still `true`, it is a prime number.

---

## Complexity

**Time Complexity:** `O(n log log n)`

**Space Complexity:** `O(n)`

---

## Key Takeaway

The important optimization is to **ignore even numbers**.

Since `2` is the only even prime:

```text
2 → handle separately
3, 5, 7, 9, 11, ... → check
```

When marking multiples, use:

```cpp
j += 2 * i;
```

so only odd multiples are processed.

This reduces the amount of work compared with the basic Sieve of Eratosthenes.
