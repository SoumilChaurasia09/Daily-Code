# 279. Perfect Squares

**Problem Name:** Perfect Squares
**Difficulty:** Medium

---

## Question

Given an integer `n`, find the minimum number of perfect square numbers that add up to `n`.

For example:

```text id="f8v7m2"
n = 12
```

We can write:

```text id="y5o8lq"
12 = 4 + 4 + 4
```

So the answer is `3`.

---

## My Solution

```cpp id="5xj2m4"
class Solution {
public:
    int numSquares(int n) {
        vector<int> dp(n + 1, n + 1);
        dp[0] = 0;

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j * j <= i; j++) {
                dp[i] = min(dp[i], dp[i - j * j] + 1);
            }
        }

        return dp[n];
    }
};
```

---

## Approach

Use **Dynamic Programming**.

Let:

```text
dp[i] = minimum number of perfect squares needed to make i
```

Initially, we set every value to a large number:

```cpp id="5r9o2x"
vector<int> dp(n + 1, n + 1);
```

We know:

```text id="0b3q5e"
dp[0] = 0
```

because we need zero numbers to make `0`.

For every `i`, try every perfect square that is less than or equal to `i`.

For example, for `i = 12`, we can try:

```text id="4uj7f3"
1, 4, 9
```

If we choose `4`, then we need to make:

```text id="z8j1pq"
12 - 4 = 8
```

So:

```cpp id="c0qj5y"
dp[12] = min(dp[12], dp[8] + 1);
```

The `+1` represents the square we just selected.

The transition is:

```text id="l8k8fv"
dp[i] = min(dp[i], dp[i - square] + 1)
```

For `12`, the minimum is:

```text id="v0qg0a"
12 = 4 + 4 + 4
```

Therefore:

```text id="q4j6w8"
dp[12] = 3
```

---

## Complexity

**Time Complexity:** `O(n√n)`

For every number from `1` to `n`, we try perfect squares up to that number.

**Space Complexity:** `O(n)`

The `dp` array contains `n + 1` values.

---

## Key Takeaway

This is a **Dynamic Programming** problem.

The main formula to remember is:

```cpp id="2x1y9e"
dp[i] = min(dp[i], dp[i - j * j] + 1);
```

Think of it as:

```text id="u3gq0q"
Current number
      ↓
Choose a perfect square
      ↓
Solve the remaining number
      ↓
Take the minimum
```
