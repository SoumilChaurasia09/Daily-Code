# 167. Two Sum II - Input Array Is Sorted

**Problem Name:** Two Sum II - Input Array Is Sorted
**Difficulty:** Medium

---

## Question

You are given a **1-indexed sorted array** `numbers` and a `target`.

Find two different elements whose sum is equal to `target`.

Return their **1-based indices**.

The array is already sorted, so we can use the **two-pointer** technique and only use constant extra space.

---

## My Solution

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& numbers, int target) {
        int left = 0;
        int right = numbers.size() - 1;

        while (left < right) {
            int sum = numbers[left] + numbers[right];

            if (sum == target) {
                return {left + 1, right + 1};
            }
            else if (sum < target) {
                left++;
            }
            else {
                right--;
            }
        }

        return {};
    }
};
```

---

## Approach

Because the array is sorted, we can use two pointers:

* `left` starts at the beginning.
* `right` starts at the end.

```cpp
int left = 0;
int right = numbers.size() - 1;
```

Calculate their sum:

```cpp
int sum = numbers[left] + numbers[right];
```

### Case 1: Sum equals target

```cpp
if (sum == target)
```

We found the required pair.

The problem uses **1-based indexing**, while C++ vectors use **0-based indexing**, so we return:

```cpp
return {left + 1, right + 1};
```

---

### Case 2: Sum is smaller than target

```cpp
else if (sum < target) {
    left++;
}
```

Since the array is sorted, increasing `left` gives us a larger number.

Therefore, the sum can increase.

---

### Case 3: Sum is greater than target

```cpp
else {
    right--;
}
```

Since the array is sorted, decreasing `right` gives us a smaller number.

Therefore, the sum can decrease.

---

## Example

Consider:

```text
numbers = [2, 7, 11, 15]
target = 9
```

Initially:

```text
left = 2
right = 15
```

Sum:

```text
2 + 15 = 17
```

Since `17 > 9`, move `right` left.

Now:

```text
2 + 11 = 13
```

Again:

```text
13 > 9
```

Move `right` left again.

Now:

```text
2 + 7 = 9
```

The target is found.

The C++ indices are:

```text
left = 0
right = 1
```

But the problem requires 1-based indices:

```text
[1, 2]
```

---

## Complexity

**Time Complexity:** `O(n)`

Each pointer moves toward the other pointer at most `n` times.

**Space Complexity:** `O(1)`

Only two integer variables are used, excluding the returned result.

---

## Key Takeaway

When an array is **sorted** and you need to find two values satisfying a sum condition, consider the **two-pointer technique**.

The main rule is:

```text
sum < target → move left forward
sum > target → move right backward
sum == target → answer found
```

This reduces the usual two-sum search from `O(n²)` to `O(n)` while using constant extra space.
