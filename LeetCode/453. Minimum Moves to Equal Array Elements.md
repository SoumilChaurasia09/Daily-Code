# 453. Minimum Moves to Equal Array Elements

**Problem Name:** Minimum Moves to Equal Array Elements
**Difficulty:** Medium

---

## Question

We are given an integer array `nums`.

In one move, we can increment `n - 1` elements by `1`, where `n` is the size of the array.

We need to find the minimum number of moves required to make all array elements equal.

---

## My Solution

```cpp
class Solution {
public:
    int minMoves(vector<int>& nums) {
        int minElement = *min_element(nums.begin(), nums.end());

        int moves = 0;

        for (int num : nums) {
            moves += num - minElement;
        }

        return moves;
    }
};
```

---

## Approach

### Step 1: Find the minimum element

```cpp
int minElement = *min_element(nums.begin(), nums.end());
```

We find the smallest element in the array.

### Step 2: Understand the mathematical logic

In every move, we increment `n - 1` elements.

Instead of incrementing `n - 1` elements, we can think of it as **decrementing the remaining one element by 1**.

Both operations have the same effect on the difference between array elements.

Therefore, the minimum number of moves required is:

```text
moves = sum of (each element - minimum element)
```

### Step 3: Calculate the moves

```cpp
for (int num : nums) {
    moves += num - minElement;
}
```

For every element, calculate how much larger it is than the minimum element.

Add all these differences to get the answer.

### Step 4: Return the answer

```cpp
return moves;
```

---

## Example

**Input:**

```text
nums = [1, 2, 3]
```

### Step 1: Find the minimum element

```text
minElement = 1
```

### Step 2: Calculate differences

| Element | Difference |
| ------- | ---------- |
| 1       | 1 - 1 = 0  |
| 2       | 2 - 1 = 1  |
| 3       | 3 - 1 = 2  |

### Step 3: Calculate total moves

```text
moves = 0 + 1 + 2
      = 3
```

**Output:**

```text
3
```

### Another Example

**Input:**

```text
nums = [1, 1, 1]
```

Minimum element:

```text
minElement = 1
```

Total moves:

```text
(1 - 1) + (1 - 1) + (1 - 1) = 0
```

**Output:**

```text
0
```

---

## Complexity

**Time Complexity:** `O(n)`

* Finding the minimum element takes `O(n)`.
* Calculating the total differences takes `O(n)`.

Therefore, overall time complexity is `O(n)`.

**Space Complexity:** `O(1)`

We use only a few variables and do not create any additional data structure.

---

## Key Takeaway

The important concept is **mathematical optimization**.

Instead of actually performing every increment operation, we reverse the operation mentally:

* Incrementing `n - 1` elements by 1.
* Is equivalent to decrementing the remaining element by 1.

Therefore, the formula is:

```text
Minimum Moves = Sum(nums[i] - minimum element)
```

**Remember:** Finding a mathematical relationship can eliminate unnecessary simulations and make a solution much faster.
