# 202. Happy Number

**Problem Name:** Happy Number
**Difficulty:** Easy

---

## Question

A happy number is a number where we repeatedly replace the number with the sum of the squares of its digits.

If the process eventually reaches `1`, the number is happy.

If the process enters a cycle that does not contain `1`, the number is not happy.

For example:

```text
19 → 82 → 68 → 100 → 1
```

Therefore, `19` is a happy number.

---

## My Solution

```cpp
class Solution {
public:
    int sumSquare(int n) {
        int sum = 0;

        while (n > 0) {
            int digit = n % 10;
            sum += digit * digit;
            n /= 10;
        }

        return sum;
    }

    bool isHappy(int n) {
        while (n != 1 && n != 4) {
            n = sumSquare(n);
        }

        return n == 1;
    }
};
```

---

## Approach

Create a helper function `sumSquare()` that calculates the sum of the squares of all digits.

For example:

```text
82
↓
8² + 2²
↓
64 + 4
↓
68
```

Then repeatedly call this function.

There are two possible outcomes:

* We reach `1` → happy number.
* We reach `4` → the sequence enters the known cycle → not happy.

The cycle is:

```text
4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4
```

So we can stop when `n` becomes either `1` or `4`.

---

## Complexity

**Time Complexity:** `O(log n)` approximately.

**Space Complexity:** `O(1)`.

---

## Key Takeaway

The important tricks to remember are:

### Extract a digit

```cpp
int digit = n % 10;
```

### Remove the last digit

```cpp
n /= 10;
```

### Square the digit

```cpp
digit * digit
```

Also remember the special cycle:

```text
4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4
```

This allows us to solve the problem using **constant space** without storing all previously seen numbers.
