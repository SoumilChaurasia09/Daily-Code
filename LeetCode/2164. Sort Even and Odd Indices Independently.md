# 2164. Sort Even and Odd Indices Independently

**Problem Name:** Sort Even and Odd Indices Independently
**Difficulty:** Easy

---

## Question

Given an integer array `nums`, rearrange the values according to these rules:

* Values at **even indices** must be sorted in non-decreasing order.
* Values at **odd indices** must be sorted in non-increasing order.

For example:

```text
nums = [4,1,2,3]
```

Even index values:

```text
[4,2]
```

After sorting:

```text
[2,4]
```

Odd index values:

```text
[1,3]
```

After sorting in decreasing order:

```text
[3,1]
```

Final array:

```text
[2,3,4,1]
```

---

## My Solution

```cpp
class Solution {
public:
    vector<int> sortEvenOdd(vector<int>& nums) {

        vector<int> even;
        vector<int> odd;

        for (int i = 0; i < nums.size(); i++) {

            if (i % 2 == 0) {
                even.push_back(nums[i]);
            }
            else {
                odd.push_back(nums[i]);
            }
        }

        sort(even.begin(), even.end());
        sort(odd.begin(), odd.end(), greater<int>());

        int e = 0;
        int o = 0;

        for (int i = 0; i < nums.size(); i++) {

            if (i % 2 == 0) {
                nums[i] = even[e];
                e++;
            }
            else {
                nums[i] = odd[o];
                o++;
            }
        }

        return nums;
    }
};
```

## What I Learned

This problem helped me practice **separating elements based on their index**.

I created two arrays:

```cpp
even
odd
```

The `even` array stores values from even indices, while the `odd` array stores values from odd indices.

Then I sorted them differently:

```cpp
sort(even.begin(), even.end());
```

for ascending order, and:

```cpp
sort(odd.begin(), odd.end(), greater<int>());
```

for descending order.

Finally, I placed the sorted values back into their respective even and odd positions.

---

## Personal Notes

The main thing I learned from this problem is that we are sorting the **values based on their positions**, not simply sorting the entire array.

If I sorted the complete array, the required relationship between even and odd indices would be lost.

Separating the two groups first made the problem much easier to understand and implement.
