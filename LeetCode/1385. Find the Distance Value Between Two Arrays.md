# 1385. Find the Distance Value Between Two Arrays

**Difficulty:** Easy

## Question

Given two integer arrays `arr1` and `arr2`, and an integer `d`, count the elements in `arr1` that have an absolute difference greater than `d` from every element in `arr2`.

## My Solution

I used two nested loops to compare every element of `arr1` with every element of `arr2`.

If any difference is less than or equal to `d`, that element is not counted.

Otherwise, increment the count.

## Approach

1. Initialize `count = 0`.
2. Traverse each element of `arr1`.
3. Assume the current element is valid.
4. Compare it with every element of `arr2`.
5. If `abs(arr1[i] - arr2[j]) <= d`, mark it invalid and break the inner loop.
6. If the element is still valid, increment `count`.
7. Return `count`.

## Example

**Input:**

```text
arr1 = [4,5,8]
arr2 = [10,9,1,8]
d = 2
```

**Output:**

```text
2
```

**Explanation:**

* `4` has a difference greater than 2 from every element in `arr2`.
* `5` also has a difference greater than 2 from every element in `arr2`.
* `8` has differences less than or equal to 2 with some elements.

Therefore, the answer is `2`.

## Complexity Analysis

* **Time Complexity:** O(n × m) – Each element of `arr1` is compared with every element of `arr2` in the worst case.
* **Space Complexity:** O(1) – Only a few extra variables are used.
