# 1280. Students and Examinations

**Problem Name:** Students and Examinations
**Difficulty:** Easy

---

## Question

Find how many times each student attended each subject's exam.

The result must contain **every student and every subject**, even if the student attended the exam `0` times.

---

## My Solution

```sql
SELECT 
    s.student_id,
    s.student_name,
    sub.subject_name,
    COUNT(e.subject_name) AS attended_exams
FROM Students s
CROSS JOIN Subjects sub
LEFT JOIN Examinations e
    ON s.student_id = e.student_id
    AND sub.subject_name = e.subject_name
GROUP BY 
    s.student_id,
    s.student_name,
    sub.subject_name
ORDER BY 
    s.student_id,
    sub.subject_name;
```

---

## Approach

There are three important steps.

### 1. Create every student-subject combination

We use:

```sql
CROSS JOIN Subjects sub
```

This creates every possible combination of students and subjects.

For example:

```text
Alice + Math
Alice + Physics
Alice + Programming

Bob + Math
Bob + Physics
Bob + Programming
```

This is important because even students who attended an exam `0` times must appear.

---

### 2. Match the examinations

We use `LEFT JOIN`:

```sql
LEFT JOIN Examinations e
    ON s.student_id = e.student_id
    AND sub.subject_name = e.subject_name
```

This matches an exam when both:

```text
student_id matches
AND
subject_name matches
```

If no exam exists, the student-subject combination is still kept because we used `LEFT JOIN`.

---

### 3. Count the exams

We use:

```sql
COUNT(e.subject_name)
```

If a student attended the exam multiple times, each row is counted.

For Alice and Math:

```text
Math
Math
Math
```

So:

```text
attended_exams = 3
```

If Bob never attended Physics:

```text
e.subject_name = NULL
```

`COUNT(e.subject_name)` ignores `NULL`, giving:

```text
0
```

---

## Why `CROSS JOIN`?

The problem requires **all students × all subjects**.

If there are:

```text
4 students
3 subjects
```

we need:

```text
4 × 3 = 12
```

student-subject combinations.

`CROSS JOIN` creates exactly these combinations.

---

## Why `COUNT(e.subject_name)` Instead of `COUNT(*)`?

This is important.

With `LEFT JOIN`, a student-subject combination with no exam still produces one row, but the examination columns are `NULL`.

If we used:

```sql
COUNT(*)
```

that row would be counted as `1`.

Instead:

```sql
COUNT(e.subject_name)
```

does not count `NULL`.

Therefore:

```text
No exam → 0
One exam → 1
Multiple exams → actual count
```

---

## Example

For Alice:

```text
Math         → 3
Physics      → 2
Programming  → 1
```

For Bob:

```text
Math         → 1
Physics      → 0
Programming  → 1
```

For Alex:

```text
Math         → 0
Physics      → 0
Programming  → 0
```

---

## Complexity

**Time Complexity:** `O(S × U + E)`

Where:

* `S` = number of students
* `U` = number of subjects
* `E` = number of examination records

**Space Complexity:** Depends on the database execution plan and intermediate result size.

---

## Key Takeaway

For problems asking for **every combination**, even when no matching record exists:

```text
CROSS JOIN
    ↓
Create all combinations
    ↓
LEFT JOIN
    ↓
Keep combinations with no records
    ↓
COUNT(column)
    ↓
Get 0 for missing records
```

The key pattern is:

```sql
CROSS JOIN
LEFT JOIN
GROUP BY
COUNT(column)
```
