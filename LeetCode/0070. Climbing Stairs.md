# 0070. Climbing Stairs

**Problem Name:** Climbing Stairs  
**Difficulty:** Easy

---

## Question

You are climbing a staircase with `n` steps.

Each time, you can climb either:

- `1` step
- `2` steps

Return the total number of distinct ways to reach the top.

---

## My Solution

```cpp
class Solution {
public:
    int climbStairs(int n) {

        if (n <= 2) {
            return n;
        }

        int first = 1;
        int second = 2;

        for (int i = 3; i <= n; i++) {

            int current = first + second;
            first = second;
            second = current;
        }

        return second;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(n)` |
| **Space Complexity** | `O(1)` |

---

## What I Learned

This problem introduced me to **Dynamic Programming**.

I observed that the number of ways to reach the current step is the sum of the ways to reach the previous two steps.

```text
ways(n) = ways(n-1) + ways(n-2)
```

Instead of storing all previous values, I only kept the last two answers, which reduced the space complexity to `O(1)`.

---

## Personal Notes

Initially, I thought about solving this problem using recursion because the pattern was easy to see. However, the recursive solution performs many repeated calculations and becomes slow for larger values of `n`.

Using an iterative Dynamic Programming approach made the solution much faster and more memory efficient. This problem also helped me recognize that many DP problems follow a pattern similar to the Fibonacci sequence.
