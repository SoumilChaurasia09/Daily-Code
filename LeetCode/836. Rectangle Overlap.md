# 836. Rectangle Overlap

**Problem Name:** Rectangle Overlap
**Difficulty:** Easy

---

## Question

Given two axis-aligned rectangles, determine whether they overlap with a **positive area**.

Rectangles that only touch at an edge or corner do not count as overlapping.

---

## My Solution

```cpp
class Solution {
public:
    bool isRectangleOverlap(vector<int>& rec1, vector<int>& rec2) {
        return rec1[0] < rec2[2] &&
               rec2[0] < rec1[2] &&
               rec1[1] < rec2[3] &&
               rec2[1] < rec1[3];
    }
};
```

---

## Approach

A rectangle is represented as:

```text
[x1, y1, x2, y2]
```

where:

```text
(x1, y1) → bottom-left
(x2, y2) → top-right
```

For two rectangles to have a positive-area intersection, their projections must overlap on **both the X-axis and Y-axis**.

### X-axis overlap

```cpp
rec1[0] < rec2[2]
rec2[0] < rec1[2]
```

This means the horizontal ranges overlap.

### Y-axis overlap

```cpp
rec1[1] < rec2[3]
rec2[1] < rec1[3]
```

This means the vertical ranges overlap.

All four conditions must be true.

---

## Why Use `<` Instead of `<=`?

Consider:

```text
rec1 = [0,0,1,1]
rec2 = [1,0,2,1]
```

The rectangles touch at the edge `x = 1`.

There is no positive-area overlap.

Because we use:

```cpp
rec1[2] > rec2[0]
```

which becomes:

```text
1 > 1
```

This is false, so the answer is `false`.

---

## Example

```text
rec1 = [0,0,2,2]
rec2 = [1,1,3,3]
```

X ranges:

```text
rec1: 0 → 2
rec2: 1 → 3
```

They overlap.

Y ranges:

```text
rec1: 0 → 2
rec2: 1 → 3
```

They also overlap.

Therefore:

```text
true
```

---

## Complexity

**Time Complexity:** `O(1)`

**Space Complexity:** `O(1)`

---

## Key Takeaway

For axis-aligned rectangles, check whether their ranges overlap on **both axes**:

```text
X overlap + Y overlap = Rectangle overlap
```

If they only touch an edge or corner, the overlap area is zero, so the answer is `false`.
