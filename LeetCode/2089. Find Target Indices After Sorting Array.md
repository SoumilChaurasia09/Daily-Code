# 2089. Find Target Indices After Sorting Array

**Problem Name:** Find Target Indices After Sorting Array  
**Difficulty:** Easy

---

## Question

Given an integer array `nums` and a `target`, sort the array in non-decreasing order.

Then find all the indices where:

```text
nums[i] == target
```

Return those indices in increasing order.

---

## My Solution

```cpp
class Solution {
public:
    vector<int> targetIndices(vector<int>& nums, int target) {

        sort(nums.begin(), nums.end());

        vector<int> ans;

        for (int i = 0; i < nums.size(); i++) {

            if (nums[i] == target) {
                ans.push_back(i);
            }
        }

        return ans;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(n log n)` |
| **Space Complexity** | `O(n)` |

```cpp
sort(nums.begin(), nums.end());
```

After sorting, I traversed the array and checked whether each element was equal to `target`.

Whenever I found the target, I stored its index in the answer array.

## Personal Notes

The important part of this problem is that the indices have to be found **after sorting** the array.

For example:

```text
nums = [1,2,5,2,3]
target = 2
```

After sorting:

```text
[1,2,2,3,5]
```

The target `2` is present at indices:

```text
[1,2]
```

This problem reinforced my understanding of sorting and array traversal.
