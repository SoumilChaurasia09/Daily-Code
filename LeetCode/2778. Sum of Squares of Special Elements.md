# 2778. Sum of Squares of Special Elements

**Problem Name:** Sum of Squares of Special Elements
**Difficulty:** Easy

---

## Question

An element `nums[i]` is special if its **1-based index divides the array length `n`**.

Return the sum of the squares of all special elements.

---

## My Solution

```cpp
class Solution {
public:
    int sumOfSquares(vector<int>& nums) {
        int n = nums.size();
        int sum = 0;

        for (int i = 1; i <= n; i++) {
            if (n % i == 0) {
                sum += nums[i - 1] * nums[i - 1];
            }
        }

        return sum;
    }
};
```

---

## Approach

1. Find the array length using `nums.size()` and store it in `n`.
2. Loop through the indices from `1` to `n`.
3. Check whether `n % i == 0`.

   * If true, the index is special.
   * Add the square of `nums[i - 1]` to `sum`.
4. Return `sum`.

**Why use `nums[i - 1]`?**

The problem uses 1-based indexing, but C++ vectors use 0-based indexing. Therefore, index `i` corresponds to `nums[i - 1]`.

---

## Example

**Input:**

```text
nums = [1, 2, 3, 4]
```

Array length: `n = 4`

Special indices: `1`, `2`, and `4`, because each divides `4`.

Calculation:

`1² + 2² + 4² = 1 + 4 + 16 = 21`

**Output:**

```text
21
```

---

## Complexity

**Time Complexity:** `O(n)` — We check every index once.

**Space Complexity:** `O(1)` — We use only a few variables.

---

## Key Takeaway

Use the modulo operator `%` to check divisibility. If `n % i == 0`, add the square of the element at that 1-based index.
