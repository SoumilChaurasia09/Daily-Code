# 3727. Maximum Alternating Sum of Squares

**Problem Name:** Maximum Alternating Sum of Squares
**Difficulty:** Medium

---

## Question

You are given an integer array `nums`. You can rearrange its elements in any order.

The alternating score is calculated as:

`score = arr[0]² - arr[1]² + arr[2]² - arr[3]² + ...`

Return the maximum possible alternating score after rearranging the array.

---

## My Solution

```cpp
class Solution {
public:
    long long maxAlternatingSum(vector<int>& nums) {
        vector<long long> squares;

        for (int num : nums) {
            long long x = num;
            squares.push_back(x * x);
        }

        sort(squares.begin(), squares.end());

        int n = squares.size();
        long long sum = 0;

        for (int i = 0; i < n; i++) {
            if (i < n / 2) {
                sum -= squares[i];
            }
            else {
                sum += squares[i];
            }
        }

        return sum;
    }
};
```

---

## Approach

### 1. Calculate the squares

Create a vector called `squares` to store the square of every element.

For each number:

`square = num * num`

We use `long long` to safely store the squared values.

### 2. Sort the squared values

Sort `squares` in ascending order.

For example:

`nums = [1, -1, 2, -2, 3, -3]`

After squaring and sorting:

`squares = [1, 1, 4, 4, 9, 9]`

### 3. Calculate the maximum score

To maximize the score:

* Subtract the smallest `n / 2` squared values.
* Add all remaining squared values.
