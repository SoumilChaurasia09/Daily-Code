# 292. Nim Game

**Problem Name:** Nim Game
**Difficulty:** Easy

---

## Question

There is a pile of `n` stones.

On each turn, a player can remove:

* 1 stone
* 2 stones
* 3 stones

The player who removes the last stone wins.

Return `true` if you can win when both players play optimally.

---

## My Solution

```cpp
class Solution {
public:
    bool canWinNim(int n) {
        return n % 4 != 0;
    }
};
```

---

## Approach

The key observation is that every multiple of `4` is a losing position.

For example:

```text
n = 4
```

Whatever we remove:

```text
4 - 1 = 3
4 - 2 = 2
4 - 3 = 1
```

The opponent can always remove the remaining stones and win.

The same pattern continues:

```text
4, 8, 12, 16, 20, ...
```

So:

```text
n % 4 == 0 → false
n % 4 != 0 → true
```

---

## Complexity

**Time Complexity:** `O(1)`

**Space Complexity:** `O(1)`

---

## Key Takeaway

Remember the pattern:

```text
Multiple of 4 → Losing position
Not a multiple of 4 → Winning position
```

Therefore:

```cpp
return n % 4 != 0;
```
