# 1710. Maximum Units on a Truck

**Problem Name:** Maximum Units on a Truck
**Difficulty:** Easy

---

## Question

We are given different types of boxes.

Each box type contains:

```text
[number of boxes, units per box]
```

The truck can hold at most `truckSize` boxes.

We need to choose boxes so that the **total number of units is maximum**.

---

## My Solution

```cpp id="n7c2wx"
class Solution {
public:
    int maximumUnits(vector<vector<int>>& boxTypes, int truckSize) {
        sort(boxTypes.begin(), boxTypes.end(), [](vector<int>& a, vector<int>& b) {
            return a[1] > b[1];
        });

        int units = 0;

        for (auto& box : boxTypes) {
            int boxes = min(truckSize, box[0]);

            units += boxes * box[1];
            truckSize -= boxes;

            if (truckSize == 0) {
                break;
            }
        }

        return units;
    }
};
```

---

## Approach

This problem uses a **Greedy** approach.

The goal is to maximize units while having a limited number of boxes.

Therefore, we should always take boxes that contain the **most units per box first**.

### 1. Sort by units per box

```cpp id="n2g5j8"
sort(boxTypes.begin(), boxTypes.end(), [](vector<int>& a, vector<int>& b) {
    return a[1] > b[1];
});
```

We sort the box types in descending order of `units per box`.

For example:

```text id="5m7g1s"
[1,3]
[2,2]
[3,1]
```

is already ordered as:

```text id="5s3v2q"
3 units/box
2 units/box
1 unit/box
```

---

### 2. Take as many boxes as possible

For each box type:

```cpp id="3nq8a5"
int boxes = min(truckSize, box[0]);
```

We can take either:

* All available boxes of that type, or
* Whatever number of spaces are left on the truck.

Then add their units:

```cpp id="4q2j9d"
units += boxes * box[1];
```

---

### 3. Reduce available truck space

```cpp id="y7k5x1"
truckSize -= boxes;
```

After taking the boxes, we reduce the remaining capacity.

If the truck is full:

```cpp id="v5p3r8"
if (truckSize == 0) {
    break;
}
```

we stop.

---

## Example

Consider:

```text id="g8k3q2"
boxTypes = [[1,3],[2,2],[3,1]]
truckSize = 4
```

The types are sorted by units per box:

```text id="c2y5vw"
[1,3]
[2,2]
[3,1]
```

### Take type 1

There is 1 box with 3 units:

```text id="n8d6s4"
1 × 3 = 3
```

Remaining truck space:

```text id="x7k9q1"
4 - 1 = 3
```

### Take type 2

There are 2 boxes with 2 units each:

```text id="q4m8ty"
2 × 2 = 4
```

Total:

```text id="b3n6p2"
3 + 4 = 7
```

Remaining space:

```text id="j5v8kc"
3 - 2 = 1
```

### Take type 3

There are 3 available boxes, but only 1 space remains.

So take 1 box:

```text id="d2q7hx"
1 × 1 = 1
```

Final total:

```text id="r6w4zn"
3 + 4 + 1 = 8
```

Answer:

```text id="f1m8ks"
8
```

---

## Complexity

**Time Complexity:** `O(n log n)`

We sort `n` box types, which takes `O(n log n)`. Then we traverse the array once.

**Space Complexity:** `O(log n)`

The sorting operation uses additional space depending on the sorting implementation.

---

## Key Takeaway

This is a **Greedy** problem.

When the truck has limited capacity and every box has a value in units, take the boxes with the **highest units per box first**.

The pattern is:

```text id="j3q8sx"
1. Sort by value in descending order.
2. Take as many high-value items as possible.
3. Continue until capacity is full.
```
