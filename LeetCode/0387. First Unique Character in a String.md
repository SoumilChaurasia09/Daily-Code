# 0387. First Unique Character in a String

**Problem Name:** First Unique Character in a String
**Difficulty:** Easy

---

## Question

Given a string `s`, find the **first character that appears only once** in the string.

Return its index.

If there is no unique character, return:

```text
-1
```

---

## My Solution

```cpp
class Solution {
public:
    int firstUniqChar(string s) {

        int freq[26] = {0};

        for (char ch : s) {
            freq[ch - 'a']++;
        }

        for (int i = 0; i < s.size(); i++) {

            if (freq[s[i] - 'a'] == 1) {
                return i;
            }
        }

        return -1;
    }
};
```

---

## Complexity

| Metric               | Value  |
| -------------------- | ------ |
| **Time Complexity**  | `O(n)` |
| **Space Complexity** | `O(1)` |

Since the string contains only lowercase English letters, the frequency array always has only `26` elements.

---

## What I Learned

This problem helped me understand how to use a **frequency array** to count characters.

First, I counted how many times every character appears:

```cpp
freq[ch - 'a']++;
```

Then I went through the string again from left to right.

If the frequency of a character was `1`, I immediately returned its index. This guarantees that I get the **first unique character**.

---

## Personal Notes

The important part was understanding:

```cpp
ch - 'a'
```

This converts a lowercase character into an index from `0` to `25`.

For example:

```text
'a' - 'a' = 0
'b' - 'a' = 1
'c' - 'a' = 2
```

Using an array instead of a hash map makes the solution simple and uses constant extra space because there are only 26 possible lowercase letters.
