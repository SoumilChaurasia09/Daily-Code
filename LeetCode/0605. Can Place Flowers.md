# 0605. Can Place Flowers

**Problem Name:** Can Place Flowers  
**Difficulty:** Easy

---

## Question

You are given a `flowerbed` represented by an array of `0`s and `1`s.

- `0` means the plot is empty.
- `1` means the plot already has a flower.
- Flowers cannot be planted in adjacent plots.

Given an integer `n`, return `true` if `n` new flowers can be planted without violating the rule. Otherwise, return `false`.

---

## My Solution

```cpp
class Solution {
public:
    bool canPlaceFlowers(vector<int>& flowerbed, int n) {

        if (n == 0) {
            return true;
        }

        for (int i = 0; i < flowerbed.size(); i++) {

            if (flowerbed[i] == 0 &&
                (i == 0 || flowerbed[i - 1] == 0) &&
                (i == flowerbed.size() - 1 || flowerbed[i + 1] == 0)) {

                flowerbed[i] = 1;
                n--;
            }

            if (n == 0) {
                return true;
            }
        }

        return false;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(n)` |
| **Space Complexity** | `O(1)` |

---

## What I Learned

This problem helped me practice **checking neighboring elements in an array**.

For every empty position, I check:

1. The current position is empty.
2. The left position is empty or does not exist.
3. The right position is empty or does not exist.

If all conditions are satisfied, I can safely place a flower there and decrease `n`.

I also learned the importance of handling **edge cases**. If `n == 0`, no flowers need to be planted, so the answer is immediately `true`.

---

## Personal Notes

Initially, my solution failed 2 test cases because I did not handle the `n = 0` case.

Even though the main logic was correct, when `n` was already `0`, the loop could finish without returning `true`.

Adding:

```cpp
if (n == 0) {
    return true;
}
```

fixed the edge case.

This reminded me to always check simple boundary conditions before implementing the main logic.
