# 680. Valid Palindrome II

**Problem Name:** Valid Palindrome II
**Difficulty:** Easy

---

## Question

Given a string `s`, determine whether it can become a palindrome after deleting **at most one character**.

A palindrome reads the same from left to right and right to left.

For example:

```text
"aba"
```

is already a palindrome.

For:

```text
"abca"
```

we can remove `c`:

```text
"aba"
```

so the answer is `true`.

---

## My Solution

```cpp
class Solution {
public:
    bool checkPalindrome(string& s, int left, int right) {
        while (left < right) {
            if (s[left] != s[right]) {
                return false;
            }

            left++;
            right--;
        }

        return true;
    }

    bool validPalindrome(string s) {
        int left = 0;
        int right = s.size() - 1;

        while (left < right) {
            if (s[left] != s[right]) {
                return checkPalindrome(s, left + 1, right) ||
                       checkPalindrome(s, left, right - 1);
            }

            left++;
            right--;
        }

        return true;
    }
};
```

---

## Approach

We use the **two-pointer technique**.

Start with:

```cpp
int left = 0;
int right = s.size() - 1;
```

`left` points to the first character and `right` points to the last character.

---

### 1. Compare characters

While:

```cpp
left < right
```

compare:

```cpp
s[left] == s[right]
```

If they are equal, move both pointers:

```cpp
left++;
right--;
```

---

### 2. Handle the first mismatch

Suppose:

```cpp
s[left] != s[right]
```

Since we are allowed to delete at most one character, there are only two possibilities.

Delete the character at `left`:

```cpp
checkPalindrome(s, left + 1, right)
```

or delete the character at `right`:

```cpp
checkPalindrome(s, left, right - 1)
```

If either remaining substring is a palindrome, the answer is `true`.

Therefore:

```cpp
return checkPalindrome(s, left + 1, right) ||
       checkPalindrome(s, left, right - 1);
```

---

### 3. Helper function

The helper function:

```cpp
checkPalindrome()
```

checks whether a section of the string is a normal palindrome.

If any characters do not match:

```cpp
if (s[left] != s[right]) {
    return false;
}
```

Otherwise, if all pairs match:

```cpp
return true;
```

---

## Example

Consider:

```text
s = "abca"
```

Start:

```text
a b c a
↑     ↑
L     R
```

`a == a`, so move both pointers:

```text
a b c a
  ↑ ↑
  L R
```

Now:

```text
b != c
```

We have two choices.

Delete `b`:

```text
"aca"
```

This is a palindrome.

Or delete `c`:

```text
"aba"
```

This is also a palindrome.

Since at least one choice works:

```text
true
```

---

### Example 2

For:

```text
s = "abc"
```

First comparison:

```text
a != c
```

Try deleting `a`:

```text
"bc"
```

Not a palindrome.

Try deleting `c`:

```text
"ab"
```

Not a palindrome.

Therefore:

```text
false
```

---

## Complexity

**Time Complexity:** `O(n)`

The main two-pointer loop processes the string once. At the first mismatch, at most two remaining substrings are checked, so the overall complexity remains `O(n)`.

**Space Complexity:** `O(1)`

Only pointer variables are used, and no new string needs to be created.

---

## Key Takeaway

For palindrome problems, the **two-pointer technique** is very useful:

```text
left → beginning
right → end
```

When the first mismatch occurs and only one deletion is allowed, try both possibilities:

```text
Skip left  → check [left + 1, right]
Skip right → check [left, right - 1]
```

If either remaining part is a palindrome, return `true`.
