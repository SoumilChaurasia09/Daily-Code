# 191. Number of 1 Bits

**Problem Name:** Number of 1 Bits
**Difficulty:** Easy

---

## Question

We are given a positive integer `n`.

We need to count the number of `1` bits in its binary representation.

The number of set bits is also called the **Hamming Weight**.

For example, the binary representation of `11` is `1011`, which contains three `1` bits.

---

## My Solution

```cpp
class Solution {
public:
    int hammingWeight(int n) {
        int count = 0;

        while (n > 0) {
            count += (n & 1);
            n = n >> 1;
        }

        return count;
    }
};
```

---

## Approach

### Step 1: Understand the AND operator

The bitwise AND operator `&` compares two binary numbers bit by bit.

```text
0 & 1 = 0
1 & 1 = 1
```

When we write:

```cpp
n & 1
```

It checks the last bit of `n`.

* If the last bit is `1`, the result is `1`.
* If the last bit is `0`, the result is `0`.

### Step 2: Count the set bits

```cpp
count += (n & 1);
```

If the last bit is `1`, increase the counter.

If it is `0`, the counter remains unchanged.

### Step 3: Right shift the number

```cpp
n = n >> 1;
```

The right shift operator moves all bits one position to the right.

This removes the last bit from consideration and allows us to check the next bit.

### Step 4: Repeat until zero

```cpp
while (n > 0)
```

Continue checking bits until all bits have been processed.

Finally, return the total count.

---

## Example

**Input:**

```text
n = 11
```

### Step 1: Convert to binary

```text
11 = 1011
```

### Step 2: Check each bit

| Number | Last Bit (`n & 1`) | Count |
| ------ | ------------------ | ----- |
| 1011   | 1                  | 1     |
| 101    | 1                  | 2     |
| 10     | 0                  | 2     |
| 1      | 1                  | 3     |

### Step 3: Return the answer

```text
Output = 3
```

---

## Complexity

**Time Complexity:** `O(log n)`

We process one binary bit in each iteration. An integer has approximately `log₂(n)` bits.

**Space Complexity:** `O(1)`

We use only a counter and a few variables.

---

## Key Takeaway

The main concept is **Bit Manipulation**.

Important operators:

| Operator | Meaning     |
| -------- | ----------- |
| `&`      | Bitwise AND |
| `\|`     | Bitwise OR  |
| `^`      | Bitwise XOR |
| `<<`     | Left shift  |
| `>>`     | Right shift |

### Alternative Optimization: Brian Kernighan's Algorithm

Instead of checking every bit, we can remove the rightmost set bit in every iteration.

```cpp
class Solution {
public:
    int hammingWeight(int n) {
        int count = 0;

        while (n != 0) {
            n = n & (n - 1);
            count++;
        }

        return count;
    }
};
```

**Important Formula:**

```cpp
n = n & (n - 1);
```

This operation removes the rightmost `1` bit.

For example:

```text
n     = 1011
n - 1 = 1010

1011 & 1010 = 1010
```

Each iteration removes exactly one set bit.

**Follow-up:** If the function is called many times, Brian Kernighan's algorithm is efficient because its time complexity is `O(k)`, where `k` is the number of set bits.
