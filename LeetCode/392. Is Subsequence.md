# 392. Is Subsequence

**Problem Name:** Is Subsequence
**Difficulty:** Easy

---

## Question

Given two strings `s` and `t`, check whether `s` is a subsequence of `t`.

A subsequence keeps the original order of characters, but some characters can be removed.

For example:

```text
s = "ace"
t = "abcde"
```

`"ace"` is a subsequence because `a`, `c`, and `e` appear in the same order.

But:

```text
"aec"
```

is not a subsequence because `e` appears after `c`.

---

## My Solution

```cpp
class Solution {
public:
    bool isSubsequence(string s, string t) {
        int i = 0;

        for (int j = 0; j < t.length(); j++) {
            if (i < s.length() && s[i] == t[j]) {
                i++;
            }
        }

        return i == s.length();
    }
};
```

---

## Approach

Use two pointers:

* `i` points to the current character of `s`.
* `j` moves through `t`.

If:

```cpp
s[i] == t[j]
```

we found the required character, so move `i` forward.

If they are different, only `j` moves forward because the current character of `t` can simply be skipped.

At the end:

```cpp
return i == s.length();
```

If `i` reached the end of `s`, all characters were found in the correct order.

---

## Complexity

**Time Complexity:** `O(n)`, where `n` is the length of `t`.

**Space Complexity:** `O(1)`.

---

## Key Takeaway

This is a classic **two-pointer** problem.

Remember:

```text
Move through t
    ↓
If characters match
    ↓
Move pointer of s
```

The important idea is that we **never move backward**.

```text
s = "abc"
t = "ahbgdc"

a ✓
h → skip
b ✓
g → skip
d → skip
c ✓

Result = true
```
