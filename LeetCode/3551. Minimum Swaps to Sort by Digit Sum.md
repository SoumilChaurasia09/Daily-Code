# 3551. Minimum Swaps to Sort by Digit Sum

**Problem Name:** Minimum Swaps to Sort by Digit Sum
**Difficulty:** Medium

---

## Question

Given an array of distinct positive integers, sort it by these rules:

1. Numbers with smaller digit sums come first.
2. If two numbers have the same digit sum, the smaller number comes first.

Return the minimum number of swaps needed to rearrange the array into this order.

---

## My Solution

```cpp
class Solution {
public:
    int minSwaps(vector<int>& nums) {
        int n = nums.size();
        vector<pair<int, int>> arr;

        for (int i = 0; i < n; i++) {
            int num = nums[i];
            int sum = 0;

            while (num > 0) {
                sum += num % 10;
                num /= 10;
            }

            arr.push_back({sum, nums[i]});
        }

        sort(arr.begin(), arr.end());

        vector<int> sortedNums;

        for (auto p : arr) {
            sortedNums.push_back(p.second);
        }

        unordered_map<int, int> position;

        for (int i = 0; i < n; i++) {
            position[nums[i]] = i;
        }

        int swaps = 0;

        for (int i = 0; i < n; i++) {
            if (nums[i] != sortedNums[i]) {
                int j = position[sortedNums[i]];

                position[nums[i]] = j;
                position[nums[j]] = i;

                swap(nums[i], nums[j]);
                swaps++;
            }
        }

        return swaps;
    }
};
```

---

## Approach

### 1. Calculate digit sums

For each number, calculate its digit sum using `% 10` and `/ 10`.

For example, the digit sum of `37` is `3 + 7 = 10`.

Store each number with its digit sum as a pair:

`{digitSum, number}`

### 2. Sort the pairs

Sort the pairs in ascending order.

C++ sorts pairs by their first value and then by their second value. This automatically follows both problem rules.

For example:

`nums = [18, 43, 34, 16]`

Their digit sums are:

* `18` → 9
* `43` → 7
* `34` → 7
* `16` → 7

The sorted array becomes:

`[16, 34, 43, 18]`

### 3. Store the target order

Extract the numbers from the sorted pairs into `sortedNums`.

This represents the order that the original array must achieve.

### 4. Track element positions

Use an `unordered_map` called `position` to store the current index of each number.

For example, `position[43] = 1` means that `43` is currently at index `1`.

### 5. Count the minimum swaps

Traverse the array from left to right.

* If `nums[i]` already equals `sortedNums[i]`, continue.
* Otherwise, find the current position `j` of the required number.
* Swap `nums[i]` and `nums[j]`.
* Update both numbers' positions in the map.
* Increment `swaps`.

Each swap places the required number in its correct position.

### 6. Return the answer

After processing every index, return `swaps`.

---

## Example

**Input:**

```text
nums = [18, 43, 34, 16]
```

**Sorted array:**

```text
[16, 34, 43, 18]
```

**Swaps:**

1. Swap `18` with `16`: `[16, 43, 34, 18]`
2. Swap `43` with `34`: `[16, 34, 43, 18]`

**Output:**

```text
2
```

---

## Complexity

**Time Complexity:** `O(n log n)` — Sorting takes `O(n log n)` time, and the position-based swaps take `O(n)` expected time.

**Space Complexity:** `O(n)` — The sorted pairs, target array, and position map require linear space.

---

## Key Takeaway

Sort numbers by `{digitSum, number}` to establish the required order. Then use a position map to find the correct element for each index and count the swaps needed to place it.
