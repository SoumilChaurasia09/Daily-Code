# 176. Second Highest Salary

**Problem Name:** Second Highest Salary
**Difficulty:** Medium

---

## Question

Find the **second highest distinct salary** from the `Employee` table.

If there is no second highest salary, return `NULL`.

---

## My Solution

```sql
SELECT MAX(salary) AS SecondHighestSalary
FROM Employee
WHERE salary < (SELECT MAX(salary) FROM Employee);
```

---

## Approach

First, find the highest salary:

```sql
SELECT MAX(salary) FROM Employee
```

Then select only salaries that are **less than the highest salary**:

```sql
WHERE salary < (SELECT MAX(salary) FROM Employee)
```

Among those salaries, find the maximum:

```sql
MAX(salary)
```

That gives us the second highest distinct salary.

---

## Example

Given:

```text
100
200
300
```

First:

```text
MAX(salary) = 300
```

Then we consider:

```text
100
200
```

The maximum of these is:

```text
200
```

So the answer is:

```text
200
```

---

## When There Is No Second Highest Salary

If the table contains only:

```text
100
```

There is no salary smaller than the maximum.

Therefore:

```text
MAX(NULL) = NULL
```

So the query correctly returns `NULL`.

---

## Why `MAX()` Works

The query does not need `DISTINCT` explicitly.

Suppose salaries are:

```text
100
200
200
300
```

After removing the highest salary `300`, the remaining values are:

```text
100
200
200
```

`MAX()` returns:

```text
200
```

So the result is automatically the **second highest distinct salary**.

---

## Key Takeaway

The simple pattern is:

```text
Find maximum
      ↓
Ignore maximum
      ↓
Find maximum again
```

```sql
MAX(salary)
WHERE salary < highest_salary
```

This also naturally returns `NULL` when a second highest salary does not exist.
