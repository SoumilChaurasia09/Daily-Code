# 976. Largest Perimeter Triangle

**Problem Name:** Largest Perimeter Triangle
**Difficulty:** Easy

---

## Question

Given an array of side lengths, choose three sides that can form a triangle with non-zero area.

Return the largest possible perimeter.

If no three sides can form a valid triangle, return `0`.

For three sides `a`, `b`, and `c`, where `c` is the largest side, the triangle condition is:

```text
a + b > c
```

---

## My Solution

```cpp
class Solution {
public:
    int largestPerimeter(vector<int>& nums) {
        sort(nums.begin(), nums.end());

        for (int i = nums.size() - 1; i >= 2; i--) {
            if (nums[i - 2] + nums[i - 1] > nums[i]) {
                return nums[i - 2] + nums[i - 1] + nums[i];
            }
        }

        return 0;
    }
};
```

---

## Approach

First, sort the array in increasing order.

After sorting, take three elements from the end because they are the largest possible sides.

For every three consecutive sides:

```text
a = nums[i - 2]
b = nums[i - 1]
c = nums[i]
```

Check:

```cpp
a + b > c
```

If this condition is true, they form a valid triangle.

Because we are checking from the largest values toward the smaller values, the first valid triangle gives the largest possible perimeter.

If no valid triangle is found, return `0`.

---

## Complexity

**Time Complexity:** `O(n log n)`

**Space Complexity:** `O(1)` auxiliary space.

---

## Key Takeaway

For triangle problems, remember the **triangle inequality**:

```text
smallest side + middle side > largest side
```

For a sorted array, simply check three consecutive elements from right to left.

### Pattern to remember:

