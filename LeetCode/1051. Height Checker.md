# 1051. Height Checker

**Problem Name:** Height Checker  
**Difficulty:** Easy

---

## Question

A school wants to arrange students in **non-decreasing order** of their heights for a group photo.

You are given an array `heights` representing the current order of students.

Return the number of indices where the current order differs from the expected sorted order.

---

## My Solution

```cpp
class Solution {
public:
    int heightChecker(vector<int>& heights) {

        vector<int> expected = heights;

        sort(expected.begin(), expected.end());

        int count = 0;

        for (int i = 0; i < heights.size(); i++) {

            if (heights[i] != expected[i]) {
                count++;
            }
        }

        return count;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(n log n)` |
| **Space Complexity** | `O(n)` |

---

## What I Learned

This problem taught me that sometimes creating a copy of the original array is useful.

I copied the `heights` array into another array called `expected` and sorted it. Then I compared both arrays index by index.

Whenever the values at the same index were different, I increased the count because that student was not standing in the correct position.

---

## Personal Notes

Initially, I thought about checking every student's correct position without sorting, but that would make the solution more complicated.

By making a copy of the array and sorting it, the comparison became very simple and easy to understand. This problem also reinforced the idea of comparing an original array with its sorted version to identify misplaced elements.
