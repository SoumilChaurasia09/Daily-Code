# 3483. Unique 3-Digit Even Numbers

**Problem Name:** Unique 3-Digit Even Numbers
**Difficulty:** Easy

---

## Question

Given an array of digits, find the number of **distinct three-digit even numbers** that can be formed.

Rules:

* Each digit can be used only once in a number.
* The first digit cannot be `0`.
* The last digit must be even.
* Duplicate numbers should only be counted once.

---

## My Solution

```cpp
class Solution {
public:
    int totalNumbers(vector<int>& digits) {
        set<int> numbers;

        for (int i = 0; i < digits.size(); i++) {
            for (int j = 0; j < digits.size(); j++) {
                for (int k = 0; k < digits.size(); k++) {
                    if (i == j || j == k || i == k)
                        continue;

                    if (digits[i] == 0)
                        continue;

                    if (digits[k] % 2 != 0)
                        continue;

                    int num = digits[i] * 100 + digits[j] * 10 + digits[k];
                    numbers.insert(num);
                }
            }
        }

        return numbers.size();
    }
};
```

---

## Approach

We need to choose three different positions from the array:

```text
First digit  → hundreds place
Second digit → tens place
Third digit  → units place
```

So we use three nested loops.

### 1. Don't reuse a digit copy

We check:

```cpp
if (i == j || j == k || i == k)
    continue;
```

This makes sure the same array position is not used twice.

For example, if:

```text
digits = [0, 2, 2]
```

the two `2`s have different positions, so both can be used.

---

### 2. No leading zero

A three-digit number cannot start with `0`.

```cpp
if (digits[i] == 0)
    continue;
```

---

### 3. Number must be even

A number is even when its last digit is one of:

```text
0, 2, 4, 6, 8
```

Therefore:

```cpp
if (digits[k] % 2 != 0)
    continue;
```

---

### 4. Store only distinct numbers

We create the number:

```cpp
int num = digits[i] * 100 + digits[j] * 10 + digits[k];
```

Then insert it into a `set`.

A `set` automatically removes duplicates.

Finally:

```cpp
return numbers.size();
```

---

## Example

For:

```text
digits = [0, 2, 2]
```

Possible valid numbers are:

```text
202
220
```

The first `2` and second `2` are different copies, so `220` is valid.

The answer is:

```text
2
```

---

## Complexity

Let `n` be the number of digits.

**Time Complexity:** `O(n³ log M)`

There are at most `n³` combinations, and inserting into the `set` takes `O(log M)`, where `M` is the number of distinct numbers.

Since `n <= 10`, this is very small.

**Space Complexity:** `O(M)`

The set stores the distinct three-digit numbers.

---

## Key Takeaway

For a small array where we need to form numbers using different positions, **three nested loops** are simple and effective.

Remember the three important conditions:

```text
First digit ≠ 0
Last digit is even
No array position is reused
```

Using a `set` ensures that duplicate numbers are counted only once.
