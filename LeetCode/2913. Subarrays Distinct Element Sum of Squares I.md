# 2913. Subarrays Distinct Element Sum of Squares I

**Problem Name:** Subarrays Distinct Element Sum of Squares I
**Difficulty:** Easy

---

## Question

Given an integer array `nums`, find every non-empty contiguous subarray.

For each subarray:

1. Count the number of distinct elements.
2. Square that count.
3. Add all the squared counts and return the total.

---

## My Solution

```cpp
class Solution {
public:
    int sumCounts(vector<int>& nums) {
        int n = nums.size();
        int sum = 0;

        for (int i = 0; i < n; i++) {
            unordered_set<int> st;

            for (int j = i; j < n; j++) {
                st.insert(nums[j]);

                int distinct = st.size();
                sum += distinct * distinct;
            }
        }

        return sum;
    }
};
```

---

## Approach

1. Find the array length and initialize `sum = 0`.
2. Use the outer loop to choose the starting index `i` of each subarray.
3. Create an `unordered_set` to store distinct elements for each starting index.
4. Use the inner loop to extend the subarray from index `i` to index `j`.
5. Insert `nums[j]` into the set. Duplicate values are stored only once.
6. Get the number of distinct elements using `st.size()`.
7. Add the square of that count to `sum`.
8. Return `sum` after processing all subarrays.

### Important Logic

`st.insert(nums[j])` adds an element to the set only if it is not already present.

For example, if the subarray is `[1, 2, 1]`, the set contains `{1, 2}`, so its distinct count is `2` and its squared count is `2 * 2 = 4`.

---

## Example

**Input:**

```text
nums = [1, 2, 1]
```

All subarrays and their squared distinct counts:

| Subarray    | Distinct Count | Square |
| ----------- | -------------: | -----: |
| `[1]`       |              1 |      1 |
| `[1, 2]`    |              2 |      4 |
| `[1, 2, 1]` |              2 |      4 |
| `[2]`       |              1 |      1 |
| `[2, 1]`    |              2 |      4 |
| `[1]`       |              1 |      1 |

**Calculation:**

`1 + 4 + 4 + 1 + 4 + 1 = 15`

**Output:**

```text
15
```

---

## Complexity

**Time Complexity:** `O(n²)` on average — There are `O(n²)` subarrays, and set insertion takes `O(1)` on average.

**Space Complexity:** `O(n)` — The set can store up to `n` distinct elements.

---

## Key Takeaway

Use two nested loops to generate every subarray. An `unordered_set` counts distinct elements, and squaring its size gives the contribution of each subarray.
