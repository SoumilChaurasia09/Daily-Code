# 0168. Excel Sheet Column Title

**Problem Name:** Excel Sheet Column Title  
**Difficulty:** Easy

---

## Question

Given an integer `columnNumber`, return its corresponding Excel column title.

Examples:

- `1 -> A`
- `2 -> B`
- `26 -> Z`
- `27 -> AA`
- `28 -> AB`

---

## My Solution

```cpp
class Solution {
public:
    string convertToTitle(int columnNumber) {

        string ans = "";

        while (columnNumber > 0) {

            columnNumber--;

            char ch = 'A' + (columnNumber % 26);
            ans = ch + ans;

            columnNumber /= 26;
        }

        return ans;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(log26 n)` |
| **Space Complexity** | `O(1)` *(Ignoring the output string.)* |

---

## What I Learned

This problem helped me understand how Excel column titles work.

Unlike a normal base-26 number system, Excel columns start from **1 instead of 0**. To handle this correctly, I subtract `1` from the column number before calculating the remainder.

I then convert the remainder into a character (`A` to `Z`) and continue dividing the number by `26` until it becomes zero.

---

## Personal Notes

Initially, I tried treating this as a normal base-26 conversion, but the results were incorrect for values like `26` and `52`.

The key idea was subtracting `1` before taking the remainder. Once I understood that Excel columns are **1-indexed**, the implementation became much simpler.

This problem also gave me more practice with number system conversions and string manipulation.
