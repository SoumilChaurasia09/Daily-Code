# 2409. Count Days Spent Together

**Problem Name:** Count Days Spent Together
**Difficulty:** Easy

---

## Question

Alice and Bob stay in Rome during specific date ranges. We are given their arrival and leaving dates in the `"MM-DD"` format.

Both arrival and leaving dates are included in their stays.

We need to return the total number of days they are in Rome together.

---

## My Solution

```cpp
class Solution {
public:
    int countDaysTogether(string arriveAlice, string leaveAlice, string arriveBob, string leaveBob) {
        int daysInMonth[] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

        auto convertToDay = [&](string date) {
            int month = stoi(date.substr(0, 2));
            int day = stoi(date.substr(3, 2));

            for (int i = 0; i < month - 1; i++) {
                day += daysInMonth[i];
            }

            return day;
        };

        int startAlice = convertToDay(arriveAlice);
        int endAlice = convertToDay(leaveAlice);
        int startBob = convertToDay(arriveBob);
        int endBob = convertToDay(leaveBob);

        int start = max(startAlice, startBob);
        int end = min(endAlice, endBob);

        return max(0, end - start + 1);
    }
};
```

---

## Approach

### Step 1: Convert dates into day numbers

Comparing dates directly is possible because they use the `"MM-DD"` format. However, converting each date into a day number makes calculating the overlap easier.

For example, January 1 is day 1, and February 1 is day 32.

The `convertToDay()` function:

1. Extracts the month using `substr(0, 2)`.
2. Extracts the day using `substr(3, 2)`.
3. Adds the number of days in all previous months.
4. Returns the resulting day number.

The `stoi()` function converts a string into an integer.

### Step 2: Find the common date range

The common period starts on the later of the two arrival dates:

`start = max(startAlice, startBob)`

The common period ends on the earlier of the two leaving dates:

`end = min(endAlice, endBob)`

### Step 3: Calculate the number of common days

If `end >= start`, the number of common days is:

`end - start + 1`

We add `1` because both the starting and ending dates are inclusive.

If `end < start`, the date ranges do not overlap, so the answer is `0`.

The expression `max(0, end - start + 1)` handles both cases.

---

## Example

**Input:**

```text
arriveAlice = "08-15"
leaveAlice = "08-18"
arriveBob = "08-16"
leaveBob = "08-19"
```

**Step 1: Convert dates into day numbers**

August 15 is day 227.

August 18 is day 230.

August 16 is day 228.

August 19 is day 231.

**Step 2: Find the common range**

```text
start = max(227, 228) = 228
end = min(230, 231) = 230
```

**Step 3: Calculate the common days**

```text
Days = 230 - 228 + 1
     = 3
```

**Output:**

```text
3
```

Alice and Bob are together on August 16, 17, and 18.

### Edge Case: No Overlap

If Alice stays from October 1 to October 31 and Bob stays from November 1 to December 31:

```text
start > end
```

Therefore, the answer is `0`.

---

## Complexity

**Time Complexity:** `O(1)`

Each date conversion checks at most 11 previous months. Since the number of months is fixed, the running time is constant.

**Space Complexity:** `O(1)`

The solution uses a fixed-size array and a constant number of variables.

---

## Key Takeaway

To find the overlap between two date ranges:

1. Find the later starting date using `max()`.
2. Find the earlier ending date using `min()`.
3. Calculate `end - start + 1` if the ranges overlap.
4. Return `0` if there is no overlap.

**Important:** Add `1` because both endpoints are included in the date ranges.
