# 0441. Arranging Coins

**Problem Name:** Arranging Coins  
**Difficulty:** Easy

---

## Question

You have `n` coins and want to arrange them into a staircase.

- The first row contains `1` coin.
- The second row contains `2` coins.
- The third row contains `3` coins, and so on.

Return the number of **complete rows** that can be formed.

---

## My Solution

```cpp
class Solution {
public:
    int arrangeCoins(int n) {

        long long left = 1;
        long long right = n;
        long long ans = 0;

        while (left <= right) {

            long long mid = left + (right - left) / 2;

            long long coins = mid * (mid + 1) / 2;

            if (coins <= n) {
                ans = mid;
                left = mid + 1;
            }
            else {
                right = mid - 1;
            }
        }

        return ans;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(log n)` |
| **Space Complexity** | `O(1)` |

---

## What I Learned

This problem helped me understand another application of **Binary Search on the answer**.

Instead of checking every possible number of rows, I searched for the maximum number of complete rows that could be formed.

For each possible number of rows `mid`, I calculated the required number of coins using the formula:

```text
mid × (mid + 1) / 2
```

If the required coins were less than or equal to `n`, I searched for a larger answer. Otherwise, I searched for a smaller one.

---

## Personal Notes

Initially, I thought about subtracting `1`, `2`, `3`, and so on from `n` until there were not enough coins left. Although that works, it takes `O(√n)` time.

Using Binary Search made the solution much faster with `O(log n)` time. This problem also reinforced that Binary Search can be applied whenever the answer lies within a searchable range.
