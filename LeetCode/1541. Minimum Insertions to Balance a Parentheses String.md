# 1541. Minimum Insertions to Balance a Parentheses String

**Problem Name:** Minimum Insertions to Balance a Parentheses String
**Difficulty:** Medium

---

## Question

Every opening parenthesis `(` must be followed by two consecutive closing parentheses `))`. Return the minimum number of insertions needed to make the string balanced.

---

## My Solution

```cpp
class Solution {
public:
    int minInsertions(string s) {
        int open = 0;
        int insertions = 0;
        int i = 0;

        while (i < s.size()) {
            if (s[i] == '(') {
                open++;
                i++;
            }
            else {
                if (i + 1 < s.size() && s[i + 1] == ')') {
                    if (open > 0) {
                        open--;
                    }
                    else {
                        insertions++;
                    }
                    i += 2;
                }
                else {
                    if (open > 0) {
                        open--;
                        insertions++;
                    }
                    else {
                        insertions += 2;
                    }
                    i++;
                }
            }
        }

        return insertions + open * 2;
    }
};
```

---

## Approach

1. `open` counts opening parentheses that still need a closing pair.
2. `insertions` counts the parentheses that must be added.
3. When we find `(`, increase `open`.
4. When we find `))`, use the pair to match one opening parenthesis. If none exists, insert an opening parenthesis.
5. When we find a single `)` without another `)` immediately after it:

   * If an opening parenthesis exists, match it and insert one missing `)`.
   * Otherwise, insert one `(` and one additional `)`.
6. At the end, each remaining opening parenthesis needs two closing parentheses, so add `open * 2`.

---

## Example

**Input:**

```text
s = "())"
```

**Output:**

```text
0
```

The opening parenthesis is followed by the required `))`, so no insertions are needed.

---

## Complexity

**Time Complexity:** `O(n)` — Each character is processed once.

**Space Complexity:** `O(1)` — Only a few variables are used.

---

## Key Takeaway

Process closing parentheses in pairs. If a closing parenthesis does not have its required partner, insert the missing parenthesis while tracking unmatched opening parentheses.
