# 177. Nth Highest Salary

**Problem Name:** Nth Highest Salary
**Difficulty:** Medium

---

## Question

Find the `nth` highest **distinct** salary from the `Employee` table.

If there are fewer than `n` distinct salaries, return `NULL`.

---

## My Solution

```sql
CREATE FUNCTION getNthHighestSalary(N INT) RETURNS INT
BEGIN
    SET N = N - 1;

    RETURN (
        SELECT DISTINCT salary
        FROM Employee
        ORDER BY salary DESC
        LIMIT 1 OFFSET N
    );
END
```

---

## Approach

First, remove duplicate salaries:

```sql
DISTINCT salary
```

Then sort salaries from highest to lowest:

```sql
ORDER BY salary DESC
```

For example:

```text
300
200
100
```

---

## Why `N = N - 1`?

SQL `OFFSET` starts counting from `0`.

For example:

```text
N = 1 → OFFSET 0
N = 2 → OFFSET 1
N = 3 → OFFSET 2
```

So we convert:

```sql
SET N = N - 1;
```

---

## How `LIMIT` and `OFFSET` Work

```sql
LIMIT 1 OFFSET N
```

means:

* Skip the first `N` salaries.
* Return the next one salary.

For:

```text
Salaries = 300, 200, 100
N = 2
```

After:

```text
N = N - 1
```

we get:

```text
N = 1
```

Then:

```sql
LIMIT 1 OFFSET 1
```

skips `300` and returns:

```text
200
```

---

## Handling Duplicates

Suppose the table contains:

```text
300
300
200
100
```

Using:

```sql
DISTINCT salary
```

gives:

```text
300
200
100
```

Therefore, the query finds the **nth highest distinct salary**.

---

## When There Are Not Enough Salaries

Suppose:

```text
Employee
100
```

and:

```text
N = 2
```

There is no second distinct salary.

The query returns:

```text
NULL
```

because there is no row at the requested offset.

---

## Key Takeaway

The important pattern is:

```text
DISTINCT
   ↓
ORDER BY salary DESC
   ↓
OFFSET N - 1
   ↓
LIMIT 1
```

This directly gives the `nth` highest distinct salary.
