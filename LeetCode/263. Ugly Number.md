# 263. Ugly Number

**Problem Name:** Ugly Number
**Difficulty:** Easy

---

## Question

A positive integer is called an ugly number if its only prime factors are:

```text
2, 3, 5
```

Given an integer `n`, return `true` if it is an ugly number and `false` otherwise.

For example:

```text
6 = 2 × 3
```

So `6` is an ugly number.

---

## My Solution

```cpp id="l4c0x8"
class Solution {
public:
    bool isUgly(int n) {
        if (n <= 0) {
            return false;
        }

        while (n % 2 == 0) {
            n /= 2;
        }

        while (n % 3 == 0) {
            n /= 3;
        }

        while (n % 5 == 0) {
            n /= 5;
        }

        return n == 1;
    }
};
```

---

## Approach

First, check whether `n` is positive.

Then repeatedly divide `n` by `2`, `3`, and `5` as long as it is divisible by them.

For example:

```text
60
↓ divide by 2
30
↓ divide by 2
15
↓ divide by 3
5
↓ divide by 5
1
```

If the final value is `1`, all prime factors of the original number were `2`, `3`, or `5`.

If another value remains, that value contains a different prime factor, so the number is not ugly.

---

## Complexity

**Time Complexity:** `O(log n)`

**Space Complexity:** `O(1)`

---

## Key Takeaway

When a number is allowed to contain only certain prime factors, repeatedly divide by those allowed factors.

For this problem:

```text
Allowed factors → 2, 3, 5
```

At the end:

```text
n == 1 → Ugly Number
n != 1 → Not an Ugly Number
```
