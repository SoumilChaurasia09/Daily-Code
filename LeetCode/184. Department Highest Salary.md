# 184. Department Highest Salary

**Problem Name:** Department Highest Salary
**Difficulty:** Medium

---

## Question

Find all employees who have the **highest salary in their department**.

If multiple employees have the same highest salary, return all of them.

---

## My Solution

```sql
SELECT 
    d.name AS Department,
    e.name AS Employee,
    e.salary AS Salary
FROM Employee e
JOIN Department d
    ON e.departmentId = d.id
WHERE e.salary = (
    SELECT MAX(e2.salary)
    FROM Employee e2
    WHERE e2.departmentId = e.departmentId
);
```

---

## Approach

First, join the `Employee` and `Department` tables:

```sql
JOIN Department d
ON e.departmentId = d.id
```

This allows us to get the department name.

For each employee, the subquery finds the highest salary in that employee's department:

```sql
SELECT MAX(e2.salary)
FROM Employee e2
WHERE e2.departmentId = e.departmentId
```

Then we keep only employees whose salary equals that maximum:

```sql
WHERE e.salary = (...)
```

---

## Example

For the `IT` department:

```text
Joe → 70000
Jim → 90000
Max → 90000
```

The highest salary is:

```text
90000
```

Both `Jim` and `Max` have this salary, so both are returned.

For `Sales`:

```text
Henry → 80000
Sam   → 60000
```

The highest salary is `80000`, so `Henry` is returned.

---

## Important Point

We use:

```sql
MAX(e2.salary)
```

instead of:

```sql
ORDER BY salary DESC
LIMIT 1
```

because we need **all employees** when multiple employees share the highest salary.

For example:

```text
Jim → 90000
Max → 90000
```

Both must appear in the result.

---

## Complexity

**Time Complexity:** `O(n²)` in the basic correlated-subquery interpretation.

**Space Complexity:** `O(1)` auxiliary space, excluding database execution structures.

---

## Key Takeaway

For finding the highest salary **within each department**:

```text
Join Employee + Department
        ↓
Find MAX salary for the employee's department
        ↓
Keep employees whose salary equals that MAX
```

The equality condition ensures that ties are included.
