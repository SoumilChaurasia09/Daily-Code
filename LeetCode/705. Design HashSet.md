# 705. Design HashSet

**Problem Name:** Design HashSet
**Difficulty:** Easy

---

## Question

Design a HashSet without using any built-in hash table library.

The HashSet should support three operations:

* `add(key)` → Insert a key.
* `remove(key)` → Remove a key.
* `contains(key)` → Check whether a key exists.

The key range is:

```text
0 <= key <= 10^6
```

---

## My Solution

```cpp
class MyHashSet {
private:
    vector<bool> hash;

public:
    MyHashSet() {
        hash.resize(1000001, false);
    }
    
    void add(int key) {
        hash[key] = true;
    }
    
    void remove(int key) {
        hash[key] = false;
    }
    
    bool contains(int key) {
        return hash[key];
    }
};
```

---

## Approach

Since the maximum key is `10^6`, we can create a boolean array of size `1000001`.

Each index represents a possible key.

For example:

```text
hash[1] = true
```

means key `1` exists.

```text
hash[2] = false
```

means key `2` does not exist.

### Add

```cpp
hash[key] = true;
```

Marks the key as present.

### Remove

```cpp
hash[key] = false;
```

Marks the key as absent.

### Contains

```cpp
return hash[key];
```

Returns whether the key exists.

---

## Complexity

**Time Complexity:** `O(1)` for `add`, `remove`, and `contains`.

**Space Complexity:** `O(10^6)`.

---

## Key Takeaway

When the possible values have a small, known range, a boolean array can be used as a simple HashSet.

```text
index → key
value → whether key exists
```
