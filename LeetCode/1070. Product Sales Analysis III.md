# 1070. Product Sales Analysis III

**Problem Name:** Product Sales Analysis III
**Difficulty:** Medium

---

## Question

For every `product_id`, find the **first year** in which that product was sold.

Then return **all sales entries** for that product in its first year.

The output should contain:

* `product_id`
* `first_year`
* `quantity`
* `price`

---

## My Solution

```sql
SELECT
    s1.product_id,
    s2.first_year,
    s1.quantity,
    s1.price
FROM Sales s1
JOIN (
    SELECT
        product_id,
        MIN(year) AS first_year
    FROM Sales
    GROUP BY product_id
) s2
ON s1.product_id = s2.product_id
AND s1.year = s2.first_year;
```

---

## Approach

Your solution is **correct**.

The main idea is to first find the earliest year for every product, then join that result back to the original `Sales` table.

### 1. Find the first year for every product

```sql
SELECT
    product_id,
    MIN(year) AS first_year
FROM Sales
GROUP BY product_id
```

`GROUP BY product_id` creates one group for each product.

Then:

```sql
MIN(year)
```

finds the earliest year for each product.

For example:

```text
Sales:

product_id   year
100          2008
100          2009
200          2011
```

The subquery produces:

```text
product_id   first_year
100          2008
200          2011
```

---

### 2. Use the subquery as a table

You give the subquery the alias `s2`:

```sql
(
    SELECT
        product_id,
        MIN(year) AS first_year
    FROM Sales
    GROUP BY product_id
) s2
```

So `s2` behaves like a temporary table containing:

```text
product_id | first_year
```

---

### 3. JOIN with the original Sales table

Now we need the `quantity` and `price` from the original `Sales` table.

That's why we use:

```sql
FROM Sales s1
JOIN (...) s2
```

We match the same product:

```sql
s1.product_id = s2.product_id
```

But that's not enough.

We also need the sale to be from the first year:

```sql
s1.year = s2.first_year
```

So the complete condition is:

```sql
ON s1.product_id = s2.product_id
AND s1.year = s2.first_year
```

---

### 4. Why this handles multiple sales in the first year

The problem says a product can have **multiple sales entries in the same year**.

Suppose:

```text
product_id | year | quantity | price
100        | 2008 | 10       | 5000
100        | 2008 | 20       | 4500
100        | 2009 | 15       | 5000
```

The subquery finds:

```text
100 | 2008
```

The join then matches **both** rows from 2008.

Result:

```text
100 | 2008 | 10 | 5000
100 | 2008 | 20 | 4500
```

This is why your `JOIN` solution is better than trying to select only one row.

---

## Example

For:

```text
Sales:

100 | 2008 | 10 | 5000
100 | 2009 | 12 | 5000
200 | 2011 | 15 | 9000
```

The subquery gives:

```text
100 | 2008
200 | 2011
```

Then the join finds the corresponding rows:

```text
100 | 2008 | 10 | 5000
200 | 2011 | 15 | 9000
```

So the final result is:

```text
+------------+------------+----------+-------+
| product_id | first_year | quantity | price |
+------------+------------+----------+-------+
| 100        | 2008       | 10       | 5000  |
| 200        | 2011       | 15       | 9000  |
+------------+------------+----------+-------+
```

---

## Complexity

**Time Complexity:** `O(n)`

The database scans and groups the `Sales` data and then joins the result back to the table. Actual performance depends on indexes and the database engine.

**Space Complexity:** `O(k)`

The subquery stores the first year for each distinct `product_id`, where `k` is the number of distinct products.

---

## Key Takeaway

This is a very common SQL pattern:

```sql
SELECT ...
FROM original_table t1
JOIN (
    SELECT
        group_column,
        MIN(value_column) AS minimum_value
    FROM original_table
    GROUP BY group_column
) t2
ON t1.group_column = t2.group_column
AND t1.value_column = t2.minimum_value;
```

Use this pattern when you need to:

1. Find the minimum or maximum value for each group.
2. Return the **complete original rows** corresponding to that minimum or maximum.

For this problem:

```text
GROUP BY product_id
        ↓
MIN(year)
        ↓
JOIN back to Sales
        ↓
Get quantity and price
```
