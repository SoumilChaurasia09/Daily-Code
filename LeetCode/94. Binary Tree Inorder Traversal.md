# 94. Binary Tree Inorder Traversal

**Problem Name:** Binary Tree Inorder Traversal  
**Difficulty:** Easy

---

## Question

We are given the root of a binary tree.

We need to return the values of its nodes using **Inorder Traversal**.

Inorder traversal follows this order:

1. Left subtree
2. Root node
3. Right subtree

This is also called **LNR (Left → Node → Right)**.

---

## My Solution

```cpp
class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> ans;
        stack<TreeNode*> st;

        TreeNode* curr = root;

        while (curr != NULL || !st.empty()) {
            while (curr != NULL) {
                st.push(curr);
                curr = curr->left;
            }

            curr = st.top();
            st.pop();

            ans.push_back(curr->val);

            curr = curr->right;
        }

        return ans;
    }
};
```

---

## Approach

We use an **iterative approach with a stack** instead of recursion.

### Step 1: Initialize variables

```cpp
vector<int> ans;
stack<TreeNode*> st;
TreeNode* curr = root;
```

- `ans` stores the traversal result.
- `st` stores tree nodes.
- `curr` points to the current node.

### Step 2: Move towards the leftmost node

```cpp
while (curr != NULL) {
    st.push(curr);
    curr = curr->left;
}
```

Keep moving left and push every visited node into the stack.

We do this because inorder traversal always visits the left subtree first.

### Step 3: Process the current node

```cpp
curr = st.top();
st.pop();

ans.push_back(curr->val);
```

When there is no more left child:

1. Take the top node from the stack.
2. Remove it from the stack.
3. Add its value to the answer.

### Step 4: Move to the right subtree

```cpp
curr = curr->right;
```

After processing the current node, move to its right child.

The process repeats until both conditions are satisfied:

- `curr == NULL`
- Stack is empty.

### Step 5: Return the answer

```cpp
return ans;
```

---

## Example

**Input:**

```text
root = [1, null, 2, 3]
```

Binary tree:

```text
    1
     \
      2
     /
    3
```

### Step-by-step traversal

**Step 1:** Start at node `1`.

- Push `1`.
- No left child.

Stack: `[1]`

**Step 2:** Pop `1` and add it to the answer.

```text
ans = [1]
```

Move right to node `2`.

**Step 3:** Push node `2`.

Move left to node `3`.

Stack: `[2, 3]`

**Step 4:** Pop node `3` and add it.

```text
ans = [1, 3]
```

Node `3` has no right child.

**Step 5:** Pop node `2` and add it.

```text
ans = [1, 3, 2]
```

No more nodes remain.

**Output:**

```text
[1, 3, 2]
```

---

## Complexity

**Time Complexity:** `O(n)`

Every node is pushed into and popped from the stack exactly once.

**Space Complexity:** `O(n)`

In the worst case, the stack can contain all nodes of a skewed binary tree.

---

## Key Takeaway

The main concept is **Binary Tree Traversal using Stack**.

Remember the three traversal orders:

| Traversal | Order |
|---|---|
| Inorder | Left → Root → Right |
| Preorder | Root → Left → Right |
| Postorder | Left → Right → Root |

**Important:** In iterative inorder traversal, always move left first, process the node, and then move right.

The stack helps us remember the parent nodes while exploring the left subtree.
