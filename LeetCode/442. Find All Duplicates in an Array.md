# 442. Find All Duplicates in an Array

**Problem Name:** Find All Duplicates in an Array
**Difficulty:** Medium

---

## Question

Given an array `nums` of size `n`, every number is between `1` and `n`.

Each number appears either once or twice.

We need to return all numbers that appear twice.

The solution must use `O(n)` time and `O(1)` extra space, excluding the output array.

---

## My Solution

```cpp
class Solution {
public:
    vector<int> findDuplicates(vector<int>& nums) {
        vector<int> ans;

        for (int i = 0; i < nums.size(); i++) {
            int x = abs(nums[i]);

            if (nums[x - 1] < 0) {
                ans.push_back(x);
            } else {
                nums[x - 1] = -nums[x - 1];
            }
        }

        return ans;
    }
};
```

---

## Approach

Since every number is between `1` and `n`, we can use each number as an array index.

For a number `x`, use index:

```text
x - 1
```

We mark that number as visited by making the value at that index negative.

For example, if we see `2`:

```cpp
nums[2 - 1] = -nums[2 - 1];
```

If we see `2` again and `nums[1]` is already negative, then `2` is a duplicate.

We use `abs(nums[i])` because the current element itself may already have been changed to negative.

---

## Complexity

**Time Complexity:** `O(n)`

**Space Complexity:** `O(1)` auxiliary space.

The output vector is not counted as extra space because the problem excludes the space needed for the output.

---

## Key Takeaway

When an array contains numbers from `1` to `n`, we can often use:

```cpp
nums[value - 1]
```

as a way to mark or store information about that value.

This is an important **array-indexing trick** for coding interviews and TCS NQT.
