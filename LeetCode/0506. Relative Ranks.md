# 0506. Relative Ranks

**Problem Name:** Relative Ranks  
**Difficulty:** Easy

---

## Question

You are given an integer array `score` where each element represents the score of an athlete.

Assign ranks based on the scores:

- Highest score → `"Gold Medal"`
- Second highest → `"Silver Medal"`
- Third highest → `"Bronze Medal"`
- Remaining athletes receive their rank number as a string.

Return the rank of each athlete in the same order as the input array.

---

## My Solution

```cpp
class Solution {
public:
    vector<string> findRelativeRanks(vector<int>& score) {

        vector<int> sorted = score;
        sort(sorted.begin(), sorted.end(), greater<int>());

        unordered_map<int, string> rank;

        for (int i = 0; i < sorted.size(); i++) {

            if (i == 0) {
                rank[sorted[i]] = "Gold Medal";
            }
            else if (i == 1) {
                rank[sorted[i]] = "Silver Medal";
            }
            else if (i == 2) {
                rank[sorted[i]] = "Bronze Medal";
            }
            else {
                rank[sorted[i]] = to_string(i + 1);
            }
        }

        vector<string> ans;

        for (int num : score) {
            ans.push_back(rank[num]);
        }

        return ans;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(n log n)` |
| **Space Complexity** | `O(n)` |

---

## What I Learned

This problem helped me understand how to combine **sorting** and a **hash map**.

I first created a copy of the scores and sorted it in descending order. Then I assigned medals to the top three scores and numerical ranks to the remaining scores.

Finally, I used a hash map to retrieve each athlete's rank while preserving the original order of the input array.

---

## Personal Notes

Initially, I thought about sorting the original array directly, but that would lose the athletes' original positions.

Creating a sorted copy and storing the rank of each score in a hash map made the solution much simpler. This problem reinforced how sorting and hash maps can work together to maintain both ranking and original order.
