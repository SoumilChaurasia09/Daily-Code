# 3619. Count Islands With Total Value Divisible by K

**Problem Name:** Count Islands With Total Value Divisible by K
**Difficulty:** Medium

---

## Question

We are given an `m x n` grid containing non-negative integers and a positive integer `k`.

* A positive number represents land.
* `0` represents water.
* Land cells belong to the same island if they are connected horizontally or vertically.

For each island, calculate the sum of all its cell values.

Return the number of islands whose total sum is divisible by `k`.

---

## My Solution

```cpp
class Solution {
public:
    int countIslands(vector<vector<int>>& grid, int k) {
        int m = grid.size();
        int n = grid[0].size();
        int count = 0;

        vector<vector<bool>> visited(m, vector<bool>(n, false));
        vector<pair<int, int>> directions = {
            {1, 0}, {-1, 0}, {0, 1}, {0, -1}
        };

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 0 || visited[i][j]) {
                    continue;
                }

                long long sum = 0;
                queue<pair<int, int>> q;
                q.push({i, j});
                visited[i][j] = true;

                while (!q.empty()) {
                    auto cell = q.front();
                    q.pop();

                    int r = cell.first;
                    int c = cell.second;
                    sum += grid[r][c];

                    for (auto direction : directions) {
                        int nr = r + direction.first;
                        int nc = c + direction.second;

                        if (nr >= 0 && nr < m &&
                            nc >= 0 && nc < n &&
                            grid[nr][nc] > 0 &&
                            !visited[nr][nc]) {
                            visited[nr][nc] = true;
                            q.push({nr, nc});
                        }
                    }
                }

                if (sum % k == 0) {
                    count++;
                }
            }
        }

        return count;
    }
};
```

---

## Approach

### Step 1: Initialize the grid information

Store the number of rows and columns in `m` and `n`.

Create a `visited` matrix to ensure each land cell is processed only once.

The `directions` vector represents the four possible movements:

* `{1, 0}`: Down
* `{-1, 0}`: Up
* `{0, 1}`: Right
* `{0, -1}`: Left

### Step 2: Find an unvisited land cell

Traverse every cell in the grid.

```cpp
if (grid[i][j] == 0 || visited[i][j]) {
    continue;
}
```

Skip the cell if it is water or has already been visited.

Otherwise, a new island has been found. Start a BFS traversal from this cell.

### Step 3: Explore the entire island using BFS

Add the starting cell to a queue and mark it as visited.

```cpp
queue<pair<int, int>> q;
q.push({i, j});
visited[i][j] = true;
```

While the queue is not empty:

1. Remove a cell from the queue.
2. Add its value to the island's sum.
3. Check its four neighboring cells.
4. If a neighbor is inside the grid, contains positive land, and has not been visited, mark it visited and add it to the queue.

This ensures that every cell belonging to the current island is visited.

### Step 4: Calculate the island's total value

```cpp
sum += grid[r][c];
```

We use `long long` for `sum` because an island can contain many cells with large values.

### Step 5: Check divisibility

After BFS finishes, the complete island sum is available.

```cpp
if (sum % k == 0) {
    count++;
}
```

If the remainder is zero, the island's total value is divisible by `k`, so increase the count.

### Step 6: Return the answer

After processing every cell, return `count`.

---

## Example

**Input:**

```text
grid = [[3,0,3,0],
        [0,3,0,3],
        [3,0,3,0]]

k = 3
```

### Step 1: Identify the islands

Every positive cell is separated from the other positive cells by water.

Therefore, there are six separate islands.

### Step 2: Calculate each island's sum

Each island contains exactly one cell with value `3`.

```text
Island 1 sum = 3
Island 2 sum = 3
Island 3 sum = 3
Island 4 sum = 3
Island 5 sum = 3
Island 6 sum = 3
```

### Step 3: Check divisibility

For every island:

```text
3 % 3 = 0
```

All six islands satisfy the condition.

**Output:**

```text
6
```

### Important Edge Case

If an island contains values `2` and `4`, its total sum is:

```text
sum = 2 + 4 = 6
```

If `k = 5`:

```text
6 % 5 = 1
```

This island is not counted because its total value is not divisible by `5`.

---

## Complexity

**Time Complexity:** `O(m × n)`

Every cell is visited at most once by the outer loops and BFS combined. Each cell checks at most four neighbors.

**Space Complexity:** `O(m × n)`

The `visited` matrix can store information for every cell, and the BFS queue can contain up to `O(m × n)` cells in the worst case.

---

## Key Takeaway

This problem uses **BFS to find connected components in a grid**.

Remember the steps:

1. Find an unvisited positive cell.
2. Use BFS to explore its entire island.
3. Calculate the sum of all cells in that island.
4. Check whether `sum % k == 0`.
5. Count the island if the remainder is zero.

**Important:** Mark cells as visited when adding them to the queue, not when removing them. This prevents the same cell from being added multiple times.
