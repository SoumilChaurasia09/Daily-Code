# 0083. Remove Duplicates from Sorted List

**Problem Name:** Remove Duplicates from Sorted List
**Difficulty:** Easy

---

## Question

Given the head of a **sorted linked list**, remove all duplicate values so that each value appears only once.

Return the linked list after removing the duplicates.

For example:

```text
[1,1,2,3,3]
```

becomes:

```text
[1,2,3]
```

---

## My Solution

```cpp
class Solution {
public:
    ListNode* deleteDuplicates(ListNode* head) {

        ListNode* current = head;

        while (current != NULL && current->next != NULL) {

            if (current->val == current->next->val) {
                current->next = current->next->next;
            }
            else {
                current = current->next;
            }
        }

        return head;
    }
};
```

---

## Complexity

| Metric               | Value  |
| -------------------- | ------ |
| **Time Complexity**  | `O(n)` |
| **Space Complexity** | `O(1)` |

---

## What I Learned

This problem helped me practice working with **linked list pointers**.

Since the linked list is already sorted, duplicate values will always be next to each other.

I used a pointer called `current` and compared:

```cpp
current->val
```

with:

```cpp
current->next->val
```

If both values are equal, I skipped the duplicate node:

```cpp
current->next = current->next->next;
```

If the values are different, I moved `current` to the next node.

---

## Personal Notes

The important thing I learned here is that we don't need another data structure to store the values.

Because the list is sorted, duplicates are already next to each other. So I can remove them directly by changing the `next` pointer.

I also learned to check:

```cpp
current != NULL && current->next != NULL
```

before accessing `current->next`, which prevents accessing an invalid pointer.
