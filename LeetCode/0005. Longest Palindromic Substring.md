# 0005. Longest Palindromic Substring

**Problem Name:** Longest Palindromic Substring
**Difficulty:** Medium

---

## Question

Given a string `s`, return the **longest palindromic substring**.

A palindrome is a string that reads the same forward and backward.

For example:

```text
"aba"
```

is a palindrome.

---

## My Solution

```cpp
class Solution {
public:
    string longestPalindrome(string s) {

        int start = 0;
        int maxLength = 1;

        for (int i = 0; i < s.size(); i++) {

            int left = i;
            int right = i;

            while (left >= 0 && right < s.size() &&
                   s[left] == s[right]) {

                if (right - left + 1 > maxLength) {
                    start = left;
                    maxLength = right - left + 1;
                }

                left--;
                right++;
            }

            left = i;
            right = i + 1;

            while (left >= 0 && right < s.size() &&
                   s[left] == s[right]) {

                if (right - left + 1 > maxLength) {
                    start = left;
                    maxLength = right - left + 1;
                }

                left--;
                right++;
            }
        }

        return s.substr(start, maxLength);
    }
};
```

---

## Approach

I used the **Expand Around Center** approach.

Every palindrome has a center.

There are two possibilities:

### 1. Odd-length palindrome

For example:

```text
aba
```

The center is the character:

```text
  b
```

So I start with:

```cpp
left = i;
right = i;
```

and expand outward.

### 2. Even-length palindrome

For example:

```text
abba
```

The center is between the two `b`s.

So I start with:

```cpp
left = i;
right = i + 1;
```

and expand outward.

For every palindrome found, I check whether its length is greater than the current `maxLength`.

---

## Complexity

| Metric               | Value   |
| -------------------- | ------- |
| **Time Complexity**  | `O(n²)` |
| **Space Complexity** | `O(1)`  |

---

## What I Learned

This problem helped me understand the **Expand Around Center** technique.

Instead of checking every possible substring separately, I treat every character and every gap between characters as a possible palindrome center.

Then I expand outward while the characters are equal.

I also learned that palindromes can have either an **odd length** or an **even length**, so both cases need to be checked.

---

## Personal Notes

Initially, I thought about generating every substring and checking whether each one was a palindrome. That would be much slower.

The center-expansion approach is easier to implement and reduces the time complexity to `O(n²)`.

The most important part for me was understanding why we need two expansions:

```cpp
left = i;
right = i;
```

for odd-length palindromes, and:

```cpp
left = i;
right = i + 1;
```

for even-length palindromes.
