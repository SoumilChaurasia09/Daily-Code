# 0326. Power of Three

**Problem Name:** Power of Three  
**Difficulty:** Easy

---

## Question

Given an integer `n`, return `true` if it is a power of three. Otherwise, return `false`.

An integer is a power of three if there exists an integer `x` such that:

```text
n = 3^x
```

---

## My Solution

```cpp
class Solution {
public:
    bool isPowerOfThree(int n) {

        if (n <= 0) {
            return false;
        }

        while (n % 3 == 0) {
            n = n / 3;
        }

        return n == 1;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(log₃ n)` |
| **Space Complexity** | `O(1)` |

---

## What I Learned

This problem helped me understand how powers of three behave.

If a number is a power of three, it can be divided by `3` repeatedly until it becomes `1`. If, after all possible divisions, the number is exactly `1`, then it is a power of three.

I also learned to check for zero and negative numbers first because they cannot be powers of three.

---

## Personal Notes

Initially, I thought about multiplying `3` repeatedly until it reached the given number. However, repeatedly dividing the number by `3` made the solution much simpler and easier to understand.

I also learned that there is a mathematical solution without using loops by checking whether the number divides the largest power of `3` within the integer range. However, this iterative approach helped me better understand the concept.
