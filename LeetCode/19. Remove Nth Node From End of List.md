# 19. Remove Nth Node From End of List

**Problem Name:** Remove Nth Node From End of List
**Difficulty:** Medium

---

## Question

Given the head of a linked list, remove the `nth` node from the **end** of the list and return the new head.

For example:

```text
[1,2,3,4,5], n = 2
```

The 2nd node from the end is `4`, so the result is:

```text
[1,2,3,5]
```

The follow-up asks us to solve it in **one pass**.

---

## My Solution

```cpp id="p5r8nd"
class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode* dummy = new ListNode(0);
        dummy->next = head;

        ListNode* slow = dummy;
        ListNode* fast = dummy;

        for (int i = 0; i < n; i++) {
            fast = fast->next;
        }

        while (fast->next != nullptr) {
            slow = slow->next;
            fast = fast->next;
        }

        slow->next = slow->next->next;

        return dummy->next;
    }
};
```

---

## Approach

We use the **two-pointer technique** with `slow` and `fast`.

The idea is to keep `fast` exactly `n` nodes ahead of `slow`.

### 1. Create a dummy node

```cpp id="b8r7pz"
ListNode* dummy = new ListNode(0);
dummy->next = head;
```

The dummy node makes it easier to handle the case where the first node itself needs to be removed.

For example:

```text
dummy -> 1 -> 2 -> 3
```

---

### 2. Start both pointers at dummy

```cpp id="t7g3wp"
ListNode* slow = dummy;
ListNode* fast = dummy;
```

Both pointers initially point to the dummy node.

---

### 3. Move `fast` forward by `n` nodes

```cpp id="e8d1qa"
for (int i = 0; i < n; i++) {
    fast = fast->next;
}
```

Now there are exactly `n` nodes between `slow` and `fast`.

---

### 4. Move both pointers

```cpp id="j4r8cx"
while (fast->next != nullptr) {
    slow = slow->next;
    fast = fast->next;
}
```

When `fast` reaches the last node, `slow` will be positioned immediately **before the node that needs to be removed**.

---

### 5. Remove the node

```cpp id="v2s6nh"
slow->next = slow->next->next;
```

Suppose the list is:

```text
1 -> 2 -> 3 -> 4 -> 5
```

and `n = 2`.

`slow` ends up at node `3`:

```text
1 -> 2 -> 3 -> 4 -> 5
          ↑
        slow
```

We skip node `4`:

```text
slow->next = slow->next->next;
```

The list becomes:

```text
1 -> 2 -> 3 -> 5
```

---

## Example

Input:

```text
head = [1,2,3,4,5]
n = 2
```

Initially:

```text
dummy -> 1 -> 2 -> 3 -> 4 -> 5
  ↑
slow
fast
```

Move `fast` two positions:

```text
dummy -> 1 -> 2 -> 3 -> 4 -> 5
  ↑         ↑
slow       fast
```

Then move both pointers until `fast` reaches the last node.

Eventually:

```text
dummy -> 1 -> 2 -> 3 -> 4 -> 5
                  ↑       ↑
                slow     fast
```

`slow` is immediately before node `4`.

Remove node `4`:

```text
[1,2,3,5]
```

---

## Edge Case

For:

```text
head = [1]
n = 1
```

The only node needs to be removed.

The dummy node makes this easy:

```text
dummy -> 1
```

`slow` stays at `dummy`.

Then:

```cpp id="s7x5xk"
slow->next = slow->next->next;
```

becomes:

```text
dummy -> nullptr
```

Finally:

```cpp id="h7k1cy"
return dummy->next;
```

returns `nullptr`, representing an empty list.

---

## Complexity

**Time Complexity:** `O(n)`

The list is traversed only once.

**Space Complexity:** `O(1)`

Only a few pointers are used.

---

## Key Takeaway

The important pattern is the **two-pointer technique**:

```text
1. Move fast by n positions.
2. Move slow and fast together.
3. When fast reaches the end, slow is before the node to remove.
4. Skip that node.
```

The dummy node is especially useful when the node to remove is the **head of the linked list**.
