# 1464. Maximum Product of Two Elements in an Array

**Problem Name:** Maximum Product of Two Elements in an Array  
**Difficulty:** Easy

---

## Question

Given an integer array `nums`, choose two different indices `i` and `j`.

Return the maximum value of:

```text
(nums[i] - 1) × (nums[j] - 1)
```

---

## My Solution

```cpp
class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int max = (nums[0] - 1) * (nums[1] - 1);
        int product = 1;

        for (int i = 0; i < nums.size() - 1; i++) {
            for (int j = i + 1; j < nums.size(); j++) {
                product = (nums[i] - 1) * (nums[j] - 1);

                if (product > max) {
                    max = product;
                }
            }
        }

        return max;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(n²)` |
| **Space Complexity** | `O(1)` |

---

## What I Learned

This problem helped me practice using **nested loops** to compare every possible pair of elements in an array.

I calculated the value of `(nums[i] - 1) * (nums[j] - 1)` for each pair and kept track of the maximum product found so far.

Although this solution checks all pairs, it correctly finds the maximum product.

---

## Personal Notes

Initially, I solved this problem using a brute-force approach because it was simple to understand and implement. By comparing every pair of elements, I was confident that the maximum product would not be missed.

Later, I learned that this problem can be optimized to `O(n)` time by finding the two largest elements in a single traversal. However, this brute-force solution helped me understand the problem before moving on to the optimized approach.
