# 1190. Reverse Substrings Between Each Pair of Parentheses

**Problem Name:** Reverse Substrings Between Each Pair of Parentheses
**Difficulty:** Medium

---

## Question

Given a string containing lowercase letters and parentheses, reverse the characters inside every matching pair of parentheses.

The innermost parentheses should be processed first.

All parentheses must be removed from the final answer.

---

## My Solution

```cpp
class Solution {
public:
    string reverseParentheses(string s) {
        vector<string> st;
        string current = "";

        for (char ch : s) {
            if (ch == '(') {
                st.push_back(current);
                current = "";
            }
            else if (ch == ')') {
                reverse(current.begin(), current.end());
                current = st.back() + current;
                st.pop_back();
            }
            else {
                current += ch;
            }
        }

        return current;
    }
};
```

---

## Approach

We use a **stack of strings** to handle nested parentheses.

### 1. When we see `(`

```cpp
st.push_back(current);
current = "";
```

The string built before the opening parenthesis is saved on the stack.

Then `current` is reset so we can build the substring inside the parentheses.

---

### 2. When we see a letter

```cpp
current += ch;
```

We simply add the character to the current string.

---

### 3. When we see `)`

```cpp
reverse(current.begin(), current.end());
```

The current substring is inside a pair of parentheses, so we reverse it.

Then:

```cpp
current = st.back() + current;
st.pop_back();
```

We attach the reversed substring to the string that existed before the opening parenthesis.

This naturally handles nested parentheses because the innermost pair is closed first.

---

## Example

Consider:

```text
s = "(u(love)i)"
```

### First `(`

Save the current string:

```text
stack = [""]
current = ""
```

Read `u`:

```text
current = "u"
```

### Second `(`

Save `"u"`:

```text
stack = ["", "u"]
current = ""
```

Read `love`:

```text
current = "love"
```

### First `)`

Reverse:

```text
"love" → "evol"
```

Then attach it to `"u"`:

```text
current = "u" + "evol"
       = "uevol"
```

Read `i`:

```text
current = "uevoli"
```

### Final `)`

Reverse:

```text
"uevoli" → "iloveu"
```

The final answer is:

```text
"iloveu"
```

---

## Complexity

**Time Complexity:** `O(n²)` in the worst case.

Nested parentheses can cause the same characters to be reversed multiple times.

**Space Complexity:** `O(n)`

The stack and strings together can contain up to `n` characters.

---

## Key Takeaway

Use a **stack** when processing nested parentheses.

The important pattern is:

```text
( → save current string
letters → add to current string
) → reverse current string and combine with saved string
```

Processing `)` from the inside outward automatically handles nested parentheses.
