# 0278. First Bad Version

**Problem Name:** First Bad Version  
**Difficulty:** Easy

---

## Question

You are given `n` versions of a product.

There is an API:

```cpp
bool isBadVersion(version);
```

- It returns `true` if the version is bad.
- Once a version becomes bad, every version after it is also bad.

Return the **first bad version** while making the minimum number of API calls.

---

## My Solution

```cpp
/* The isBadVersion API is defined for you.
      bool isBadVersion(int version);
*/

class Solution {
public:
    int firstBadVersion(int n) {

        int left = 1;
        int right = n;

        while (left < right) {

            int mid = left + (right - left) / 2;

            if (isBadVersion(mid)) {
                right = mid;
            }
            else {
                left = mid + 1;
            }
        }

        return left;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(log n)` |
| **Space Complexity** | `O(1)` |

---

## What I Learned

This problem helped me understand another application of **Binary Search**.

Instead of searching for a value in an array, I searched for the first version where the condition changes from **good** to **bad**.

If `mid` is a bad version, the first bad version could be `mid` or before it, so I moved the `right` pointer.

If `mid` is a good version, I searched in the right half by moving the `left` pointer.

---

## Personal Notes

Initially, I thought about checking every version one by one, but that would require too many API calls.

Using Binary Search reduced the number of API calls to `O(log n)`. This problem also taught me that Binary Search can be used to find the first or last position where a condition becomes true, not just to search for a specific value.
