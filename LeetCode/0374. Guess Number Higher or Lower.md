# 0374. Guess Number Higher or Lower

**Problem Name:** Guess Number Higher or Lower  
**Difficulty:** Easy

---

## Question

We are playing a guessing game.

A number is picked between `1` and `n`.

You can use the API:

```cpp
int guess(int num);
```

It returns:

- `-1` → Your guess is too high.
- `1` → Your guess is too low.
- `0` → Your guess is correct.

Return the number that was picked.

---

## My Solution

```cpp
/** 
 * Forward declaration of guess API.
 * int guess(int num);
 */

class Solution {
public:
    int guessNumber(int n) {

        int left = 1;
        int right = n;

        while (left <= right) {

            int mid = left + (right - left) / 2;

            int result = guess(mid);

            if (result == 0) {
                return mid;
            }
            else if (result == -1) {
                right = mid - 1;
            }
            else {
                left = mid + 1;
            }
        }

        return -1;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(log n)` |
| **Space Complexity** | `O(1)` |

---

## What I Learned

This problem helped me practice **Binary Search** using an API instead of an array.

At each step, I guessed the middle number.

- If the API returned `0`, I found the answer.
- If it returned `-1`, the guessed number was too large, so I searched the left half.
- If it returned `1`, the guessed number was too small, so I searched the right half.

This approach minimizes the number of guesses.

---

## Personal Notes

Initially, I thought about guessing every number one by one, but that would take too many attempts for large values of `n`.

Using Binary Search reduced the number of guesses to `O(log n)`. This problem reinforced that Binary Search is useful whenever the search space is ordered and each comparison tells us which half to discard.
