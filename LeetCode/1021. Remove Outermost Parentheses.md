# 1021. Remove Outermost Parentheses

**Problem Name:** Remove Outermost Parentheses
**Difficulty:** Easy

---

## Question

Given a valid parentheses string, divide it into primitive valid parentheses strings.

For every primitive string, remove its **outermost `(` and `)`**.

Return the resulting string.

For example:

```text id="5n3gqv"
s = "(()())(())"
```

Primitive parts are:

```text id="8n5k2x"
"(()())" + "(())"
```

After removing the outermost parentheses:

```text id="j7c4mt"
"()()" + "()"
```

Result:

```text id="2k6v1p"
"()()()"
```

---

## My Solution

```cpp id="f1n6bz"
class Solution {
public:
    string removeOuterParentheses(string s) {
        string result = "";
        int depth = 0;

        for (char ch : s) {
            if (ch == '(') {
                if (depth > 0) {
                    result += ch;
                }
                depth++;
            }
            else {
                depth--;
                if (depth > 0) {
                    result += ch;
                }
            }
        }

        return result;
    }
};
```

---

## Approach

We use a `depth` variable to track how deeply nested we currently are.

```cpp id="h8x4kp"
int depth = 0;
```

The key idea is:

* The `(` that changes `depth` from `0 → 1` is the **outermost opening parenthesis**, so we skip it.
* The `)` that changes `depth` from `1 → 0` is the **outermost closing parenthesis**, so we skip it.
* All other parentheses belong to the inside of a primitive and should be added to the answer.

---

### 1. When we see `(`

```cpp id="q5z7dn"
if (ch == '(') {
    if (depth > 0) {
        result += ch;
    }
    depth++;
}
```

First, check the current depth.

If:

```text id="9j7b2m"
depth > 0
```

the opening parenthesis is **not** outermost, so we add it.

Then increase the depth.

For the first `(` of a primitive:

```text id="x3c8nv"
depth = 0
```

we don't add it.

---

### 2. When we see `)`

```cpp id="p2q6ws"
depth--;
if (depth > 0) {
    result += ch;
}
```

We decrease the depth first.

If the new depth is still greater than `0`, this `)` is not the outermost closing parenthesis, so we keep it.

If the new depth becomes `0`, it is the outermost closing parenthesis, so we skip it.

---

## Example

Consider:

```text id="q6r8tm"
s = "(()())"
```

Process each character:

```text id="f5k2xc"
Character    Depth       Action

(            0           Skip
(            1           Add
)            2 → 1       Add
(            1           Add
)            2 → 1       Add
)            1 → 0       Skip
```

The result is:

```text id="z3n6vh"
"()()"
```

The outermost pair:

```text id="j2p8sw"
( ... )
```

has been removed.

---

### Multiple Primitive Strings

Consider:

```text id="n8m4vx"
s = "()(())"
```

Primitive decomposition:

```text id="q7c5ny"
"()" + "(())"
```

For `"()"`, removing the outer pair gives:

```text id="w6k3pm"
""
```

For `"(())"`, removing the outer pair gives:

```text id="a9v2cx"
"()"
```

Final result:

```text id="m4q8dz"
"()"
```

The `depth` automatically returns to `0` between primitive strings, so the next `(` is treated as a new outermost parenthesis.

---

## Complexity

**Time Complexity:** `O(n)`

We traverse the string exactly once.

**Space Complexity:** `O(n)`

The result string can contain up to `n` characters.

---

## Key Takeaway

The easiest way to remove outermost parentheses is to track the **nesting depth**.

The important rules are:

```text id="d8f2mx"
'(' at depth 0 → skip it
'(' at depth > 0 → keep it

')' that makes depth 0 → skip it
')' that keeps depth > 0 → keep it
```

You don't need to explicitly find each primitive substring. The `depth` counter automatically identifies its outermost parentheses.
