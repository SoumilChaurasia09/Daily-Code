# 3870. Count Commas in Range

**Problem Name:** Count Commas in Range
**Difficulty:** Easy

---

## Question

Given an integer `n`, count the total number of commas used when writing all numbers from `1` to `n` in standard number formatting.

A comma is needed for every number with at least 4 digits.

Since the constraint is:

```text
1 <= n <= 10^5
```

every number from `1000` onward has exactly one comma.

---

## My Solution

```cpp
class Solution {
public:
    int countCommas(int n) {
        if (n < 1000)
            return 0;

        return n - 999;
    }
};
```

---

## Approach

Numbers from `1` to `999` do not contain any commas.

The first number containing a comma is:

```text
1000
```

Every number from `1000` to `n` contains exactly one comma because `n <= 100000`.

So the number of integers from `1000` to `n` is:

```text
n - 1000 + 1
```

which simplifies to:

```text
n - 999
```

Therefore:

```cpp
return n - 999;
```

---

## Example 1

```text
n = 1002
```

Numbers containing commas:

```text
1000
1001
1002
```

There are `3` numbers.

```text
1002 - 999 = 3
```

Answer:

```text
3
```

---

## Example 2

```text
n = 998
```

All numbers have fewer than 4 digits.

Therefore:

```text
0
```

---

## Complexity

**Time Complexity:** `O(1)`

**Space Complexity:** `O(1)`

---

## Key Takeaway

Because `n <= 10^5`, every number that contains a comma has exactly **one comma**.

So:

```text
If n < 1000 → 0
Otherwise → n - 999
```
