# 0028. Find the Index of the First Occurrence in a String

**Problem Name:** Find the Index of the First Occurrence in a String  
**Difficulty:** Easy

---

## Question

Given two strings `haystack` and `needle`, return the index of the first occurrence of `needle` in `haystack`.

If `needle` is not found, return `-1`.

---

## My Solution

```cpp
class Solution {
public:
    int strStr(string haystack, string needle) {

        int n = haystack.size();
        int m = needle.size();

        for (int i = 0; i <= n - m; i++) {

            int j = 0;

            while (j < m && haystack[i + j] == needle[j]) {
                j++;
            }

            if (j == m) {
                return i;
            }
        }

        return -1;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(n × m)` |
| **Space Complexity** | `O(1)` |

Where:
- `n` = Length of `haystack`
- `m` = Length of `needle`

---

## What I Learned

This problem helped me understand how **substring searching** works.

I checked every possible starting position in `haystack` and compared its characters with `needle`. If all characters matched, I returned the current index. Otherwise, I continued checking the next position.

This is a simple brute-force approach and is easy to understand.

## Personal Notes

Initially, I thought about using the built-in `find()` function. However, implementing the search manually helped me understand how string matching works internally.

Although more efficient algorithms like **KMP** exist, this straightforward solution is enough for the given constraints and is much easier to understand as a beginner.
