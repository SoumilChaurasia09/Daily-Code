# 17. Letter Combinations of a Phone Number

**Problem Name:** Letter Combinations of a Phone Number
**Difficulty:** Medium

---

## Question

Given a string `digits` containing digits from `2` to `9`, return all possible letter combinations that the digits represent on a telephone keypad.

Each digit maps to several letters. Choose one letter for each digit to create every possible combination.

---

## My Solution

```cpp
class Solution {
public:
    vector<string> letterCombinations(string digits) {
        if (digits.empty()) {
            return {};
        }

        vector<string> mapping = {
            "", "", "abc", "def", "ghi",
            "jkl", "mno", "pqrs", "tuv", "wxyz"
        };

        vector<string> result;
        string current = "";

        backtrack(digits, 0, current, result, mapping);

        return result;
    }

    void backtrack(string& digits, int index, string& current,
                   vector<string>& result, vector<string>& mapping) {
        if (index == digits.size()) {
            result.push_back(current);
            return;
        }

        string letters = mapping[digits[index] - '0'];

        for (char ch : letters) {
            current.push_back(ch);

            backtrack(digits, index + 1, current, result, mapping);

            current.pop_back();
        }
    }
};
```

---

## Approach

### 1. Create the phone keypad mapping

Store the letters corresponding to each digit in a vector.

For example:

* `2` → `"abc"`
* `3` → `"def"`
* `7` → `"pqrs"`
* `9` → `"wxyz"`

The expression `digits[index] - '0'` converts a digit character into its integer value.

### 2. Use backtracking

The `backtrack()` function builds combinations one character at a time.

* `index` identifies the digit currently being processed.
* `current` stores the combination being built.
* `result` stores all completed combinations.

### 3. Add a character

For the current digit, loop through all its possible letters.

For each letter:

1. Add it to `current`.
2. Recursively process the next digit.
3. Remove the last character using `pop_back()` to try the next letter.

Removing the character allows the same string to be reused for other combinations.

### 4. Base case

When `index == digits.size()`, all digits have been processed.

Add `current` to `result` and return.

### 5. Return the result

After all possible combinations have been generated, return `result`.

---

## Example

**Input:**

```text
digits = "23"
```

Digit `2` represents `"abc"` and digit `3` represents `"def"`.

The combinations are:

```text
["ad", "ae", "af",
 "bd", "be", "bf",
 "cd", "ce", "cf"]
```

**Output:**

```text
["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

There are `3 × 3 = 9` combinations.

---

## Complexity

Let `n` be the number of digits and `k` be the number of generated combinations.

**Time Complexity:** `O(n × k)` — There are at most `4ⁿ` combinations, and each combination contains `n` characters. Therefore, the worst-case time complexity is `O(n × 4ⁿ)`.

**Space Complexity:** `O(n)` auxiliary space for the recursive call stack and the current combination, excluding the output. The output requires `O(n × k)` space.

---

## Key Takeaway

Backtracking builds combinations by choosing one letter for each digit. Add a letter, recursively process the next digit, and remove the letter to explore another possibility.
