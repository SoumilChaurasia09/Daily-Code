# 509. Fibonacci Number

**Problem Name:** Fibonacci Number
**Difficulty:** Easy

---

## Question

The Fibonacci sequence starts with `0` and `1`. Every next number is the sum of the previous two numbers.

* `F(0) = 0`
* `F(1) = 1`
* `F(n) = F(n - 1) + F(n - 2)`

Given `n`, return the `n`th Fibonacci number.

---

## My Solution

```cpp
class Solution {
public:
    int fib(int n) {
        if (n <= 1) {
            return n;
        }

        int a = 0;
        int b = 1;

        for (int i = 2; i <= n; i++) {
            int c = a + b;
            a = b;
            b = c;
        }

        return b;
    }
};
```

---

## Approach

1. **Handle the base cases:** If `n` is `0` or `1`, return `n`.
2. Initialize `a = 0` and `b = 1`, representing the first two Fibonacci numbers.
3. Start a loop from `2` to `n`.
4. Calculate the next number using `c = a + b`.
5. Update the variables:

   * `a = b`
   * `b = c`
6. After the loop, return `b`.

This approach calculates each Fibonacci number only once and uses just three variables.

---

## Example

**Input:**

```text
n = 4
```

**Calculation:**

| i |  a |  b | c = a + b |
| - | -: | -: | --------: |
| 2 |  0 |  1 |         1 |
| 3 |  1 |  1 |         2 |
| 4 |  1 |  2 |         3 |

**Output:**

```text
3
```

---

## Complexity

**Time Complexity:** `O(n)` — The loop runs `n - 1` times for `n > 1`.

**Space Complexity:** `O(1)` — Only three integer variables are used.

---

## Key Takeaway

The Fibonacci sequence can be calculated efficiently using iteration. Store the previous two numbers, add them to get the next number, and update the variables.
