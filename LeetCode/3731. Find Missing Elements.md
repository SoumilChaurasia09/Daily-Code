# 3731. Find Missing Elements

**Problem Name:** Find Missing Elements  
**Difficulty:** Easy

---

## Question

You are given an integer array `nums` containing unique integers.

Originally, the array contained every integer within a continuous range. However, some integers are missing.

The smallest and largest integers of the original range are still present.

Return all the missing integers in sorted order.

---

## My Solution

```cpp
class Solution {
public:
    vector<int> findMissingElements(vector<int>& nums) {

        unordered_set<int> st;

        int mini = nums[0];
        int maxi = nums[0];

        for (int i = 0; i < nums.size(); i++) {
            st.insert(nums[i]);
            mini = min(mini, nums[i]);
            maxi = max(maxi, nums[i]);
        }

        vector<int> ans;

        for (int i = mini; i <= maxi; i++) {

            if (st.find(i) == st.end()) {
                ans.push_back(i);
            }
        }

        return ans;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(n + (max - min))` |
| **Space Complexity** | `O(n)` |

---

## What I Learned

This problem helped me understand how to use a **Hash Set** to quickly check whether a number exists in the array.

First, I stored all the elements in an `unordered_set` while finding the smallest and largest values. Then, I checked every integer between the minimum and maximum values. If a number was not present in the set, I added it to the answer.

This made the solution simple and efficient.

---

## Personal Notes

Initially, I thought about sorting the array and checking the gaps between consecutive elements. Although that approach works, using a hash set made the implementation much simpler.

This problem reinforced the idea that hash sets are very useful for fast lookups and for finding missing values within a range.
