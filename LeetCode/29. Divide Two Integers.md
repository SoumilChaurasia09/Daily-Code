# 29. Divide Two Integers

**Problem Name:** Divide Two Integers
**Difficulty:** Medium

---

## Question

Given two integers `dividend` and `divisor`, find the quotient without using multiplication (`*`), division (`/`), or modulo (`%`).

The result should truncate toward zero.

For example:

```text
10 / 3 = 3
7 / -3 = -2
```

---

## My Solution

```cpp
class Solution {
public:
    int divide(int dividend, int divisor) {
        if (dividend == INT_MIN && divisor == -1)
            return INT_MAX;

        long long a = abs((long long)dividend);
        long long b = abs((long long)divisor);

        long long ans = 0;

        while (a >= b) {
            long long temp = b;
            long long multiple = 1;

            while (a >= temp + temp) {
                temp += temp;
                multiple += multiple;
            }

            a -= temp;
            ans += multiple;
        }

        if ((dividend < 0) != (divisor < 0))
            ans = -ans;

        return ans;
    }
};
```

---

## Approach

We cannot use normal division, so we simulate division using subtraction.

Instead of subtracting the divisor one time at a time, we repeatedly **double** it.

For example, for:

```text
10 / 3
```

we can double `3`:

```text
3 → 6 → 12
```

`12` is too large, so use `6`.

```text
10 - 6 = 4
```

Then:

```text
4 - 3 = 1
```

We used:

```text
6 = 3 × 2
3 = 3 × 1
```

Therefore:

```text
2 + 1 = 3
```

The sign is handled after calculating the positive quotient.

---

## Complexity

**Time Complexity:** `O(log² n)` approximately.

**Space Complexity:** `O(1)`.

---

## Key Takeaway

The main trick is **doubling** instead of repeatedly subtracting.

Remember this pattern:

```text
divisor
divisor × 2
divisor × 4
divisor × 8
...
```

In code, doubling can be done without multiplication:

```cpp
temp += temp;
multiple += multiple;
```

Also remember to use `long long` when working with `INT_MIN`, because its positive counterpart cannot fit inside a 32-bit `int`.

The special overflow case is:

```cpp
if (dividend == INT_MIN && divisor == -1)
    return INT_MAX;
```
