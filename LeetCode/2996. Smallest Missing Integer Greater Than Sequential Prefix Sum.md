# 2996. Smallest Missing Integer Greater Than Sequential Prefix Sum

**Problem Name:** Smallest Missing Integer Greater Than Sequential Prefix Sum  
**Difficulty:** Easy

---

## Question

Given an integer array `nums`, find the **longest sequential prefix**.

A sequential prefix means every next element is exactly `1` greater than the previous element.

For example:

```text
[1,2,3]
```

is sequential because:

```text
2 = 1 + 1
3 = 2 + 1
```

Find the sum of this longest sequential prefix.

Then return the smallest integer that is **greater than or equal to this sum** and is **not present in `nums`**.

---

## My Solution

```cpp
class Solution {
public:
    int missingInteger(vector<int>& nums) {

        int sum = nums[0];

        for (int i = 1; i < nums.size(); i++) {

            if (nums[i] == nums[i - 1] + 1) {
                sum += nums[i];
            }
            else {
                break;
            }
        }

        unordered_set<int> st;

        for (int num : nums) {
            st.insert(num);
        }

        while (st.count(sum)) {
            sum++;
        }

        return sum;
    }
};
```

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(n)` |
| **Space Complexity** | `O(n)` |

## What I Learned

This problem helped me practice finding a **sequential prefix**.

First, I started with the first element and checked whether the next element was exactly:

```cpp
nums[i - 1] + 1
```

If it was, I added it to `sum`. If not, the sequential prefix ended.

After finding the sum, I used an `unordered_set` to quickly check whether the sum was already present in the array.

If it was present, I increased `sum` until I found a number that was missing.

## Personal Notes

The important part of this problem is understanding that we only need the **longest sequential prefix**, not the entire array.

For example:

```text
nums = [1,2,3,2,5]
```

The sequential prefix is:

```text
[1,2,3]
```

Its sum is:

```text
1 + 2 + 3 = 6
```

Since `6` is not present in the array, the answer is:

```text
6
```

This problem helped me combine array traversal with a hash set for fast searching.
