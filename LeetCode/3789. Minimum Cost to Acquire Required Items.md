# 3789. Minimum Cost to Acquire Required Items

**Problem Name:** Minimum Cost to Acquire Required Items  
**Difficulty:** Medium

---

## Question

We are given five integers:

- `cost1`: Cost of one type 1 item.
- `cost2`: Cost of one type 2 item.
- `costBoth`: Cost of one type 3 item.
- `need1`: Required contribution for type 1.
- `need2`: Required contribution for type 2.

There are three types of items:

1. Type 1 contributes to requirement 1 only.
2. Type 2 contributes to requirement 2 only.
3. Type 3 contributes to both requirements.

We need to find the minimum total cost to satisfy both requirements.

---

## My Solution

```cpp
class Solution {
public:
    long long minimumCost(int cost1, int cost2, int costBoth, int need1, int need2) {
        long long option1 = 1LL * need1 * cost1 + 1LL * need2 * cost2;

        int common = min(need1, need2);

        long long option2 = 1LL * common * costBoth
                          + 1LL * (need1 - common) * cost1
                          + 1LL * (need2 - common) * cost2;

        long long option3 = 1LL * max(need1, need2) * costBoth;

        return min({option1, option2, option3});
    }
};
```

---

## Approach

We use a **Greedy approach with three possible strategies**.

### Step 1: Buy only individual items

Buy all type 1 and type 2 items separately.

```cpp
long long option1 = 1LL * need1 * cost1 + 1LL * need2 * cost2;
```

Formula:

`option1 = need1 × cost1 + need2 × cost2`

### Step 2: Buy common items for shared requirements

Buy type 3 items for the minimum of `need1` and `need2`.

```cpp
int common = min(need1, need2);
```

After buying common items, purchase the remaining individual items.

```cpp
long long option2 = 1LL * common * costBoth
                  + 1LL * (need1 - common) * cost1
                  + 1LL * (need2 - common) * cost2;
```

### Step 3: Buy only common items

We can also purchase type 3 items for the entire larger requirement.

```cpp
long long option3 = 1LL * max(need1, need2) * costBoth;
```

This may be cheaper even though some contributions exceed the smaller requirement.

### Step 4: Find the minimum cost

```cpp
return min({option1, option2, option3});
```

Compare all three strategies and return the cheapest one.

**Why are these three strategies sufficient?**

Let `x` represent the number of type 3 items.

There are three important possibilities:

1. `x = 0`: Buy only individual items.
2. `x = min(need1, need2)`: Satisfy the smaller requirement using common items.
3. `x = max(need1, need2)`: Satisfy both requirements using only common items.

Between these points, the total cost changes linearly. Therefore, the minimum occurs at one of these three boundaries.

---

## Example

**Input:**

```text
cost1 = 3
cost2 = 2
costBoth = 1
need1 = 3
need2 = 2
```

### Step 1: Individual items

```text
option1 = (3 × 3) + (2 × 2)
        = 9 + 4
        = 13
```

### Step 2: Common items + individual items

```text
common = min(3, 2) = 2

option2 = (2 × 1) + (1 × 3) + (0 × 2)
        = 2 + 3
        = 5
```

### Step 3: Only common items

```text
option3 = max(3, 2) × 1
        = 3
```

### Step 4: Find minimum

```text
answer = min(13, 5, 3)
       = 3
```

**Output:**

```text
3
```

## Complexity

**Time Complexity:** `O(1)`

Only a constant number of arithmetic operations and comparisons are performed.

**Space Complexity:** `O(1)`

Only a few variables are used.

---

## Key Takeaway

The main concept is **Greedy + Mathematical Optimization**.

Compare three strategies:

1. Buy all individual items.
2. Buy common items for the shared requirement and individual items for the remaining requirements.
3. Buy only common items, allowing extra contributions if necessary.

Choose the minimum cost.

**Important:** Always use `long long` because the requirements can reach `10^9`, and multiplication can exceed the 32-bit integer limit.
