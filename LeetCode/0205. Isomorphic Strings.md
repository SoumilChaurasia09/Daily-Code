# 0205. Isomorphic Strings

**Problem Name:** Isomorphic Strings  
**Difficulty:** Easy

---

## Question

Given two strings `s` and `t`, determine whether they are **isomorphic**.

Two strings are isomorphic if every character in `s` can be replaced to get `t`.

Rules:

- Every character must always map to the same character.
- No two different characters can map to the same character.
- A character may map to itself.

---

## My Solution

```cpp
class Solution {
public:
    bool isIsomorphic(string s, string t) {

        unordered_map<char, char> mp1;
        unordered_map<char, char> mp2;

        for (int i = 0; i < s.size(); i++) {

            if (mp1.count(s[i])) {

                if (mp1[s[i]] != t[i]) {
                    return false;
                }
            }
            else {

                if (mp2.count(t[i])) {
                    return false;
                }

                mp1[s[i]] = t[i];
                mp2[t[i]] = s[i];
            }
        }

        return true;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(n)` |
| **Space Complexity** | `O(n)` |

---

## What I Learned

This problem helped me understand how to maintain a **one-to-one mapping** between characters of two strings.

I used two hash maps:

- One map stored the mapping from characters in `s` to characters in `t`.
- The other map stored the reverse mapping from `t` to `s`.

By checking both maps, I ensured that each character mapped consistently and that no two different characters mapped to the same character.

---

## Personal Notes

Initially, I thought using a single hash map would be enough. However, I realized that one map cannot detect cases where two different characters map to the same character.

Using two hash maps made the solution straightforward and correctly handled all cases. This problem also strengthened my understanding of hash maps and one-to-one relationships.
