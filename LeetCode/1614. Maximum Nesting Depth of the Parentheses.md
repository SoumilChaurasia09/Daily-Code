# 1614. Maximum Nesting Depth of the Parentheses

**Problem Name:** Maximum Nesting Depth of the Parentheses
**Difficulty:** Easy

---

## Question

Given a valid parentheses string `s`, find the maximum number of parentheses that are open at the same time.

This maximum number is called the **nesting depth**.

---

## My Solution

```cpp
class Solution {
public:
    int maxDepth(string s) {
        int depth = 0;
        int maxDepth = 0;

        for (char ch : s) {
            if (ch == '(') {
                depth++;
                maxDepth = max(maxDepth, depth);
            }
            else if (ch == ')') {
                depth--;
            }
        }

        return maxDepth;
    }
};
```

---

## Approach

We keep track of the current nesting level using `depth`.

### 1. Opening parenthesis

Whenever we find:

```cpp
if (ch == '(')
```

we increase the current depth:

```cpp
depth++;
```

Then update the maximum depth:

```cpp
maxDepth = max(maxDepth, depth);
```

### 2. Closing parenthesis

Whenever we find:

```cpp
else if (ch == ')')
```

we decrease the current depth:

```cpp
depth--;
```

Because the input is guaranteed to be a valid parentheses string, `depth` will never become invalid.

### 3. Ignore other characters

Digits and operators such as:

```text
1 2 3 + - * /
```

do not affect the nesting depth, so we simply ignore them.

---

## Example

For:

```text
(1+(2*3)+((8)/4))+1
```

When processing the parentheses:

```text
(
( (
```

The maximum number of simultaneously open parentheses is `3`.

Therefore:

```text
maxDepth = 3
```

The answer is:

```text
3
```

Another example:

```text
(1)+((2))+(((3)))
```

The deepest part is:

```text
(((3)))
```

There are three open parentheses around `3`.

Therefore:

```text
3
```

---

## Complexity

**Time Complexity:** `O(n)`

We traverse the string once.

**Space Complexity:** `O(1)`

Only two integer variables are used.

---

## Key Takeaway

For nesting-depth problems, maintain a counter:

```text
'(' → depth++
')' → depth--
```

Track the maximum value reached by `depth`.

The maximum value is the **maximum nesting depth**.
