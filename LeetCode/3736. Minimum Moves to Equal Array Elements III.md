# 3736. Minimum Moves to Equal Array Elements III

**Problem Name:** Minimum Moves to Equal Array Elements III
**Difficulty:** Easy

---

## Question

We are given an integer array `nums`.

In one move, we can increase any single element by `1`.

We need to make all array elements equal using the minimum number of moves.

Since we can only increase elements, the best target is the **maximum element** in the array.

---

## My Solution

```cpp
class Solution {
public:
    int minMoves(vector<int>& nums) {
        int maxElement = *max_element(nums.begin(), nums.end());

        int moves = 0;

        for (int num : nums) {
            moves += maxElement - num;
        }

        return moves;
    }
};
```

---

## Approach

### Step 1: Find the maximum element

```cpp
int maxElement = *max_element(nums.begin(), nums.end());
```

We find the largest element because we can only increase values, not decrease them.

Therefore, every element must be increased to at least the maximum existing value.

### Step 2: Calculate the required moves

```cpp
for (int num : nums) {
    moves += maxElement - num;
}
```

For every element, calculate the difference between the maximum element and the current element.

This difference represents the number of increments required.

### Step 3: Return the total moves

```cpp
return moves;
```

Add all the differences to get the minimum total number of moves.

---

## Example

**Input:**

```text
nums = [2, 1, 3]
```

### Step 1: Find the maximum element

```text
maxElement = 3
```

### Step 2: Calculate the moves

| Element | Calculation | Moves |
| ------- | ----------- | ----- |
| 2       | 3 - 2       | 1     |
| 1       | 3 - 1       | 2     |
| 3       | 3 - 3       | 0     |

### Step 3: Calculate total moves

```text
moves = 1 + 2 + 0
      = 3
```

**Output:**

```text
3
```

### Another Example

**Input:**

```text
nums = [4, 4, 5]
```

Maximum element:

```text
maxElement = 5
```

Total moves:

```text
moves = (5 - 4) + (5 - 4) + (5 - 5)
      = 1 + 1 + 0
      = 2
```

**Output:**

```text
2
```

---

## Complexity

**Time Complexity:** `O(n)`

* Finding the maximum element takes `O(n)`.
* Calculating the total moves takes `O(n)`.

**Space Complexity:** `O(1)`

Only a few extra variables are used.

---

## Key Takeaway

The main concept is **Greedy + Maximum Element**.

Since we can only increase elements, the optimal target is always the maximum element already present in the array.

**Formula:**

```text
Minimum Moves = Σ (Maximum Element - nums[i])
```
