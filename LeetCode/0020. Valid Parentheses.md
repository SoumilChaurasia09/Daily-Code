# 0020. Valid Parentheses

**Problem Name:** Valid Parentheses  
**Difficulty:** Easy

---

## Question

Given a string `s` containing only the characters:

- `(`
- `)`
- `{`
- `}`
- `[`
- `]`

Determine whether the string is valid.

A string is valid if:

- Every opening bracket has a matching closing bracket.
- Brackets are closed in the correct order.
- Every closing bracket corresponds to the correct opening bracket.

---

## My Solution

```cpp
class Solution {
public:
    bool isValid(string s) {

        stack<char> st;

        for (int i = 0; i < s.size(); i++) {

            if (s[i] == '(' || s[i] == '{' || s[i] == '[') {
                st.push(s[i]);
            }
            else {

                if (st.empty()) {
                    return false;
                }

                if ((s[i] == ')' && st.top() != '(') ||
                    (s[i] == '}' && st.top() != '{') ||
                    (s[i] == ']' && st.top() != '[')) {
                    return false;
                }

                st.pop();
            }
        }

        return st.empty();
    }
};
```

## What I Learned

This problem introduced me to the **Stack** data structure.

Whenever I found an opening bracket, I pushed it onto the stack. When I encountered a closing bracket, I checked whether it matched the bracket at the top of the stack. If it matched, I removed it; otherwise, the string was invalid.

At the end, if the stack was empty, it meant every opening bracket had a matching closing bracket.

---

## Personal Notes

Initially, I tried solving this problem using counters, but that approach doesn't work for different types of brackets and their order.

Using a stack made the solution much cleaner because the most recently opened bracket must always be closed first. This problem helped me understand why stacks are commonly used for matching parentheses and nested structures.
