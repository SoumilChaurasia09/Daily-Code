# 75. Sort Colors

**Problem Name:** Sort Colors
**Difficulty:** Medium

---

## Question

Given an array containing only `0`, `1`, and `2`, sort the array in-place so that:

```text
0 0 ... 1 1 ... 2 2
```

The solution should not use the library's `sort()` function.

---

## My Solution

```cpp
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int low = 0;
        int mid = 0;
        int high = nums.size() - 1;

        while (mid <= high) {
            if (nums[mid] == 0) {
                swap(nums[low], nums[mid]);
                low++;
                mid++;
            }
            else if (nums[mid] == 1) {
                mid++;
            }
            else {
                swap(nums[mid], nums[high]);
                high--;
            }
        }
    }
};
```

---

## Approach

Use three pointers:

* `low` points to the position where the next `0` should be placed.
* `mid` points to the current element being checked.
* `high` points to the position where the next `2` should be placed.

There are three cases:

### If the current element is `0`

Swap it with `nums[low]` and move both `low` and `mid`.

### If the current element is `1`

It is already in the correct middle section, so only move `mid`.

### If the current element is `2`

Swap it with `nums[high]` and move `high`.

We don't move `mid` in this case because the element received from `high` has not been checked yet.

---

## Complexity

**Time Complexity:** `O(n)`

**Space Complexity:** `O(1)`

---

## Key Takeaway

Use three pointers:

```text
low → 0s
mid → current element
high → 2s
```

The main pattern is:

```cpp
0 → swap with low, move low and mid
1 → move mid
2 → swap with high, move high
```

This allows the array to be sorted in one pass without using `sort()`.
