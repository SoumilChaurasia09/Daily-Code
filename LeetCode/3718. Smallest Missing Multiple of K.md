# 3718. Smallest Missing Multiple of K

**Problem Name:** Smallest Missing Multiple of K
**Difficulty:** Easy

---

## Question

Given an integer array `nums` and an integer `k`, find the smallest positive multiple of `k` that is not present in `nums`.

For example:

```text
nums = [8,2,3,4,6]
k = 2
```

The multiples of `2` are:

```text
2, 4, 6, 8, 10, ...
```

Since `2`, `4`, `6`, and `8` exist but `10` does not, the answer is `10`.

---

## My Solution

```cpp
class Solution {
public:
    int missingMultiple(vector<int>& nums, int k) {
        unordered_set<int> s(nums.begin(), nums.end());

        int multiple = k;

        while (s.count(multiple)) {
            multiple += k;
        }

        return multiple;
    }
};
```

---

## Approach

First, store all elements of `nums` in an `unordered_set`.

Then start checking multiples of `k` from `k`:

```text
k, 2k, 3k, 4k, ...
```

For each multiple, check whether it exists in the set.

If it exists, move to the next multiple:

```cpp
multiple += k;
```

When we find a multiple that does not exist, return it.

---

## Complexity

**Time Complexity:** `O(n + m)` average, where `n` is the array size and `m` is the number of multiples checked.

**Space Complexity:** `O(n)`.

---

## Key Takeaway

When you need to find a missing value from a collection, an `unordered_set` provides a simple way to check whether a value exists.

For this problem, check multiples in order:

```text
k → 2k → 3k → 4k → ...
```

The first missing multiple is the answer.
