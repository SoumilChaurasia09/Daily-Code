# 888. Fair Candy Swap

**Problem Name:** Fair Candy Swap
**Difficulty:** Easy

---

## Question

Alice and Bob have different total numbers of candies.

They need to exchange exactly one candy box each so that both have the same total number of candies.

Return the candy count of the box Alice gives and the candy count of the box Bob gives.

---

## My Solution

```cpp
class Solution {
public:
    vector<int> fairCandySwap(vector<int>& aliceSizes, vector<int>& bobSizes) {
        int sumA = 0, sumB = 0;

        for (int x : aliceSizes)
            sumA += x;

        for (int x : bobSizes)
            sumB += x;

        int diff = (sumA - sumB) / 2;

        unordered_set<int> bob;

        for (int x : bobSizes)
            bob.insert(x);

        for (int x : aliceSizes) {
            int y = x - diff;

            if (bob.count(y)) {
                return {x, y};
            }
        }

        return {};
    }
};
```

---

## Approach

Suppose:

* Alice has total `sumA`
* Bob has total `sumB`
* Alice gives `x`
* Bob gives `y`

After swapping:

```text
Alice = sumA - x + y
Bob   = sumB - y + x
```

We need:

```text
sumA - x + y = sumB - y + x
```

Rearranging:

```text
x - y = (sumA - sumB) / 2
```

Therefore:

```text
y = x - (sumA - sumB) / 2
```

For every box `x` belonging to Alice, we calculate the required box `y` from Bob.

We store all Bob's box sizes in an `unordered_set` so we can quickly check whether `y` exists.

---

## Example

```text
Alice = [1, 1]
Bob   = [2, 2]

sumA = 2
sumB = 4

diff = (2 - 4) / 2
     = -1
```

For Alice's box `x = 1`:

```text
y = 1 - (-1)
  = 2
```

Bob has a box containing `2` candies.

So:

```text
Answer = [1, 2]
```

After swapping:

```text
Alice = 2 - 1 + 2 = 3
Bob   = 4 - 2 + 1 = 3
```

Both have `3` candies.

---

## Complexity

**Time Complexity:** `O(n + m)`

**Space Complexity:** `O(m)`

Where `n` is the number of Alice's boxes and `m` is the number of Bob's boxes.

---

## Key Takeaway

The important part is the equation:

```text
Alice's box - Bob's box = (Alice total - Bob total) / 2
```

Using a hash set lets us find the required Bob box in approximately `O(1)` time.
