# 0069. Sqrt(x)

**Problem Name:** Sqrt(x)  
**Difficulty:** Easy

---

## Question

Given a non-negative integer `x`, return the square root of `x` rounded down to the nearest integer.

You must not use any built-in square root or exponent functions.

---

## My Solution

```cpp
class Solution {
public:
    int mySqrt(int x) {

        if (x == 0) {
            return 0;
        }

        int left = 1;
        int right = x;
        int ans = 0;

        while (left <= right) {

            long long mid = left + (right - left) / 2;

            if (mid * mid == x) {
                return mid;
            }

            if (mid * mid < x) {
                ans = mid;
                left = mid + 1;
            }
            else {
                right = mid - 1;
            }
        }

        return ans;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(log n)` |
| **Space Complexity** | `O(1)` |

---

## What I Learned

This problem helped me understand how **Binary Search** can be applied to find the square root of a number.

Instead of checking every number one by one, I searched within the range `1` to `x`. If `mid * mid` was less than or equal to `x`, I stored `mid` as a possible answer and searched the right half. Otherwise, I searched the left half.

Using `long long` prevented integer overflow when calculating `mid * mid`.

---

## Personal Notes

Initially, I thought about checking every number from `1` until its square became larger than `x`. While that approach works, it takes `O(√n)` time.

Using Binary Search reduced the time complexity to `O(log n)`, making the solution much faster for large values of `x`. This problem also reinforced how Binary Search can be used on the answer space, not just on sorted arrays.
