# 3. Longest Substring Without Repeating Characters

**Problem Name:** Longest Substring Without Repeating Characters
**Difficulty:** Medium

---

## Question

Given a string `s`, find the length of the longest substring that contains no repeated characters.

For example:

```text
s = "abcabcbb"
```

The longest substring without repeating characters is:

```text
"abc"
```

Its length is `3`.

---

## My Solution

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        vector<int> last(256, -1);

        int left = 0;
        int ans = 0;

        for (int right = 0; right < s.length(); right++) {
            if (last[s[right]] >= left) {
                left = last[s[right]] + 1;
            }

            last[s[right]] = right;
            ans = max(ans, right - left + 1);
        }

        return ans;
    }
};
```

---

## Approach

Use the **sliding window** technique.

We maintain a window from `left` to `right` that contains no duplicate characters.

The `last` array stores the most recent index where each character appeared.

When we find a repeated character:

```cpp
if (last[s[right]] >= left)
```

move `left` just after its previous position:

```cpp
left = last[s[right]] + 1;
```

Then update the character's latest position:

```cpp
last[s[right]] = right;
```

The current window length is:

```cpp
right - left + 1
```

Keep the maximum length in `ans`.

For:

```text
"abcabcbb"
```

the window grows to:

```text
"abc"
```

When the second `a` appears, move `left` forward and continue.

---

## Complexity

**Time Complexity:** `O(n)`

**Space Complexity:** `O(1)`

The `last` array has a fixed size of `256`.

---

## Key Takeaway

This is a classic **sliding window** problem.

Remember the pattern:

```text
right → expand the window
duplicate → move left
update answer
```

The important formula is:

```cpp
right - left + 1
```

which gives the current window length.
