# 0231. Power of Two

**Problem Name:** Power of Two  
**Difficulty:** Easy

---

## Question

Given an integer `n`, return `true` if it is a power of two. Otherwise, return `false`.

An integer is a power of two if there exists an integer `x` such that:

```text
n = 2^x
```

---

## My Solution

```cpp
class Solution {
public:
    bool isPowerOfTwo(int n) {

        if (n <= 0) {
            return false;
        }

        while (n % 2 == 0) {
            n = n / 2;
        }

        return n == 1;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(log n)` |
| **Space Complexity** | `O(1)` |

---

## What I Learned

This problem helped me understand how powers of two behave.

If a number is a power of two, it can be divided by `2` repeatedly until it becomes `1`. If, after all possible divisions, the number is exactly `1`, then it is a power of two.

I also learned to handle negative numbers and zero first because they cannot be powers of two.

---

## Personal Notes

Initially, I thought about multiplying `2` repeatedly until it became equal to the given number. However, dividing the number by `2` until it reached `1` was a much simpler approach.

I also discovered that there is a clever bit manipulation solution using `n & (n - 1)` that runs in `O(1)` time, but this loop-based solution was easier for me to understand while learning the concept.
