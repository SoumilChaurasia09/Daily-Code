# 0242. Valid Anagram

**Problem Name:** Valid Anagram  
**Difficulty:** Easy

---

## Question

Given two strings `s` and `t`, determine whether `t` is an anagram of `s`.

An anagram is a word or phrase formed by rearranging the letters of another word, using all the original letters exactly once.

Return `true` if `t` is an anagram of `s`; otherwise, return `false`.

---

## My Solution

```cpp
class Solution {
public:
    bool isAnagram(string s, string t) {

        if (s.size() != t.size()) {
            return false;
        }

        vector<int> freq(26, 0);

        for (int i = 0; i < s.size(); i++) {
            freq[s[i] - 'a']++;
            freq[t[i] - 'a']--;
        }

        for (int i = 0; i < 26; i++) {

            if (freq[i] != 0) {
                return false;
            }

        }

        return true;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(n)` |
| **Space Complexity** | `O(1)` |

---

## What I Learned

This problem helped me understand how to use a **frequency array** to compare two strings.

I counted the frequency of each character in the first string and subtracted the frequency of the corresponding character from the second string. If every frequency became zero, it meant both strings contained the same characters with the same counts.

This approach is simple and more efficient than sorting both strings.

---

## Personal Notes

Initially, I thought about sorting both strings and then comparing them. Although that solution works, it takes `O(n log n)` time.

Using a frequency array reduced the time complexity to `O(n)` while keeping the code simple. This problem reinforced how counting frequencies is a common and efficient technique for solving string-related problems.
