# 241. Different Ways to Add Parentheses

**Problem Name:** Different Ways to Add Parentheses
**Difficulty:** Medium

---

## Question

Given a mathematical expression containing numbers and the operators `+`, `-`, and `*`, return all possible results from computing the expression with different valid ways of adding parentheses.

For example:

```text
2*3-4*5
```

can be evaluated in different ways depending on where we place parentheses.

---

## My Solution

```cpp
class Solution {
public:
    vector<int> diffWaysToCompute(string expression) {
        vector<int> result;

        for (int i = 0; i < expression.size(); i++) {
            char op = expression[i];

            if (op == '+' || op == '-' || op == '*') {
                vector<int> left = diffWaysToCompute(expression.substr(0, i));
                vector<int> right = diffWaysToCompute(expression.substr(i + 1));

                for (int a : left) {
                    for (int b : right) {
                        if (op == '+')
                            result.push_back(a + b);
                        else if (op == '-')
                            result.push_back(a - b);
                        else
                            result.push_back(a * b);
                    }
                }
            }
        }

        if (result.empty())
            result.push_back(stoi(expression));

        return result;
    }
};
```

---

## Approach

The main idea is **recursion**.

We scan the expression and treat every operator as a possible place to split the expression.

For example:

```text
2*3-4*5
```

If we choose `-` as the main operator:

```text
2*3  -  4*5
```

We recursively calculate all possible results on the left and right sides.

Then we combine every left result with every right result using the selected operator.

For example:

```text
left = [6]
right = [20]

6 - 20 = -14
```

We repeat this for every operator.

---

## Base Case

If there is no operator in the expression, it is simply a number.

For example:

```text
"12"
```

There is only one possible result:

```cpp
stoi("12")
```

So we add it to the result:

```cpp
if (result.empty())
    result.push_back(stoi(expression));
```

---

## How the Recursion Works

For every operator:

```text
Expression
   |
   ├── Left part
   |
   └── Right part
```

We calculate:

```text
all possible left results
all possible right results
```

Then combine them:

```text
for every left result
    for every right result
        apply the operator
```

This generates every possible valid result.

---

## Example

For:

```text
2-1-1
```

Possible calculations are:

```text
(2-1)-1 = 0
2-(1-1) = 2
```

Therefore:

```text
[0, 2]
```

---

## Complexity

**Time Complexity:** Approximately `O(n × Cn)`

where `Cn` represents the number of different parenthesizations. The number of possible results grows exponentially with the number of operators.

**Space Complexity:** `O(Cn)` for storing the results and recursive calls.

---

## Key Takeaway

For expression problems where different parenthesizations can produce different answers:

```text
Choose each operator as a split
        ↓
Recursively solve left side
        ↓
Recursively solve right side
        ↓
Combine all possible results
```

This is a classic **Divide and Conquer + Recursion** problem.
