# 22. Generate Parentheses

**Problem Name:** Generate Parentheses
**Difficulty:** Medium

---

## Question

Given `n` pairs of parentheses, generate all possible combinations of parentheses that are **well-formed**.

For example, when `n = 3`, we need exactly 3 opening and 3 closing parentheses.

A valid combination must never have more closing parentheses than opening parentheses at any point.

---

## My Solution

```cpp id="8xqk2m"
class Solution {
public:
    void generate(int n, int open, int close, string current, vector<string>& ans) {
        if (current.size() == 2 * n) {
            ans.push_back(current);
            return;
        }

        if (open < n) {
            generate(n, open + 1, close, current + "(", ans);
        }

        if (close < open) {
            generate(n, open, close + 1, current + ")", ans);
        }
    }

    vector<string> generateParenthesis(int n) {
        vector<string> ans;
        generate(n, 0, 0, "", ans);
        return ans;
    }
};
```

---

## Approach

We use **backtracking** to build the parentheses string one character at a time.

We keep track of:

* `open` = number of `(` used
* `close` = number of `)` used
* `current` = current parentheses string

There are two important rules.

### 1. We can add `(`

```cpp id="4gk0nf"
if (open < n)
```

We can add an opening parenthesis as long as we have not used all `n` opening parentheses.

```cpp id="3imj5n"
generate(n, open + 1, close, current + "(", ans);
```

---

### 2. We can add `)`

```cpp id="9w6w5f"
if (close < open)
```

A closing parenthesis can only be added when there is an unmatched opening parenthesis.

For example:

```text id="o7f6z8"
"(" → ")" is allowed
""   → ")" is not allowed
```

This prevents invalid strings such as:

```text id="m6vl86"
")("
"())("
```

---

### 3. Stop when the string is complete

Each valid answer contains exactly `n` opening and `n` closing parentheses, so its length is:

```cpp id="x6n9pf"
2 * n
```

When we reach this length:

```cpp id="y6gq3t"
if (current.size() == 2 * n)
```

we add the string to `ans`.

---

## Example

For:

```text id="f3l7dx"
n = 2
```

We start with:

```text id="u5t9ds"
""
```

We can add `(`:

```text id="z6wq5q"
"("
```

From `"("`, we can either:

```text id="z1qjz2"
"(("
"()"
```

From `"(("`, we can add `)`:

```text id="t3w7jb"
"(()"
```

Then:

```text id="j5l6c2"
"(())"
```

From `"()"`, we can add another `(`:

```text id="3kg0ey"
"()("
```

Then:

```text id="t5y6m3"
"()()"
```

So the result is:

```text id="m1z1pw"
["(())", "()()"]
```

For `n = 3`, the algorithm generates:

```text id="u8gk3v"
["((()))", "(()())", "(())()", "()(())", "()()()"]
```

---

## Complexity

**Time Complexity:** `O(Cₙ × n)`

Where `Cₙ` is the number of valid parentheses combinations, given by the `n`th Catalan number:

```text id="f4j5qn"
Cₙ = (1 / (n + 1)) × C(2n, n)
```

Each generated string has length `2n`, so we spend `O(n)` time to construct each result.

**Space Complexity:** `O(n)`

The recursion depth is at most `2n`. The returned result itself requires additional space proportional to the number of generated strings.

---

## Key Takeaway

For generating all valid combinations, use **backtracking** with rules that prevent invalid choices.

The two important conditions are:

```text id="b8x5sj"
open < n
close < open
```

Remember:

* You can always add `(` until `n` opening parentheses are used.
* You can add `)` only when there are more opening parentheses than closing parentheses.
* When the length reaches `2 * n`, the combination is valid.
