# 383. Ransom Note

**Problem Name:** Ransom Note
**Difficulty:** Easy

---

## Question

Given two strings, `ransomNote` and `magazine`, return `true` if `ransomNote` can be constructed using letters from `magazine`. Each letter in `magazine` can be used only once.

---

## My Solution

```cpp
class Solution {
public:
    bool canConstruct(string ransomNote, string magazine) {
        int count[26] = {};

        for (char ch : magazine) {
            count[ch - 'a']++;
        }

        for (char ch : ransomNote) {
            if (count[ch - 'a'] == 0) {
                return false;
            }

            count[ch - 'a']--;
        }

        return true;
    }
};
```

---

## Approach

1. Create an array `count[26]` to store the frequency of each lowercase English letter.
2. Traverse `magazine` and count how many times each letter appears.
3. Traverse `ransomNote`:

   * If the required letter has a count of `0`, return `false`.
   * Otherwise, decrease its count by `1` because that letter has been used.
4. If every letter is available, return `true`.

### Important Logic

`ch - 'a'` converts a lowercase letter into an array index:

* `'a' - 'a' = 0`
* `'b' - 'a' = 1`
* `'z' - 'a' = 25`

Decreasing the count ensures that each magazine letter is used at most once.

---

## Example

**Input:**

```text
ransomNote = "aa"
magazine = "aab"
```

**Execution:**

* Count letters in `magazine`: `a = 2`, `b = 1`.
* First `'a'`: count decreases from `2` to `1`.
* Second `'a'`: count decreases from `1` to `0`.
* Both letters are available, so return `true`.

**Output:**

```text
true
```

---

## Complexity

**Time Complexity:** `O(n + m)`, where `n` is the length of `ransomNote` and `m` is the length of `magazine`.

**Space Complexity:** `O(1)` — The frequency array always contains exactly 26 elements.

---

## Key Takeaway

Use a frequency array to count available characters. Check each required character and decrease its count whenever it is used.
