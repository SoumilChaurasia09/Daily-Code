# 18. 4Sum

**Problem Name:** 4Sum
**Difficulty:** Medium

---

## Question

Given an integer array `nums` and a target value, find all unique groups of four different elements whose sum equals the target.

For example:

```text
nums = [1,0,-1,0,-2,2]
target = 0
```

The unique quadruplets are:

```text
[-2,-1,1,2]
[-2,0,0,2]
[-1,0,0,1]
```

---

## My Solution

```cpp
class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, long long target) {
        vector<vector<int>> ans;
        int n = nums.size();

        sort(nums.begin(), nums.end());

        for (int i = 0; i < n - 3; i++) {
            if (i > 0 && nums[i] == nums[i - 1])
                continue;

            for (int j = i + 1; j < n - 2; j++) {
                if (j > i + 1 && nums[j] == nums[j - 1])
                    continue;

                int left = j + 1;
                int right = n - 1;

                while (left < right) {
                    long long sum = (long long)nums[i] + nums[j] +
                                    nums[left] + nums[right];

                    if (sum == target) {
                        ans.push_back({nums[i], nums[j], nums[left], nums[right]});

                        left++;
                        right--;

                        while (left < right && nums[left] == nums[left - 1])
                            left++;

                        while (left < right && nums[right] == nums[right + 1])
                            right--;
                    }
                    else if (sum < target) {
                        left++;
                    }
                    else {
                        right--;
                    }
                }
            }
        }

        return ans;
    }
};
```

---

## Approach

First, sort the array.

Then fix the first two elements using two loops:

```text
i → first element
j → second element
```

For the remaining two elements, use two pointers:

```text
left → beginning
right → end
```

Calculate:

```text
nums[i] + nums[j] + nums[left] + nums[right]
```

### If sum equals target

Store the quadruplet and move both pointers:

```text
left++
right--
```

### If sum is smaller than target

Move `left` forward to increase the sum.

### If sum is greater than target

Move `right` backward to decrease the sum.

### Avoid duplicates

Because the answer must contain only unique quadruplets, skip equal values for `i`, `j`, `left`, and `right`.

For example:

```cpp
if (i > 0 && nums[i] == nums[i - 1])
    continue;
```

This prevents generating the same quadruplet multiple times.

### Why use `long long`?

The values can be as large as `10^9`.

Adding four such values can exceed the range of a normal `int`, so the sum is calculated using `long long`.

---

## Complexity

**Time Complexity:** `O(n^3)`

Two elements are fixed using loops, and the remaining two are searched using two pointers.

**Space Complexity:** `O(1)` auxiliary space, excluding the output.

---

## Key Takeaway

This problem is an extension of the **3Sum** pattern.

The basic structure is:

```text
Sort
  ↓
Fix first element
  ↓
Fix second element
  ↓
Use two pointers for the remaining two
  ↓
Skip duplicates
```

The important pattern is:

```cpp
int left = j + 1;
int right = n - 1;

while (left < right) {
    long long sum = ...;

    if (sum == target) {
        left++;
        right--;
    }
    else if (sum < target) {
        left++;
    }
    else {
        right--;
    }
}
```
