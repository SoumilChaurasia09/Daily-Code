# 0007. Reverse Integer

**Problem Name:** Reverse Integer  
**Difficulty:** Medium

---

## Question

Given a signed 32-bit integer `x`, return the integer with its digits reversed.

If reversing the integer causes it to go outside the 32-bit signed integer range `[-2³¹, 2³¹ - 1]`, return `0`.

You are not allowed to use a 64-bit integer.

---

## My Solution

```cpp
class Solution {
public:
    int reverse(int x) {

        int rev = 0;

        while (x != 0) {

            int digit = x % 10;

            if (rev > INT_MAX / 10 || (rev == INT_MAX / 10 && digit > 7))
                return 0;

            if (rev < INT_MIN / 10 || (rev == INT_MIN / 10 && digit < -8))
                return 0;

            rev = rev * 10 + digit;
            x = x / 10;
        }

        return rev;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(log n)` |
| **Space Complexity** | `O(1)` |

## What I Learned

This problem helped me understand how to reverse an integer using arithmetic operations.

I extracted the last digit using the modulo (`%`) operator and built the reversed number one digit at a time. Before adding each digit, I checked whether the new value would exceed the 32-bit integer range.

These overflow checks ensure the function returns `0` whenever the reversed number cannot fit into an `int`.

---

## Personal Notes

Initially, I thought about storing the reversed number in a `long long`, but the problem specifically asks for a solution without using a 64-bit integer.

Learning how to detect overflow before it happens was the most important part of this problem. It also improved my understanding of integer limits (`INT_MAX` and `INT_MIN`) and safe arithmetic operations.
