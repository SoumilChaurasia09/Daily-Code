# 0367. Valid Perfect Square

**Problem Name:** Valid Perfect Square  
**Difficulty:** Easy

---

## Question

Given a positive integer `num`, return `true` if it is a perfect square; otherwise, return `false`.

A perfect square is an integer that is the square of an integer.

You must **not** use any built-in library function such as `sqrt()`.

---

## My Solution

```cpp
class Solution {
public:
    bool isPerfectSquare(int num) {

        int odd = 1;

        while (num > 0) {
            num = num - odd;
            odd = odd + 2;
        }

        return num == 0;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(√n)` |
| **Space Complexity** | `O(1)` |

---

## What I Learned

This problem introduced me to a mathematical property of perfect squares.

A perfect square can be obtained by adding consecutive odd numbers:

```text
1 = 1
4 = 1 + 3
9 = 1 + 3 + 5
16 = 1 + 3 + 5 + 7
25 = 1 + 3 + 5 + 7 + 9
```

Instead of adding odd numbers, I repeatedly subtracted odd numbers from the given value.

- If the final result became `0`, the number was a perfect square.
- If it became negative, the number was not a perfect square.
