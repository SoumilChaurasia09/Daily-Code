# 43. Multiply Strings

**Problem Name:** Multiply Strings
**Difficulty:** Medium

---

## Question

Given two non-negative integers represented as strings, return their product as a string.

We cannot directly convert the strings into integers or use a BigInteger library.

For example:

```text
num1 = "123"
num2 = "456"

Output = "56088"
```

---

## My Solution

```cpp
class Solution {
public:
    string multiply(string num1, string num2) {
        if (num1 == "0" || num2 == "0") {
            return "0";
        }

        int n = num1.size();
        int m = num2.size();

        vector<int> result(n + m, 0);

        for (int i = n - 1; i >= 0; i--) {
            for (int j = m - 1; j >= 0; j--) {
                int a = num1[i] - '0';
                int b = num2[j] - '0';

                int product = a * b;

                int pos1 = i + j;
                int pos2 = i + j + 1;

                int sum = product + result[pos2];

                result[pos2] = sum % 10;
                result[pos1] += sum / 10;
            }
        }

        string ans = "";

        for (int digit : result) {
            if (!(ans.empty() && digit == 0)) {
                ans += char(digit + '0');
            }
        }

        return ans;
    }
};
```

---

## Approach

We simulate normal multiplication digit by digit.

First create an array of size:

```cpp
n + m
```

because multiplying an `n`-digit number by an `m`-digit number can produce at most `n + m` digits.

For every pair of digits:

```cpp
int product = a * b;
```

we add the product to the correct positions in the result array.

The current digit is stored using:

```cpp
result[pos2] = sum % 10;
```

and the carry is added using:

```cpp
result[pos1] += sum / 10;
```

After all digit multiplications are complete, convert the result array into a string.

---

## Complexity

**Time Complexity:** `O(n × m)`

**Space Complexity:** `O(n + m)`

---

## Key Takeaway

When numbers are too large for normal integer types, represent them as strings and perform arithmetic digit by digit.

Useful character conversion:

```cpp
num1[i] - '0'
```

converts a digit character into an integer.

And:

```cpp
char(digit + '0')
```

converts an integer digit back into a character.

The main multiplication pattern is:

```text
digit × digit
     ↓
add to result
     ↓
store digit + carry
```
