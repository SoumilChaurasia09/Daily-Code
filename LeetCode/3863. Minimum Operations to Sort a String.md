# 3863. Minimum Operations to Sort a String

**Problem Name:** Minimum Operations to Sort a String
**Difficulty:** Medium

---

## Question

Given a lowercase string `s`, one operation allows you to choose a proper substring and sort it in non-descending alphabetical order.

Return the minimum number of operations needed to sort the entire string, or `-1` if it is impossible.

---

## My Solution

The solution sorts a copy of the string and checks whether the string is already sorted. It then uses the string length and boundary characters to determine the minimum number of operations.

---

## Approach

1. Sort a copy of `s` to obtain the target string.
2. If the original string is already sorted, return `0`.
3. If the string has length `2` and is unsorted, return `-1`.
4. For a string of length `3`, check whether either boundary character is already in its correct position.
5. For longer strings:

   * If the first character is the smallest or the last character is the largest, return `1`.
   * If the first character is the largest and the last character is the smallest, check whether either extreme character appears more than once.
   * If an extreme character appears more than once, return `2`; otherwise, return `3`.
   * In other cases, return `2`.

---

## Example

**Input:**

```text
s = "jgg"
```

Sorted string:

```text
"ggj"
```

The first character is the largest, and the last character is the smallest. However, the smallest character `'g'` appears twice, so two operations are sufficient.

**Output:**

```text
2
```

---

## Complexity

**Time Complexity:** `O(n log n)` — Sorting takes `O(n log n)` time.

**Space Complexity:** `O(n)` — The sorted copy requires linear space.

---

## Key Takeaway

When determining the minimum operations, consider duplicate characters as well as the first and last characters. Repeated minimum or maximum characters can reduce the number of required operations.
