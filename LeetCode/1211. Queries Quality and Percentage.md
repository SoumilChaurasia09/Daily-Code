# 1211. Queries Quality and Percentage

**Problem Name:** Queries Quality and Percentage
**Difficulty:** Easy

---

## Question

For each `query_name`, calculate:

* **quality:** The average of `rating / position`
* **poor_query_percentage:** The percentage of queries where `rating < 3`

Both values should be rounded to 2 decimal places.

---

## My Solution

```sql
SELECT
    query_name,
    ROUND(AVG(rating / position), 2) AS quality,
    ROUND(AVG(CASE WHEN rating < 3 THEN 1 ELSE 0 END) * 100, 2) AS poor_query_percentage
FROM Queries
GROUP BY query_name;
```

---

## Approach

### 1. GROUP BY query_name

```sql
GROUP BY query_name
```

This groups all rows belonging to the same query.

For example, all `Dog` rows are grouped together and all `Cat` rows are grouped together.

### 2. Calculate quality

```sql
AVG(rating / position)
```

For every row, we calculate:

```text
rating / position
```

Then `AVG()` calculates the average of these values for each `query_name`.

### 3. Calculate poor query percentage

A query is considered poor when:

```sql
rating < 3
```

We use `CASE`:

```sql
CASE WHEN rating < 3 THEN 1 ELSE 0 END
```

This converts each query into:

* `1` if it is a poor query
* `0` otherwise

Then:

```sql
AVG(CASE WHEN rating < 3 THEN 1 ELSE 0 END) * 100
```

calculates the percentage of poor queries.

### 4. ROUND

```sql
ROUND(..., 2)
```

rounds both calculated values to 2 decimal places.

---

## Example

For `Dog`:

```text
rating / position

5 / 1   = 5
5 / 2   = 2.5
1 / 200 = 0.005
```

Quality:

```text
(5 + 2.5 + 0.005) / 3
= 2.50166...
= 2.50
```

Only one Dog query has `rating < 3`.

```text
1 / 3 × 100 = 33.33%
```

So the result is:

```text
Dog | 2.50 | 33.33
```

---

## Complexity

**Time Complexity:** `O(n)`

The query processes all rows in the `Queries` table.

**Space Complexity:** `O(n)`

The database may use additional space for grouping the rows by `query_name`.

---

## Key Takeaway

Use:

```sql
GROUP BY
```

when calculations need to be performed separately for each category.

For percentage conditions, a useful pattern is:

```sql
AVG(CASE WHEN condition THEN 1 ELSE 0 END) * 100
```

This converts a condition into `1` or `0` and calculates the percentage of rows satisfying the condition.
