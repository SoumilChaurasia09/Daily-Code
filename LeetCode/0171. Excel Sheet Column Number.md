# 0171. Excel Sheet Column Number

**Problem Name:** Excel Sheet Column Number  
**Difficulty:** Easy

---

## Question

Given a string `columnTitle` representing an Excel column title, return its corresponding column number.

Examples:

- `A -> 1`
- `B -> 2`
- `Z -> 26`
- `AA -> 27`
- `AB -> 28`

---

## My Solution

```cpp
class Solution {
public:
    int titleToNumber(string columnTitle) {

        int ans = 0;

        for (int i = 0; i < columnTitle.size(); i++) {

            ans = ans * 26 + (columnTitle[i] - 'A' + 1);

        }

        return ans;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(n)` |
| **Space Complexity** | `O(1)` |

Where `n` is the length of the column title.

---

## What I Learned

This problem helped me understand how to convert an Excel column title into its corresponding number.

I treated the column title as a base-26 number. For each character, I multiplied the current answer by `26` and added the value of the current letter (`A = 1`, `B = 2`, ..., `Z = 26`).

This is similar to converting a number from another base into decimal.

## Personal Notes

Initially, I thought I would need to handle one-letter and two-letter column names separately. After observing the pattern, I realized the same logic works for column titles of any length.
