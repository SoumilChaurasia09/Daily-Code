# 0009. Palindrome Number

**Problem Name:** Palindrome Number  
**Difficulty:** Easy

---

## Question

Given an integer `x`, return `true` if it is a palindrome, otherwise return `false`.

A palindrome is a number that reads the same from left to right and from right to left.

The solution should be implemented **without converting the integer into a string**.

---

## My Solution

```cpp
class Solution {
public:
    bool isPalindrome(int x) {

        if (x < 0) {
            return false;
        }

        int original = x;
        long long reverse = 0;

        while (x > 0) {

            int digit = x % 10;
            reverse = reverse * 10 + digit;
            x = x / 10;
        }

        return original == reverse;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(log n)` |
| **Space Complexity** | `O(1)` |

---

## What I Learned

This problem helped me understand how to reverse an integer without converting it into a string.

I stored the original number, then extracted each digit using the modulo (`%`) operator and built the reversed number. Finally, I compared the reversed number with the original number.

If both numbers were equal, the number was a palindrome.
