# 33. Search in Rotated Sorted Array

**Problem Name:** Search in Rotated Sorted Array
**Difficulty:** Medium

---

## Question

Given a sorted array that has been rotated, find the index of `target`.

All values are distinct.

For example:

```text
nums = [4,5,6,7,0,1,2]
target = 0
```

The answer is:

```text
4
```

The solution must run in `O(log n)` time.

---

## My Solution

```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size() - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                return mid;
            }

            if (nums[left] <= nums[mid]) {
                if (nums[left] <= target && target < nums[mid]) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            } else {
                if (nums[mid] < target && target <= nums[right]) {
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }
        }

        return -1;
    }
};
```

---

## Approach

Use **binary search**.

In a rotated sorted array, at least one half of the current range will always be sorted.

For example:

```text
[4, 5, 6, 7, 0, 1, 2]
       ↑
      mid
```

### Case 1: Left half is sorted

Check:

```cpp
nums[left] <= nums[mid]
```

If true, the left half is sorted.

Then check whether `target` is inside this sorted range:

```cpp
nums[left] <= target && target < nums[mid]
```

If it is, search the left half.

Otherwise, search the right half.

### Case 2: Right half is sorted

If the left half isn't sorted, the right half must be sorted.

Check whether the target is inside the right sorted range:

```cpp
nums[mid] < target && target <= nums[right]
```

If it is, search the right half.

Otherwise, search the left half.

---

## Complexity

**Time Complexity:** `O(log n)`

**Space Complexity:** `O(1)`

---

## Key Takeaway

The main idea is:

```text
Find mid
   ↓
Is left half sorted?
   ↓
Yes → Is target inside left half?
   ↓
Search the correct half
```

If the left half is not sorted, the right half is sorted.

The important condition is:

```cpp
if (nums[left] <= nums[mid])
```

which tells us which side is normally sorted.
