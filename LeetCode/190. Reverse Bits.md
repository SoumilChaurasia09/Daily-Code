# 190. Reverse Bits

**Problem Name:** Reverse Bits
**Difficulty:** Easy

---

## Question

Given a 32-bit integer `n`, reverse all its 32 bits and return the resulting integer.

---

## My Solution

```cpp
class Solution {
public:
    int reverseBits(int n) {
        int result = 0;

        for (int i = 0; i < 32; i++) {
            result = (result << 1) | (n & 1);
            n >>= 1;
        }

        return result;
    }
};
```

---

## Approach

1. Initialize `result = 0` to store the reversed bits.
2. Run a loop exactly 32 times because the integer contains 32 bits.
3. **Extract the last bit:**

   ```cpp
   n & 1
   ```

   This gives either `0` or `1`.
4. **Shift the result left by one bit:**

   ```cpp
   result << 1
   ```

   This creates space for the next bit.
5. **Add the extracted bit:**

   ```cpp
   result = (result << 1) | (n & 1);
   ```

   The bitwise OR places the extracted bit at the rightmost position.
6. **Shift `n` right:**

   ```cpp
   n >>= 1;
   ```

   This moves the next bit into the rightmost position.
7. Return `result` after processing all 32 bits.

---

## Example

**Input:**

```text
n = 43261596
```

Binary representation:

```text
00000010100101000001111010011100
```

After reversing all 32 bits:

```text
00111001011110000010100101000000
```

**Output:**

```text
964176192
```

---

## Complexity

**Time Complexity:** `O(1)` — The loop always executes 32 times.

**Space Complexity:** `O(1)` — Only a constant number of variables are used.

---

## Key Takeaway

Use bitwise AND (`& 1`) to extract the last bit, left shift (`<<`) to make room in the result, bitwise OR (`|`) to append the bit, and right shift (`>>`) to process the next bit.
