# 190. Reverse Bits

**Problem Name:** Reverse Bits
**Difficulty:** Easy

---

## Question

Given a 32-bit unsigned integer `n`, reverse all its 32 bits and return the resulting integer.

For example, the binary representation of `n` is reversed from left to right.

---

## My Solution

```cpp
class Solution {
public:
    uint32_t reverseBits(uint32_t n) {
        uint32_t result = 0;

        for (int i = 0; i < 32; i++) {
            result = (result << 1) | (n & 1);
            n >>= 1;
        }

        return result;
    }
};
```

---

## Approach

### 1. Initialize the result

Set `result = 0`. It will store the reversed bits.

### 2. Process all 32 bits

Use a loop that runs exactly 32 times.

**Step 1: Extract the last bit**

```cpp
n & 1
```

This extracts the rightmost bit of `n`.

**Step 2: Shift the result left**

```cpp
result << 1
```

This creates space for the next bit.

**Step 3: Add the extracted bit**

```cpp
(result << 1) | (n & 1)
```

The bitwise OR places the extracted bit at the rightmost position of `result`.

**Step 4: Remove the processed bit**

```cpp
n >>= 1;
```

This shifts `n` one position to the right so its next bit can be processed.

Repeat these steps 32 times to reverse all the bits.

### 3. Return the result

After all 32 bits have been processed, return `result`.

---

## Example

**Input:**

```text
n = 43261596
```

Binary representation:

```text
00000010100101000001111010011100
```

After reversing all 32 bits:

```text
00111001011110000010100101000000
```

**Output:**

```text
964176192
```

---

## Complexity

**Time Complexity:** `O(1)` — Exactly 32 iterations are performed.

**Space Complexity:** `O(1)` — Only a constant number of variables are used.

---

## Key Takeaway

Use bitwise AND (`& 1`) to extract the last bit, left shift (`<<`) to build the reversed number, bitwise OR (`|`) to append the bit, and right shift (`>>`) to process the next bit.

### Follow-up: How can repeated calls be optimized?

If the function is called many times, use a **lookup table** that reverses the bits of each byte. Split the 32-bit integer into four bytes, reverse each byte using the precomputed table, and combine them in reverse order. This reduces the number of operations per call at the cost of extra memory for the table.
