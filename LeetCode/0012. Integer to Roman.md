# 0012. Integer to Roman

**Problem Name:** Integer to Roman
**Difficulty:** Medium

---

## Question

Given an integer `num`, convert it into its corresponding Roman numeral.

Roman numerals use the following symbols:

```text
I = 1
V = 5
X = 10
L = 50
C = 100
D = 500
M = 1000
```

The special subtractive forms are:

```text
IV = 4
IX = 9
XL = 40
XC = 90
CD = 400
CM = 900
```

---

## My Solution

```cpp
class Solution {
public:
    string intToRoman(int num) {

        vector<int> values = {
            1000, 900, 500, 400,
            100, 90, 50, 40,
            10, 9, 5, 4, 1
        };

        vector<string> symbols = {
            "M", "CM", "D", "CD",
            "C", "XC", "L", "XL",
            "X", "IX", "V", "IV", "I"
        };

        string ans = "";

        for (int i = 0; i < values.size(); i++) {

            while (num >= values[i]) {
                ans += symbols[i];
                num -= values[i];
            }
        }

        return ans;
    }
};
```

---

## Complexity

| Metric               | Value  |
| -------------------- | ------ |
| **Time Complexity**  | `O(1)` |
| **Space Complexity** | `O(1)` |

Since the maximum input is `3999`, the number of iterations is bounded by a small constant.

---

## What I Learned

This problem helped me understand how to convert a number into a Roman numeral using a **Greedy approach**.

I stored the Roman numeral values from largest to smallest, including the special subtractive values such as:

```text
900 = CM
400 = CD
90 = XC
40 = XL
9 = IX
4 = IV
```

For each value, I repeatedly added its corresponding Roman symbol while the number was large enough.

For example:

```text
1994

1000 → M
900  → CM
90   → XC
4    → IV

Result = MCMXCIV
```

---

## Personal Notes

The main idea was to always take the **largest possible Roman value** first.

The two arrays make the logic easy to understand:

```cpp
values
symbols
```

The value at the same index in both arrays represents one Roman numeral conversion.

This problem helped me practice the **Greedy approach** and working with arrays of values and strings.
