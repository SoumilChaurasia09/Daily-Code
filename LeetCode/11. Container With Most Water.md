# 11. Container With Most Water

**Problem Name:** Container With Most Water  
**Difficulty:** Medium

---

## Question

We are given an array `height`, where each element represents the height of a vertical line.

We need to choose two lines that form a container capable of holding the maximum amount of water.

The water capacity depends on:

- The distance between the two lines (width).
- The height of the shorter line.

Return the maximum possible water area.

---

## My Solution

```cpp
class Solution {
public:
    int maxArea(vector<int>& height) {
        int left = 0;
        int right = height.size() - 1;
        int maxWater = 0;

        while (left < right) {
            int width = right - left;
            int h = min(height[left], height[right]);

            int area = width * h;

            maxWater = max(maxWater, area);

            if (height[left] < height[right]) {
                left++;
            } else {
                right--;
            }
        }

        return maxWater;
    }
};
```

---

## Approach

We use the **Two Pointers** technique to find the maximum water area efficiently.

### Step 1: Initialize two pointers

```cpp
int left = 0;
int right = height.size() - 1;
```

- `left` starts at the first index.
- `right` starts at the last index.

Initially, we consider the container with the maximum possible width.

### Step 2: Calculate the width

```cpp
int width = right - left;
```

The distance between the two selected lines represents the container's width.

### Step 3: Find the container height

```cpp
int h = min(height[left], height[right]);
```

The container's water level is limited by the shorter line.

Therefore, we use the minimum of the two heights.

### Step 4: Calculate the water area

```cpp
int area = width * h;
```

**Formula:**

`Area = Width × Minimum Height`

Update the maximum area:

```cpp
maxWater = max(maxWater, area);
```

### Step 5: Move the pointers

```cpp
if (height[left] < height[right]) {
    left++;
} else {
    right--;
}
```

This is the most important part of the algorithm.

- If the left line is shorter, move `left` forward.
- Otherwise, move `right` backward.

**Why?**

The shorter line limits the water capacity.

Moving the taller line cannot increase the container's height, and it decreases the width.

Therefore, we move the shorter line in search of a taller one.

### Step 6: Return the maximum area

Continue until both pointers meet.

Return `maxWater`.

---

## Example

**Input:**

```text
height = [1,8,6,2,5,4,8,3,7]
```

### Step 1: Initialize pointers

```text
left = 0
right = 8
```

### Step 2: Calculate area

```text
width = 8 - 0 = 8

height = min(1, 7) = 1

area = 8 × 1 = 8
```

Move the left pointer because its height is smaller.

### Step 3: Continue calculating

| Left | Right | Width | Minimum Height | Area |
|---:|---:|---:|---:|---:|
| 0 | 8 | 8 | 1 | 8 |
| 1 | 8 | 7 | 7 | 49 |
| 1 | 7 | 6 | 3 | 18 |
| 1 | 6 | 5 | 8 | 40 |
| 1 | 5 | 4 | 4 | 16 |
| 1 | 4 | 3 | 5 | 15 |
| 1 | 3 | 2 | 2 | 4 |
| 1 | 2 | 1 | 6 | 6 |

### Step 4: Find maximum area

```text
maxWater = 49
```

**Output:**

```text
49
```

The maximum area is formed by the lines at indices `1` and `8`.

---

## Complexity

**Time Complexity:** `O(n)`

Both pointers move towards each other. Each element is visited at most once.

**Space Complexity:** `O(1)`

Only a few variables are used. No additional data structure is required.

---

## Key Takeaway

The main concept is **Two Pointers**.

Remember:

1. Start with one pointer at each end.
2. Calculate the area using the shorter height.
3. Update the maximum area.
4. Move the pointer pointing to the shorter line.
5. Repeat until both pointers meet.

**Important Formula:**

```text
Area = (right - left) × min(height[left], height[right])
```

**Remember:** Always move the pointer at the shorter line because it is the limiting factor for the water capacity.
