# 504. Base 7

**Problem Name:** Base 7
**Difficulty:** Easy

---

## Question

Given an integer `num`, convert it into its **base 7 representation** and return the result as a string.

Base 7 uses the digits:

```text
0 1 2 3 4 5 6
```

For example:

```text
100 in base 7 = 202
```

---

## My Solution

```cpp id="z7r2mt"
class Solution {
public:
    string convertToBase7(int num) {
        if (num == 0) {
            return "0";
        }

        bool negative = num < 0;

        if (negative) {
            num = -num;
        }

        string result = "";

        while (num > 0) {
            result += char('0' + num % 7);
            num /= 7;
        }

        reverse(result.begin(), result.end());

        if (negative) {
            result = "-" + result;
        }

        return result;
    }
};
```

---

## Approach

To convert a decimal number to base 7, repeatedly divide the number by `7`.

The remainder gives the next base-7 digit.

### 1. Handle zero

If:

```cpp id="3d5b8a"
num == 0
```

the answer is simply:

```text id="y3kj6w"
"0"
```

---

### 2. Handle negative numbers

We first remember whether the number is negative:

```cpp id="1t7x5q"
bool negative = num < 0;
```

Then work with its positive value:

```cpp id="l1d7ca"
num = -num;
```

The negative sign is added at the end.

---

### 3. Get base-7 digits

We repeatedly calculate:

```cpp id="cv6w3m"
num % 7
```

This gives the remainder.

Then:

```cpp id="p5m7fh"
num /= 7;
```

removes the part that has already been converted.

For example, `100`:

```text id="0uhz5d"
100 % 7 = 2
100 / 7 = 14

14 % 7 = 0
14 / 7 = 2

2 % 7 = 2
2 / 7 = 0
```

The remainders are obtained as:

```text id="k5f8dn"
2, 0, 2
```

They are generated from right to left, so we reverse them:

```text id="q3r7tz"
202
```

---

### 4. Convert the digit to a character

The remainder is an integer from `0` to `6`.

We convert it to a character using:

```cpp id="h4p2c7"
char('0' + num % 7)
```

For example:

```text id="t6g0ac"
'0' + 2 → '2'
'0' + 5 → '5'
```

---

### 5. Reverse the result

Because the digits are generated from the least significant digit first:

```cpp id="j6r8vy"
reverse(result.begin(), result.end());
```

puts them in the correct order.

---

## Example

For:

```text id="n2r7cq"
num = 100
```

Repeated division gives:

```text id="w4n8pn"
100 → remainder 2
14  → remainder 0
2   → remainder 2
```

So the generated string is:

```text id="e6y7r3"
"202"
```

For:

```text id="n7w5za"
num = -7
```

We convert `7`:

```text id="p4u1cm"
7 % 7 = 0
7 / 7 = 1

1 % 7 = 1
1 / 7 = 0
```

This gives:

```text id="8u8m9n"
"10"
```

Since the original number was negative, we add `-`:

```text id="j3v4dz"
"-10"
```

---

## Complexity

**Time Complexity:** `O(log₇(|num|))`

The number is divided by `7` repeatedly, so the number of iterations is proportional to the number of base-7 digits.

**Space Complexity:** `O(log₇(|num|))`

The result string stores the base-7 digits.

---

## Key Takeaway

To convert decimal to another base:

```text id="x4f1pw"
remainder = num % base
num = num / base
```

For base 7, use:

```text id="z2j7xa"
num % 7
num / 7
```

The remainders are generated backwards, so reverse the result at the end.
