# 881. Boats to Save People

**Problem Name:** Boats to Save People
**Difficulty:** Medium

---

## Question

We have people with different weights and an unlimited number of boats.

Each boat can carry at most **2 people**, and their combined weight cannot exceed `limit`.

Find the minimum number of boats required to carry everyone.

---

## My Solution

```cpp
class Solution {
public:
    int numRescueBoats(vector<int>& people, int limit) {
        sort(people.begin(), people.end());

        int left = 0;
        int right = people.size() - 1;
        int boats = 0;

        while (left <= right) {
            if (people[left] + people[right] <= limit) {
                left++;
            }

            right--;
            boats++;
        }

        return boats;
    }
};
```

---

## Approach

First, sort the people by weight.

Use two pointers:

* `left` points to the lightest person.
* `right` points to the heaviest person.

For every boat:

1. Take the heaviest person.
2. Check if the lightest person can go with them.
3. If their combined weight is within `limit`, put both in the same boat.
4. Otherwise, the heaviest person must go alone.
5. Move `right` every time because the heaviest person has been placed in a boat.
6. Increase the boat count.

---

## Example

```text
people = [3, 2, 2, 1]
limit = 3
```

After sorting:

```text
[1, 2, 2, 3]
```

### Step 1

```text
1 + 3 > 3
```

Person `3` must go alone.

```text
Boats = 1
```

### Step 2

```text
1 + 2 <= 3
```

Put `1` and `2` together.

```text
Boats = 2
```

### Step 3

The remaining `2` goes alone.

```text
Boats = 3
```

Answer:

```text
3
```

---

## Why This Works

The heaviest person is the hardest person to place.

If the lightest person cannot fit with the heaviest person, then **nobody else can fit with the heaviest person**, because everyone else is at least as heavy as the lightest person.

If the lightest person can fit, pairing them with the heaviest person is optimal because it saves a boat.

This is a **Greedy + Two Pointer** approach.

---

## Complexity

**Time Complexity:** `O(n log n)`

Sorting takes `O(n log n)` and the two-pointer traversal takes `O(n)`.

**Space Complexity:** `O(1)` auxiliary space, excluding the sorting implementation's internal stack.

---

## Key Takeaway

For problems where:

* We have a maximum capacity.
* At most two elements can be grouped.
* We want to minimize the number of groups.

A useful strategy is:

```text
Sort → Use two pointers → Pair smallest with largest when possible
```
