# 3723. Maximize Sum of Squares of Digits

**Problem Name:** Maximize Sum of Squares of Digits
**Difficulty:** Medium

---

## Question

Given two positive integers, `num` and `sum`, construct an integer with exactly `num` digits whose digits add up to `sum`.

The goal is to maximize the sum of the squares of its digits. If multiple integers achieve the same maximum score, return the largest integer. If no valid integer exists, return an empty string.

---

## My Solution

```cpp
class Solution {
public:
    string maxSumOfSquares(int num, int sum) {
        if (sum > 9 * num) {
            return "";
        }

        string result = "";

        for (int i = 0; i < num; i++) {
            int digit = min(9, sum);
            result += char('0' + digit);
            sum -= digit;
        }

        return result;
    }
};
```

---

## Approach

### 1. Check whether a solution exists

Each digit can be at most `9`. Therefore, the maximum possible digit sum is:

`9 * num`

If `sum > 9 * num`, no valid integer exists, so return an empty string.

### 2. Place the largest possible digits first

To maximize the sum of squared digits, assign as much of the remaining sum as possible to each digit, starting from the left.

For every position:

* Choose `min(9, sum)` as the next digit.
* Append that digit to the result.
* Subtract the digit from `sum`.

This fills the number with as many `9`s as possible, followed by the remaining digit and then zeros.

### 3. Return the result

After `num` iterations, the string contains exactly `num` digits and has the required digit sum.

Placing the largest possible digits first also gives the largest integer among those achieving the maximum score.

---

## Example

**Input:**

```text
num = 2, sum = 17
```

**Execution:**

* First digit: `min(9, 17) = 9`. Remaining sum: `8`.
* Second digit: `min(9, 8) = 8`. Remaining sum: `0`.

**Output:**

```text
"98"
```

The sum of squared digits is:

`9² + 8² = 81 + 64 = 145`

---

## Complexity

**Time Complexity:** `O(num)` — We process each digit once.

**Space Complexity:** `O(num)` — The result string stores `num` digits.

---

## Key Takeaway

To maximize the sum of squared digits, assign the largest possible digit (`9`) to the leftmost positions first, then use the remaining sum for the next digit. Any unused positions become zeros.
