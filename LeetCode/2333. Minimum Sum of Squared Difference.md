# 2333. Minimum Sum of Squared Difference

**Problem Name:** Minimum Sum of Squared Difference
**Difficulty:** Medium

---

## Question

Given two arrays, calculate the absolute difference at each index. You can reduce these differences by performing at most `k1 + k2` operations.

Each operation changes one array element by `1` or `-1`, reducing its absolute difference by at most `1`.

Return the minimum possible sum of squared differences.

---

## My Solution

The solution uses **binary search** to find the smallest maximum difference that can be achieved within the available operations.

---

## Approach

### 1. Calculate the differences

For each index:

`diff[i] = abs(nums1[i] - nums2[i])`

Combine the available operations:

`k = k1 + k2`

If the sum of all differences is at most `k`, every difference can be reduced to zero, so return `0`.

### 2. Binary search for the maximum difference

Let `mid` be a possible maximum difference.

To reduce every difference greater than `mid` to `mid`, the required operations are:

`operations = sum(diff[i] - mid)` for every `diff[i] > mid`.

* If `operations <= k`, the maximum difference `mid` is achievable. Try a smaller value.
* Otherwise, more operations are needed, so try a larger value.

Binary search finds the smallest achievable maximum difference.

### 3. Calculate the answer

Reduce every difference greater than the binary-search result to that result.

Use the remaining operations to reduce individual differences by one more. This minimizes the sum of squares because reducing a larger difference provides a greater reduction in its square.

Finally, add all squared differences.

---

## Example

**Input:**

```text
nums1 = [1,4,10,12]
nums2 = [5,8,6,9]
k1 = 1
k2 = 1
```

**Initial differences:**

```text
[4, 4, 4, 3]
```

There are `2` operations available.

One optimal result is:

```text
[3, 4, 3, 3]
```

The sum of squared differences is:

`3² + 4² + 3² + 3² = 43`

**Output:**

```text
43
```

---

## Complexity

**Time Complexity:** `O(n log M)`, where `M` is the maximum absolute difference.

**Space Complexity:** `O(n)` for storing the differences.

---

## Key Takeaway

Binary search can find the smallest achievable maximum difference. After finding that threshold, use any remaining operations to reduce individual differences further and minimize the sum of squares.
