# 3644. Maximum K to Sort a Permutation

**Problem Name:** Maximum K to Sort a Permutation
**Difficulty:** Medium

---

## Question

You are given a permutation of integers from `0` to `n - 1`.

You can swap two elements only when their bitwise AND equals `k`:

`nums[i] & nums[j] == k`

Return the maximum possible value of `k` that allows the array to be sorted. If the array is already sorted, return `0`.

---

## My Solution

```cpp
class Solution {
public:
    int sortPermutation(vector<int>& nums) {
        int n = nums.size();
        int k = (1 << 30) - 1;
        bool sorted = true;

        for (int i = 0; i < n; i++) {
            if (nums[i] != i) {
                k &= nums[i];
                sorted = false;
            }
        }

        if (sorted) {
            return 0;
        }

        return k;
    }
};
```

---

## Approach

### 1. Identify misplaced elements

In a sorted permutation, every element must satisfy:

`nums[i] == i`

If this condition is false, the element is misplaced and must be moved.

### 2. Calculate the bitwise AND

Initialize `k` with all bits set:

```cpp
int k = (1 << 30) - 1;
```

For every misplaced element, update:

```cpp
k &= nums[i];
```

The bitwise AND keeps only the bits that are set in every misplaced element.

These common bits determine the maximum possible value of `k`.

### 3. Handle an already sorted array

If every element is already in its correct position, return `0`.

Otherwise, return the calculated `k`.

---

## Example

**Input:**

```text
nums = [0, 3, 2, 1]
```

The misplaced elements are `3` and `1`.

Their bitwise AND is:

```text
3 = 11 (binary)
1 = 01 (binary)
    --
    01 = 1
```

Therefore, the maximum valid value of `k` is `1`.

**Output:**

```text
1
```

---

## Complexity

**Time Complexity:** `O(n)` — Each array element is checked once.

**Space Complexity:** `O(1)` — Only a few variables are used.

---

## Key Takeaway

For a permutation, misplaced elements must be moved using valid swaps. The bitwise AND of all misplaced values gives the maximum possible `k`, while an already sorted permutation returns `0`.
