# 511. Game Play Analysis I

**Problem Name:** Game Play Analysis I
**Difficulty:** Easy

---

## Question

We are given an `Activity` table containing player login records.

Each player can have multiple login records on different dates.

We need to find the **earliest login date for each player**.

The output must contain:

* `player_id`
* `first_login`

---

## My Solution

```sql
SELECT
    player_id,
    MIN(event_date) AS first_login
FROM Activity
GROUP BY player_id;
```

---

## Approach

### Step 1: Select the required columns

```sql
SELECT player_id, MIN(event_date) AS first_login
```

* `player_id` identifies each player.
* `MIN(event_date)` returns the earliest login date.
* `AS first_login` renames the result column.

### Step 2: Select the table

```sql
FROM Activity
```

We retrieve records from the `Activity` table.

### Step 3: Group records by player

```sql
GROUP BY player_id
```

This groups all login records belonging to the same player.

The `MIN()` function then finds the earliest login date within each group.

---

## Example

**Input:**

| player_id | device_id | event_date | games_played |
| --------- | --------- | ---------- | ------------ |
| 1         | 2         | 2016-03-01 | 5            |
| 1         | 2         | 2016-05-02 | 6            |
| 2         | 3         | 2017-06-25 | 1            |
| 3         | 1         | 2016-03-02 | 0            |
| 3         | 4         | 2018-07-03 | 5            |

### Step 1: Group by player_id

Player 1 has two login dates:

* 2016-03-01
* 2016-05-02

Player 2 has one login date:

* 2017-06-25

Player 3 has two login dates:

* 2016-03-02
* 2018-07-03

### Step 2: Find the minimum date

| player_id | MIN(event_date) |
| --------- | --------------- |
| 1         | 2016-03-01      |
| 2         | 2017-06-25      |
| 3         | 2016-03-02      |

**Output:**

| player_id | first_login |
| --------- | ----------- |
| 1         | 2016-03-01  |
| 2         | 2017-06-25  |
| 3         | 2016-03-02  |

---

## Complexity

**Time Complexity:** `O(n)`

The database processes the activity records and calculates the minimum date for each player. Actual execution can depend on indexing and the database query plan.

**Space Complexity:** `O(p)`

Grouping may require storage for up to `p` distinct players, depending on the database execution strategy.

---

## Key Takeaway

Important SQL concepts used:

1. **MIN():** Returns the smallest value. For dates, it returns the earliest date.
2. **GROUP BY:** Groups rows having the same value in a column.
3. **AS:** Assigns an alias to a result column.

**Remember:** When finding the earliest or latest record for each group, `MIN()` or `MAX()` with `GROUP BY` is a useful pattern.
