# 462. Minimum Moves to Equal Array Elements II

**Problem Name:** Minimum Moves to Equal Array Elements II
**Difficulty:** Medium

---

## Question

We are given an integer array `nums`.

In one move, we can increment or decrement any single element by `1`.

We need to find the minimum number of moves required to make all elements equal.

---

## My Solution

```cpp
class Solution {
public:
    int minMoves2(vector<int>& nums) {
        sort(nums.begin(), nums.end());

        int median = nums[nums.size() / 2];
        int moves = 0;

        for (int num : nums) {
            moves += abs(num - median);
        }

        return moves;
    }
};
```

---

## Approach

### Step 1: Sort the array

```cpp
sort(nums.begin(), nums.end());
```

Sorting arranges the elements in ascending order.

### Step 2: Find the median

```cpp
int median = nums[nums.size() / 2];
```

The median is the middle element of the sorted array.

The important mathematical concept is that **the median minimizes the sum of absolute differences**.

Therefore, making every element equal to the median requires the minimum number of moves.

For an even-sized array, any value between the two middle elements minimizes the total moves. Choosing the upper middle element works correctly.

### Step 3: Calculate the moves

```cpp
for (int num : nums) {
    moves += abs(num - median);
}
```

For every element, calculate its absolute difference from the median.

The absolute difference tells us how many increments or decrements are required to make that element equal to the median.

### Step 4: Return the answer

```cpp
return moves;
```

---

## Example

**Input:**

```text
nums = [1, 10, 2, 9]
```

### Step 1: Sort the array

```text
[1, 2, 9, 10]
```

### Step 2: Find the median

There are four elements, so we choose the upper middle element.

```text
median = 9
```

### Step 3: Calculate the moves

| Element |           Moves |
| ------- | --------------: |
| 1       |  abs(1 - 9) = 8 |
| 2       |  abs(2 - 9) = 7 |
| 9       |  abs(9 - 9) = 0 |
| 10      | abs(10 - 9) = 1 |

### Step 4: Calculate total moves

```text
moves = 8 + 7 + 0 + 1
      = 16
```

**Output:**

```text
16
```

---

## Complexity

**Time Complexity:** `O(n log n)`

* Sorting the array takes `O(n log n)`.
* Finding the median takes `O(1)`.
* Calculating the total moves takes `O(n)`.

Overall complexity is `O(n log n)`.

**Space Complexity:** `O(log n)` auxiliary space on typical implementations of `std::sort` due to recursion stack usage.

---

## Key Takeaway

The main concept is **Median and Greedy Optimization**.

Remember:

* For LeetCode 453, incrementing `n - 1` elements is equivalent to decrementing one element. The minimum element gives the answer.
* For LeetCode 462, we can increment or decrement individual elements. The median gives the minimum total moves.

**Important Formula:**

```text
Minimum Moves = Sum of abs(nums[i] - median)
```

**Remember:** When minimizing the sum of absolute differences, think about the median rather than the average.
