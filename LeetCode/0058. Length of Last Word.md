# 0058. Length of Last Word

**Problem Name:** Length of Last Word  
**Difficulty:** Easy

---

## Question

Given a string `s` consisting of words and spaces, return the length of the last word.

A word is defined as a sequence of non-space characters.

---

## My Solution

```cpp
class Solution {
public:
    int lengthOfLastWord(string s) {

        int length = 0;
        int i = s.size() - 1;

        while (i >= 0 && s[i] == ' ') {
            i--;
        }

        while (i >= 0 && s[i] != ' ') {
            length++;
            i--;
        }

        return length;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(n)` |
| **Space Complexity** | `O(1)` |

---

## What I Learned

This problem helped me understand how to traverse a string from the end.

I first skipped all trailing spaces, then counted the characters of the last word until I reached another space or the beginning of the string.

This approach avoids splitting the string into words and uses constant extra space.

---

## Personal Notes

Initially, I thought about splitting the string into separate words and taking the last one. Although that works, it requires extra memory.

Traversing the string from the end turned out to be a much simpler and more efficient solution. This problem also gave me more confidence in handling strings with leading and trailing spaces.
