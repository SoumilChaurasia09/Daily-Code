# 264. Ugly Number II

**Problem Name:** Ugly Number II
**Difficulty:** Medium

---

## Question

An ugly number is a positive number whose prime factors are only:

```text
2, 3, 5
```

Given `n`, return the `nth` ugly number.

The sequence starts with:

```text
1, 2, 3, 4, 5, 6, 8, 9, 10, 12, ...
```

---

## My Solution

```cpp
class Solution {
public:
    int nthUglyNumber(int n) {
        vector<int> ugly(n);

        ugly[0] = 1;

        int i2 = 0;
        int i3 = 0;
        int i5 = 0;

        for (int i = 1; i < n; i++) {
            int next2 = ugly[i2] * 2;
            int next3 = ugly[i3] * 3;
            int next5 = ugly[i5] * 5;

            ugly[i] = min(next2, min(next3, next5));

            if (ugly[i] == next2)
                i2++;

            if (ugly[i] == next3)
                i3++;

            if (ugly[i] == next5)
                i5++;
        }

        return ugly[n - 1];
    }
};
```

---

## Approach

We build the ugly numbers one by one.

Every ugly number can be generated by multiplying an earlier ugly number by:

```text
2, 3, or 5
```

We use three pointers:

```text
i2 → numbers that can be multiplied by 2
i3 → numbers that can be multiplied by 3
i5 → numbers that can be multiplied by 5
```

For every position, calculate:

```text
next2 = ugly[i2] × 2
next3 = ugly[i3] × 3
next5 = ugly[i5] × 5
```

The smallest of these three is the next ugly number.

---

## Example

For:

```text
n = 10
```

We start with:

```text
ugly = [1]
```

Possible next values:

```text
1 × 2 = 2
1 × 3 = 3
1 × 5 = 5
```

Smallest is `2`.

Then:

```text
2, 3, 5, 4, 5, 6, 8, 9, 10, 12
```

The first 10 ugly numbers are:

```text
1, 2, 3, 4, 5, 6, 8, 9, 10, 12
```

Therefore the answer is:

```text
12
```

---

## Why Do We Increment Multiple Pointers?

Suppose the next ugly number is `6`.

It can be generated in two ways:

```text
2 × 3 = 6
3 × 2 = 6
```

So both corresponding pointers need to move forward.

That is why we use separate `if` statements instead of `else if`:

```cpp
if (ugly[i] == next2)
    i2++;

if (ugly[i] == next3)
    i3++;

if (ugly[i] == next5)
    i5++;
```

This prevents duplicate ugly numbers.

---

## Complexity

**Time Complexity:** `O(n)`

We generate each ugly number once.

**Space Complexity:** `O(n)`

The `ugly` array stores the first `n` ugly numbers.

---

## Key Takeaway

Use **Dynamic Programming + Three Pointers**.

```text
2-pointer → generate multiples of 2
3-pointer → generate multiples of 3
5-pointer → generate multiples of 5

Take the smallest → next ugly number
```

This efficiently generates the ugly number sequence without checking every integer.
