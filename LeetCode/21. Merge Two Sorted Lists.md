# 21. Merge Two Sorted Lists

**Problem Name:** Merge Two Sorted Lists
**Difficulty:** Easy

---

## Question

Given two sorted linked lists, merge them into one sorted linked list.

We should reuse the existing nodes instead of creating a new linked list.

For example:

```text
list1: 1 → 2 → 4
list2: 1 → 3 → 4

Result: 1 → 1 → 2 → 3 → 4 → 4
```

---

## My Solution

```cpp
class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        ListNode dummy(0);
        ListNode* current = &dummy;

        while (list1 != nullptr && list2 != nullptr) {
            if (list1->val <= list2->val) {
                current->next = list1;
                list1 = list1->next;
            } else {
                current->next = list2;
                list2 = list2->next;
            }

            current = current->next;
        }

        if (list1 != nullptr) {
            current->next = list1;
        } else {
            current->next = list2;
        }

        return dummy.next;
    }
};
```

---

## Approach

Both linked lists are already sorted.

We compare the current nodes of `list1` and `list2`.

* If `list1->val` is smaller, connect `list1` to the result.
* Otherwise, connect `list2` to the result.
* Move the selected list forward.
* Move `current` forward.

When one list becomes empty, attach the remaining part of the other list.

A dummy node is used to make handling the first node easier.

The actual merged list starts at:

```cpp
dummy.next
```

---

## Complexity

**Time Complexity:** `O(n + m)`

**Space Complexity:** `O(1)`

---

## Key Takeaway

For merging sorted linked lists, remember this pattern:

```text
Compare → Connect smaller node → Move pointer
```

The important linked-list operations are:

```cpp
current->next = list1;
list1 = list1->next;
current = current->next;
```

This is a very useful pattern for TCS NQT and other linked-list questions.
