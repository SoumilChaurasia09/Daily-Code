# 3903. Smallest Stable Index I

**Problem Name:** Smallest Stable Index I
**Difficulty:** Easy

---

## Question

Find the smallest index `i` such that the difference between the maximum value from `0` to `i` and the minimum value from `i` to the end is at most `k`.

---

## My Solution

```cpp
class Solution {
public:
    int firstStableIndex(vector<int>& nums, int k) {
        int n = nums.size();

        vector<int> suffixMin(n);
        suffixMin[n - 1] = nums[n - 1];

        for (int i = n - 2; i >= 0; i--) {
            suffixMin[i] = min(nums[i], suffixMin[i + 1]);
        }

        int prefixMax = nums[0];

        for (int i = 0; i < n; i++) {
            prefixMax = max(prefixMax, nums[i]);

            if (prefixMax - suffixMin[i] <= k) {
                return i;
            }
        }

        return -1;
    }
};
```

---

## Important Fix

The compile error occurs because the judge is calling:

```cpp
firstStableIndex()
```

but the previous code used:

```cpp
smallestStableIndex()
```

The function name must **exactly match** the name expected by LeetCode.

So use:

```cpp
int firstStableIndex(vector<int>& nums, int k)
```

---

## Approach

1. Create a `suffixMin` array.
2. `suffixMin[i]` stores the minimum value from index `i` to the end.
3. Maintain `prefixMax`, which stores the maximum value from index `0` to `i`.
4. For every index:

   * Calculate `prefixMax - suffixMin[i]`.
   * If it is at most `k`, return that index.
5. Since we scan from left to right, the first valid index is the smallest one.

---

## Complexity

**Time Complexity:** `O(n)`

**Space Complexity:** `O(n)`

---

## Key Takeaway

When LeetCode gives a predefined function name, the function name must match **exactly**, otherwise the code will give a compile error even if the logic is correct.
