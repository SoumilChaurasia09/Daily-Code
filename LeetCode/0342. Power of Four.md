# 0342. Power of Four

**Problem Name:** Power of Four  
**Difficulty:** Easy

---

## Question

Given an integer `n`, return `true` if it is a power of four. Otherwise, return `false`.

An integer is a power of four if there exists an integer `x` such that:

```text
n = 4^x
```

---

## My Solution

```cpp
class Solution {
public:
    bool isPowerOfFour(int n) {

        if (n <= 0) {
            return false;
        }

        while (n % 4 == 0) {
            n = n / 4;
        }

        return n == 1;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(log₄ n)` |
| **Space Complexity** | `O(1)` |

---

## What I Learned

This problem helped me understand how powers of four behave.

If a number is a power of four, it can be divided by `4` repeatedly until it becomes `1`. If, after all possible divisions, the number is exactly `1`, then it is a power of four.

I also learned to check for zero and negative numbers first because they cannot be powers of four.

---

## Personal Notes

Initially, I thought about multiplying `4` repeatedly until it reached the given number. However, dividing the number by `4` until it became `1` was a much simpler approach.

I also learned that there are bit manipulation and mathematical solutions for this problem, but this loop-based approach was easier for me to understand and implement while learning the concept.
