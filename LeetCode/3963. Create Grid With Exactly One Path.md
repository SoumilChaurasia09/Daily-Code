# 3963. Create Grid With Exactly One Path

**Problem Name:** Create Grid With Exactly One Path
**Difficulty:** Easy

---

## Question

Construct an `m x n` grid containing `'.'` for free cells and `'#'` for obstacles.

There must be exactly one valid path from the top-left cell `(0, 0)` to the bottom-right cell `(m - 1, n - 1)`, moving only right or down.

---

## My Solution

```cpp
class Solution {
public:
    vector<string> createGrid(int m, int n) {
        vector<string> grid(m, string(n, '#'));

        for (int j = 0; j < n; j++) {
            grid[0][j] = '.';
        }

        for (int i = 0; i < m; i++) {
            grid[i][n - 1] = '.';
        }

        return grid;
    }
};
```

---

## Approach

### Step 1: Initialize the grid

```cpp
vector<string> grid(m, string(n, '#'));
```

Create a grid filled entirely with obstacles.

### Step 2: Open the top row

```cpp
for (int j = 0; j < n; j++) {
    grid[0][j] = '.';
}
```

Make every cell in the first row free. This allows movement from the top-left corner to the top-right corner.

### Step 3: Open the last column

```cpp
for (int i = 0; i < m; i++) {
    grid[i][n - 1] = '.';
}
```

Make every cell in the last column free. This allows movement from the top-right corner to the bottom-right corner.

### Step 4: Return the grid

The only valid route is to move right along the top row and then down the last column.

All other cells remain obstacles, preventing alternative paths.

---

## Example

**Input:**

```text
m = 3, n = 3
```

**Output:**

```text
["...", "##.", "##."]
```

Grid representation:

```text
. . .
# # .
# # .
```

The only valid path is:

```text
(0,0) → (0,1) → (0,2)
                   ↓
                (1,2)
                   ↓
                (2,2)
```

Therefore, exactly one valid path exists.

---

## Complexity

**Time Complexity:** `O(m × n)`

Initializing the grid takes `O(m × n)` time. Opening the top row and last column takes `O(m + n)` time.

**Space Complexity:** `O(m × n)`

The grid contains `m × n` characters.

---

## Key Takeaway

Initialize every cell as an obstacle, then open the top row and last column.

This creates exactly one path: move right first, then down.

**Important:** The LeetCode judge expects the function name `createGrid`. Using `constructGrid` causes a compilation error because the function name does not match the expected signature.
