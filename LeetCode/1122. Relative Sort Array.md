# 1122. Relative Sort Array

**Problem Name:** Relative Sort Array  
**Difficulty:** Easy

---

## Question

Given two arrays `arr1` and `arr2`:

- All elements in `arr2` are distinct.
- Every element of `arr2` also exists in `arr1`.

Sort `arr1` so that:

- The elements appearing in `arr2` come first and follow the same order as in `arr2`.
- The remaining elements are placed at the end in ascending order.

---

## My Solution

```cpp
class Solution {
public:
    vector<int> relativeSortArray(vector<int>& arr1, vector<int>& arr2) {

        unordered_map<int, int> freq;

        for (int num : arr1) {
            freq[num]++;
        }

        vector<int> ans;

        for (int num : arr2) {

            while (freq[num] > 0) {
                ans.push_back(num);
                freq[num]--;
            }
        }

        vector<int> remaining;

        for (auto it : freq) {

            while (it.second > 0) {
                remaining.push_back(it.first);
                it.second--;
            }
        }

        sort(remaining.begin(), remaining.end());

        for (int num : remaining) {
            ans.push_back(num);
        }

        return ans;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(n + m + k log k)` |

Where:
- `n` = size of `arr1`
- `m` = size of `arr2`
- `k` = number of elements not present in `arr2`

| Metric | Value |
|--------|-------|
| **Space Complexity** | `O(n)` |

---

## What I Learned

This problem helped me practice using a **Hash Map** to count the frequency of elements.

I first stored the frequency of every element in `arr1`. Then I traversed `arr2` and placed its elements into the answer according to their frequencies. Finally, I collected the remaining elements, sorted them, and added them to the end of the answer.

This approach follows the required relative ordering while efficiently handling duplicate values.

---

## Personal Notes

Initially, I thought about sorting the entire array with a custom comparator. However, using a frequency map made the implementation much simpler and easier to understand.

This problem reinforced how frequency counting and sorting can be combined to solve ordering problems efficiently.
