# 0747. Largest Number At Least Twice of Others

**Problem Name:** Largest Number At Least Twice of Others  
**Difficulty:** Easy

---

## Question

Given an integer array `nums` where the largest element is unique, determine whether the largest element is at least twice as large as every other number.

- If it is, return the index of the largest element.
- Otherwise, return `-1`.

---

## My Solution

```cpp
class Solution {
public:
    int dominantIndex(vector<int>& nums) {

        int largest = -1;
        int secondLargest = -1;
        int index = -1;

        for (int i = 0; i < nums.size(); i++) {

            if (nums[i] > largest) {
                secondLargest = largest;
                largest = nums[i];
                index = i;
            }
            else if (nums[i] > secondLargest) {
                secondLargest = nums[i];
            }
        }

        if (largest >= 2 * secondLargest) {
            return index;
        }

        return -1;
    }
};
```

---

## Complexity

| Metric | Value |
|--------|-------|
| **Time Complexity** | `O(n)` |
| **Space Complexity** | `O(1)` |

---

## What I Learned

This problem taught me how to find the **largest** and **second largest** elements in a single traversal.

Instead of sorting the array, I kept track of the two largest values while iterating through the array. After the loop, I simply checked whether the largest element was at least twice the second largest.

This approach is faster than sorting and uses constant extra space.

---

## Personal Notes

Initially, I thought about sorting the array to find the two largest numbers. However, sorting takes `O(n log n)` time, which is unnecessary.

By updating the largest and second largest values during one traversal, I solved the problem in `O(n)` time. This problem reinforced that sometimes only a few variables are enough to keep track of the information needed.
