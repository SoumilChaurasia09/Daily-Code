# 507. Perfect Number

**Problem Name:** Perfect Number
**Difficulty:** Easy

---

## Question

A number is called a **perfect number** if the sum of all its positive divisors, excluding the number itself, is equal to the number.

For example:

```text
28 = 1 + 2 + 4 + 7 + 14
```

Therefore, `28` is a perfect number.

---

## My Solution

```cpp
class Solution {
public:
    bool checkPerfectNumber(int num) {
        if (num <= 1)
            return false;

        int sum = 1;

        for (int i = 2; i * i <= num; i++) {
            if (num % i == 0) {
                sum += i;

                if (i != num / i)
                    sum += num / i;
            }
        }

        return sum == num;
    }
};
```

---

## Approach

We need to find all divisors of `num`.

Instead of checking every number from `1` to `num - 1`, we only check up to `sqrt(num)`.

If `i` divides `num`, then:

```text
i
num / i
```

are both divisors.

For example, for `28`:

```text
i = 2
28 / 2 = 14

i = 4
28 / 4 = 7
```

So we can find both divisors at the same time.

We start with:

```text
sum = 1
```

because `1` is always a proper divisor of every number greater than `1`.

The condition:

```cpp
if (i != num / i)
```

prevents adding the same divisor twice when `num` is a perfect square.

Finally:

```cpp
return sum == num;
```

---

## Example

For:

```text
num = 28
```

The divisors we find are:

```text
1, 2, 14, 4, 7
```

Their sum is:

```text
1 + 2 + 14 + 4 + 7 = 28
```

Therefore:

```text
true
```

---

## Complexity

**Time Complexity:** `O(√n)`

**Space Complexity:** `O(1)`

---

## Key Takeaway

When finding divisors, we don't need to check all numbers up to `n`.

If `i` is a divisor, then `n / i` is also a divisor. Therefore, checking only up to `√n` lets us find divisors in pairs efficiently.
